## §0 一句话模型

> ## 凡夫畏果，菩萨畏因，**佛畏系统**。
> ## 因为 —— **结果 = f(运气, 实力)，而 实力 = 长期系统中被重复执行的动作的积分。**
> ## 你唯一能直接拧的旋钮，是"动作"和"下注比例"，不是"结果"。

写成式子：

```
三种畏惧的层级：

  畏果  →  优化 [ 结果 ]        每次都要赢       ← 你在跟方差搏斗
  畏因  →  优化 [ 动作 ]        找对原因就改     ← 你在跟线性因果搏斗
  畏系统 → 优化 [ 规则 / 下注 / 重复次数 ]      ← 你在跟分布搏斗

而实际的数学结构是：

  单次结果      = 运气 + 实力           ← 信噪比极低，不可优化
  长期结果      = ∏ (1 + f × rᵢ)        ← 连乘，不是连加
  你追求的目标  = max E[ log(1 + f × r) ]   ← 不是 max E[r]

  ⇒ 能调的旋钮只有两个：重复次数 N，下注比例 f
```

**这是全书的发动机。** 它一次解释掉四个悖论：

| 悖论 | 用模型一句话解开 |
|---|---|
| 越努力盯结果，结果越差 | 盯结果 → 每次波动都要动作 → **交易成本与择时误差吃掉正的期望** |
| 有人方法很笨却一直赢 | 他的方法能**被重复很多次**，而你的"聪明方法"是一次性的 |
| 明明期望值为正还是亏光 | 期望值算的是**一群人同时玩一次**；你玩的是**一个人连续玩很多次**（见 §5.1） |
| 计划定得越细，执行越差 | 目标驱动是**负反馈**：达成即消差，消差即停机（见 §4 回路 D） |

> **万维钢的核心表述（意译）**：目标是为失败者准备的，系统是为成功者准备的。
> 这句话不是他的原创 —— 出自 Scott Adams 2013 年的 *How to Fail at Almost Everything and Still Win Big*。
> **万维钢做的是把它接上了概率论的地基**：因为长期结果是连乘的，所以"系统的几何增长率"才是真正的目标函数。

**记住这个非对称：均值由运气决定，增长率由系统决定。**
我们的直觉默认"期望值 = 我会拿到的"。**这条在非遍历系统里是错的。**

## §1 七个反直觉翻转

| # | 你以为 | 实际上是 | 为什么 |
|---|---|---|---|
| 1 | 想要好结果，就要死盯结果 | **盯结果会让你在每一次波动里做动作**，动作本身消耗掉正的期望 | 单次结果 = 运气 + 实力，信噪比极低。盯着噪声做决策，等于把随机数当成信号 |
| 2 | 有目标才有动力 | **目标达成即动力归零，人回到基线** —— 这就是"新年决心"的解剖结构 | 目标驱动的反馈是**负反馈**：偏差 → 动作 → 偏差消失 → 驱动力消失。系统没有自我维持项 |
| 3 | 胜率高才值得下注 | **胜率 30% 也可以是极好的机会**，只要上行/下行不对称（+10 / −1） | 期望值 = p × 幅度，不由 p 单独决定。见 §5.3 |
| 4 | 期望值为正就该玩，越大越好 | **期望值为正的赌局可以让你几乎必然破产** | 因为"必然破产"和"期望为正"是两个不同坐标系的事实。期望值对**人群**求平均，你活在**时间**里 |
| 5 | 成功者总结的方法能复制 | **他们大多是被运气选出来的**，方法常常是事后缝上去的叙事 | 幸存者偏差：你看到的是结果的条件分布 P(方法 \| 成功)，不是 P(成功 \| 方法) |
| 6 | 统计显著 = 有效 | **N 足够大时，任何微小差异都会显著** | p 值衡量"证据强度"，效应量衡量"差异大小"。这是两个正交的量，被混用了几十年 |
| 7 | 稳定靠控制，管得越细越稳 | **系统自带负反馈，你的干预是叠加在它上面的扰动** | 负反馈回路本来就在消差。你多加一层控制器，只增加了振荡与延迟 |

**其中第 2、4、6 条最容易被低估，也最有杠杆。**
第 4 条尤其反直觉 —— 它不是"赌博有害"这种道德劝告，它是**一个纯数学事实**，而且它推翻了经济学里"最大化期望效用"的默认设定。

## §2 核心区分：什么才算"系统"

全书最关键的重新定义：**系统 ≠ 复杂的计划表，系统 ≠ 每天打卡的清单。**
系统的定义只有一个：**一个能把动作转成反馈、并且能无限重复的结构。**

```
系统的成立条件：
  ① 有一个可重复的动作（不是一次性事件）
  ② 有明确的反馈信号（做对了会怎样，做错了会怎样）
  ③ 有下注规则（每次投入多少 —— 这一条最常被漏掉）
  ④ 没有吸收壁（破产、出局、死亡 —— 一旦碰到就永久停止重复）

缺任何一条：
  缺① → 那是项目，不是系统
  缺② → 那是习惯，不是系统（无法自我修正）
  缺③ → 那是赌，不是系统（迟早被遍历性杀死）
  缺④ → 那是定时炸弹，不是系统
```

**反例**：定一个"今年赚 100 万"的目标 → **不是系统**，它一次性、无重复结构、无下注规则。
**正例**：每周写一篇公开文章，用一个可测的反馈（完读率）调整写法，单篇投入设上限 → **这是系统**。它不承诺结果，它承诺**重复**。

> **关键推论**：系统的产出是**分布**，不是**数值**。
> 目标是给一个数；系统是给一条概率曲线。**你不能要"系统帮我赚 100 万"，你只能要"系统帮我把赚钱的概率提高一点"。**

### 目标 vs 系统（本书最著名的一组区分）

| | **目标（Goal）** | **系统（System）** |
|---|---|---|
| 时间结构 | 有终点，一次性的 | 无终点，持续的 |
| 反馈极性 | **负反馈**（消差 → 达成 → 停机） | **正反馈**（成功 → 资源 → 更容易成功）+ 内部负反馈（自我修正） |
| 失败定义 | 达不到就是失败 | 只有"停止运行"才叫失败 |
| 情绪结构 | 长期焦虑 + 短暂狂喜 | 几乎无情绪波动 |
| 面对运气 | **运气直接决定成败**（只有一两次抽样） | **运气被大数定律平均掉** |
| 典型例子 | 减 10 公斤、考上、融资到 B 轮 | 每天训练、持续输出、保持现金流为正 |
| 什么时候它错 | 需要**一次性大跳**的场合（见 §8） | 需要**快速集中资源**的场合 |

> **"目标是为失败者准备的"这句话是启发式，不是定理。**
> 精确版本是：**目标的抽样次数太少，所以它的结果由运气主导；系统的抽样次数足够多，所以它的结果由实力主导。**
> 因此：**在运气主导的领域用系统，在实力主导且窗口极短的领域用目标。**

### 三组必须拆开的词（本书的"重新定义"清单）

| 你以为是一个词 | 实际是两个 |
|---|---|
| **风险** | **风险（概率已知）** vs **不确定性（概率未知）** —— 前者可以算期望，后者只能算敞口 |
| **波动** | **好的波动（上行不对称）** vs **坏的波动（下行致死）** —— 波动不是敌人，**致命波动**才是 |
| **稳定** | **静态稳定（从不变化 = 脆）** vs **动态稳定（一直在微调 = 韧）** —— 塔勒布的"反脆弱"讲的正是这个 |

> **"金融世界的正态分布滥用"是本书最锋利的一根刺。**
> 如果收益率真的服从正态分布，日频 5σ 事件的理论概率约 **5.7 × 10⁻⁷**，
> 在 100 年的日频数据（约 25,000 天）里**期望出现 0.014 次** —— 也就是说，**大约七千年才有一次**。
> 而真实市场里，这种量级的单日波动**每隔几年就会出现一次**。
> **你不是遇到了一次奇迹，你是用错了分布。**

## §3 三根支柱与核心定理

### 支柱一：结果 = 运气 + 实力，两者的配比由领域决定

```
结果  =  运气分量  +  实力分量

领域的两端：
  纯运气领域    结果 ≈ 运气                      实力分量 ≈ 0
                （买彩票、单次掷骰、一年内的股价）
  纯实力领域    结果 ≈ 实力                      运气分量 ≈ 0
                （100 米跑、下棋、长跑选手的十年成绩）

中间地带才是真实世界：结果 ≈ α·实力 + (1−α)·运气
```

**万维钢的关键动作**：不要问"这件事里实力占多少"，要问 **"我要重复多少次，才能让运气分量被平均掉"**。

| 运气的方差 | 需要多少次重复才"靠实力说话" |
|---|---|
| 小（技能型：下棋、举重） | 几次 |
| 中（投资） | 几百到几千次 |
| 大（创业、演艺） | **可能你的一生都不够** —— 这时"重复次数"这个旋钮根本拧不动 |

> **"实力是运气的积分"** —— 这句话是本书最好的表述之一。
> 它的准确含义是：**实力 = 在长期重复中，正期望被累积、负方差被避免之后剩下的东西。**
> 一个有一点点正期望的人，如果能活足够多次，就必然赢过期望为零的高手。

### 支柱二：系统 = 动作 × 反馈 × 下注

```
        ┌──────────────────────────────────────┐
        │  动作（可重复）                       │
        │       ↓                              │
        │  结果（含运气）                       │
        │       ↓                              │
        │  反馈提取（把运气剥离，只留信号）        │
        │       ↓                              │
        │  规则修正（改下次的动作）               │
        │       ↓                              │
        │  下注规则（改下次投入多少）★ 最常被漏   │
        └──────────────────────────────────────┘
```

**下注规则为什么最关键**：因为它是**唯一决定你能不能活到"大数定律生效"那一刻**的东西。
动作可以错（改就是了），下注不能错（错了就出局）。

### 支柱三：系统的行为由反馈的极性决定

| | **正反馈回路** | **负反馈回路** |
|---|---|---|
| 行为 | 偏差被放大 | 偏差被消除 |
| 数学形状 | 指数 / 复利 / 相变 | 均衡 / 回归 / 均值回复 |
| 例子 | 复利、网络效应、马太效应、病毒传播 | 温度调节、套利抹平、竞争侵蚀超额利润 |
| 风险 | **临界点**（过了某点就不可逆） | 过度稳定 → 脆弱（不能承受冲击） |
| 该做什么 | 尽早进入，承受前期缓慢 | 不要干预，干预会增加振荡 |

> **马太效应的机制就是正反馈**：成功 → 资源 → 更大的成功。
> 这不是道德问题，是**回路极性**问题。所以"赢家通吃"的行业里，竞争发生在**进入之前**，不在进入之后。

### ⭐ 核心定理

> ## 不要最大化 **E[X]**，要最大化 **E[log X]**。
> ## 因为长期结果由**几何增长率**决定，不由**算术期望**决定。
>
> 而这两者在非遍历系统里，**会给出方向相反的答案。**

展开成可操作的等式：

```
算术期望（错的）：  μ  = Σ pᵢ · rᵢ              ← 对"人群"求平均
几何增长率（对的）：g  = Σ pᵢ · ln(1 + f·rᵢ)    ← 对"时间"求平均

只要 f 不为零，两者就不相等。
只要存在 rᵢ = −100%（全损），g 就是 −∞，无论 μ 多大。
```

**这跟前面几份的核心定理是同构的**：

| 模型 | 核心定理 | 形式 |
|---|---|---|
| 小岛经济学 | 财富 = 产能；货币/债务 = 索取权 | 实物 vs 凭证 |
| 博弈论 | 内卷 = 帕累托最优 − 纳什均衡 | 两个点的距离 |
| 乌合之众 | 群体意见 = 最响意见 ≠ 平均意见 | 两个量的错位 |
| **佛畏系统** | **长期结果 = 几何增长 ≠ 算术期望** | **两种"平均"的错位** |

**四本都在讲同一件事：你知道的那个"平均值"，和你实际会得到的那个数，不是同一个东西。**

## §4 四条因果回路

### 回路 A：复利自锁回路（正反馈）

```
       动作被执行 N 次
            ↓
       能力/资源 / 声望 ↑
            ↓
       下一次执行的成本 ↓（更熟练 / 更多人愿意配合）
            ↓
       单次产出 ↑
            ↓
       更愿意继续执行（动力 + 沉没成本 + 可见回报）
            ↓
       动作被执行 N+1 次（回到起点，且更强）
```

**自锁点**：回路里没有任何一环会自然刹车。
**唯一刹车**：**容量上限 / 边际收益递减**（这是内生的负反馈，不是外来干预）。
**注意**：这个回路前期极慢 —— 1% 日改进要 70 天才翻倍（见 §5.4），这就是**绝大多数人死在拐点之前**的原因。

> 实战含义：**正反馈系统的前期看起来像失败。**
> 你必须用"是不是在重复"来判断，而不是用"最近有没有回报"来判断。

---

### 回路 B：套利抹平回路（负反馈 —— 系统的天然刹车）

```
       某个动作的超额回报被发现
              ↓
       更多人进入，供给增加
              ↓
       超额回报被摊薄
              ↓
       边际参与者退出
              ↓
       供给减少，回报部分恢复
              ↓
       （收敛回均衡，不再继续放大）
```

**这是负反馈，它带来稳定。**
**关键参数是"信息传播速度"和"进入门槛"**：
- 传播越快、门槛越低 → 抹平越快 → 超额回报的**寿命越短**
- 这直接推出一句操作结论：**任何"公开分享的高收益方法"，在它被分享的那一刻就已经在衰减。**

> **推论**：负反馈系统里，**超额收益不是能力，是时差。**
> 你要找的不是"永远有效的方法"，是"**我能比别人早进入多久**"。

---

### 回路 C：遍历性毁灭回路（正反馈 + 吸收壁）

```
       单次下注比例 f 过大
            ↓
       某一次亏损幅度触及 −100%（或接近）
            ↓
       ★ 资本归零 → 无法继续下注
            ↓
       后续所有正期望的机会与你无关
            ↓
       你停留在一个永久状态（回到起点？不 —— 起点的门已经关了）
```

**自锁点**：★ **破产是吸收态（absorbing state）**。一旦进入，回路终止，时间不再为你提供任何"平均"。
**唯一刹车**：**下注比例上限**（Kelly 上限，见 §5.2）。

> **这是全书最重要的一条回路，因为它是唯一一条会导致"游戏结束"的。**
> 其他回路的代价是"慢"，这条回路的代价是"死"。
> **慢可以补救，死不能。**
> 所以决策的第一问永远不是"这个期望值多高"，而是 **"最坏情况下我还活着吗"**。

---

### 回路 D：目标驱动回路（负反馈 —— 为什么目标会自我熄灭）

```
       设定目标
          ↓
       当前状态与目标的差距（消差信号）
          ↓
       采取行动
          ↓
       差距缩小
          ↓
       ★ 差距趋近于零 → 驱动力趋近于零
          ↓
       行动停止
          ↓
       状态回落到基线（惰性 / 环境压力）
          ↓
       差距重新出现（但你已经消耗完了意志力预算）
```

**自锁点**：★ **这个回路的自锁点就是"达成"本身。**
**唯一刹车（把它从负反馈改成正反馈的唯一办法）**：**把反馈信号从"距离目标还有多远"换成"这个动作这一轮是否被执行了"。**

> **这就是"目标 → 系统"转换的严格含义**：
> 不是换一个更宏大的目标，是**换掉反馈信号的来源**。
> 目标让反馈来自"结果"，系统让反馈来自"执行"。
> 结果信号的方差极大且延迟极长；执行信号的方差几乎为零且即时可得。
> **用低方差的信号驱动，是唯一能长期运行的方式。**

## §5 六组算术

### 5.1 遍历性：期望值为正，但你依然会归零（最锋利的一组）

**赌局**：每次以 50% 概率 +50%，50% 概率 −40%。单次投入全部本金。

**先算算术期望**：

```
期望倍数 = 0.5 × 1.5  +  0.5 × 0.6
         = 0.75 + 0.30
         = 1.05
```

→ 每玩一轮，平均赚 **5%**。**看起来是台印钞机。**

**再算实际会发生什么。** 因为总收益是**连乘**而不是连加，10 轮之后：

```
最可能的情形（恰好 5 赢 5 输）：
  1.5⁵ × 0.6⁵  =  7.59375 × 0.07776  =  0.59049

也就是：本金变成 59%，亏掉 41%。
```

这个"最可能的情形"出现的概率 = C(10,5)/2¹⁰ = 252/1024 = **24.6%**。

**更狠的一步**：算算有多少比例的路径最终是赚钱的。

```
要赚钱，需要 1.5^k × 0.6^(10−k) > 1
   →  (1.5/0.6)^k > 1/0.6¹⁰ = 165.38
   →  2.5^k > 165.38
   →  k ≥ 6   （即 10 次里至少赢 6 次）

P(赢 6 次及以上) = (210+120+45+10+1)/1024 = 386/1024 = 37.7%
```

| 轮数 | 结果（恰好一半赢） | 相对本金 |
|---|---|---|
| 10 | 0.9⁵ = **0.59049** | −41.0% |
| 50 | 0.9²⁵ = **0.07179** | −92.8% |
| 100 | 0.9⁵⁰ = **0.005153** | −99.48% |
| 500 | 0.9²⁵⁰ = **3.6 × 10⁻¹²** | 基本归零 |
| 1000 | 0.9⁵⁰⁰ = **1.32 × 10⁻²³** | 事实上不存在 |

**而精确的每轮几何增长率**：

```
√(1.5 × 0.6) = √0.9 = 0.948683  →  每轮 −5.13%
```

> ## 结论
> **算术平均告诉你每轮 +5%；几何平均告诉你每轮 −5.13%。**
> **在时间维度上，你实际经历的是后者。**
> 原因不神秘：+50% 和 −40% 不是对称的。**跌掉 40% 后，需要涨 66.7% 才能回本。**
> 这就是"遍历性"：**"很多人同时各玩一次"的平均值，和"一个人连续玩很多次"的时间平均值，是两个不同的数。**
> 你只有一个时间序列，所以只有后者对你有意义。

**直接搬到现实上**：
```
任何"看起来期望为正"的高波动策略（杠杆、重仓单一标的、押注小概率大赔率）
   —— 只要单次下注比例足够大 ——
   长期结果 = 必然归零，且期望值为正。
```
**所以问题从来不是"这个赌局好不好"，而是"我该下注多少"。这就是 §5.2。**

### 5.2 凯利公式：全押为什么是数学上的自杀

**问题**：一个赌局，赢面 p = 55%，输了赔掉全部注码，赢了 1 赔 1（净赔率 b = 1）。你的胜率优势是真实的。**该下注多少？**

**凯利公式**：

```
f* = p − q/b        （p = 胜率，q = 败率 = 1−p，b = 净赔率）

f* = 0.55 − 0.45/1 = 0.10
```

→ **最优下注比例 = 本金的 10%。**

**为什么不是"越多越好"？** 因为要最大化的是几何增长率：

```
g(f) = 0.55 · ln(1 + f) + 0.45 · ln(1 − f)
```

| 下注比例 f | 每局的几何增长率 g | 100 局之后 |
|---|---|---|
| 5%（半凯利） | 0.003753 → **+0.375%** | **1.455 倍**（+45.5%） |
| **10%（满凯利 f\*）** | 0.005008 → **+0.501%** | **1.650 倍**（+65.0%） ★最优 |
| 20%（2 倍凯利） | −0.000138 → **−0.014%** | **0.99 倍**（≈0%） ← 归零线 |
| 30%（3 倍凯利） | −0.016203 → **−1.62%** | **0.198 倍**（−80.2%） |
| 100%（全押） | 0.55·ln2 + 0.45·ln0 → **−∞** | **必然爆仓** |

**归零线在 f ≈ 20%，也就是 2 倍凯利处。**

**现在看那个 97 倍的鸿沟。**

f = 0.30 时，每一局押上 30% 本金，而每一局的期望收益率是 +10%（0.55 − 0.45 = 0.10），
所以**每局的算术期望收益 = 0.30 × 0.10 = +3%**：

```
算术期望推演：  1.03¹⁰⁰ = 19.219 倍   ← "期望上"你赚了 19 倍
几何实际结果：  0.1978 倍            ← 实际上你亏掉 80%

差距 = 19.219 / 0.1978 ≈ 97 倍
```

> ## 结论
> **在同一个游戏上，算术期望说"赚 19 倍"，几何现实说"亏 80%"。**
> **两者都算对了。只是它们描述的是两个不同的东西。**
> 全押（f = 1）之所以是自杀，不是因为"运气不好会输光"——
> 是因为 **ln(0) = −∞**：只要有一次亏损，你就永远出局，**后面所有的正期望都与你无关**。
> 而 55% 胜率下，100 局里至少输一次的**概率是 1 − 0.55¹⁰⁰ ≈ 1**（0.55¹⁰⁰ ≈ 10⁻²⁶）。
>
> **下注比例是唯一一个"越界就不可逆"的旋钮。这就是为什么它是系统四要件里最不能漏的一条。**

### 5.3 不对称收益：胜率 30% 也能是极好的机会

**机会**：下行 **−1**，上行 **+10**。胜率只有 **30%**。

**期望值**：

```
E = 0.30 × (+10)  +  0.70 × (−1)
  = 3.0 − 0.7
  = +2.3        → 每投入 1 单位，期望收回 2.3 单位
```

**盈亏平衡胜率**（令期望为 0）：

```
p × 10 = (1 − p) × 1
10p = 1 − p
11p = 1
p* = 1/11 = 9.09%
```

→ **实际胜率 30% 是平衡点的 3.3 倍。安全边际极大。**

**但真正的力量在于"可以重复很多次"**：

| 独立机会次数 | 至少中一次的概率 | 期望中几次 | 期望总盈亏（每次 1 单位） |
|---|---|---|---|
| 1 | 30.0% | 0.3 | +2.3 |
| 5 | 1 − 0.7⁵ = **83.2%** | 1.5 | +11.5 |
| 10 | 1 − 0.7¹⁰ = **97.18%** | 3.0 | +23.0 |
| 50 | 1 − 0.7⁵⁰ = **99.999998%** | 15.0 | +115 |
| 100 | 1 − 0.7¹⁰⁰ ≈ **1 − 3.23×10⁻¹⁶** | 30.0 | +230 |

**最坏情况**（一次都不中）：

| 次数 | 全输的概率 | 最大亏损 |
|---|---|---|
| 10 | 0.7¹⁰ = **2.82%** | −10 |
| 50 | 0.7⁵⁰ = **1.8 × 10⁻⁸** | −50 |
| 100 | 0.7¹⁰⁰ = **3.23 × 10⁻¹⁶** | −100 |

> ## 结论
> **只要"下行有限、上行开放"且"可以重复很多次"，你的胜率就变得几乎不重要。**
> 但注意这里藏着一个致命前提：**上面每一行我都假设每次只押 1 个单位，而且你总共有远超 100 个单位的本金。**
> 如果你有 10 个单位，押 10 次每次 1 个单位，最坏情况你就出局了 —— **2.82% 的概率触发出局。**
> **不对称收益的价值，只有在"下注足够小"的前提下才成立。** 否则 §5.1 会来收账。
>
> **所以正确的读法是**：不对称收益 × 小下注 × 多次重复 = 系统。
> **三者缺一，它就退化回赌博。**

### 5.4 复利与临界点：1% 的日改进，拐在哪里

**设定**：每天改进 1%，即乘以 1.01。

| 天数 | 结果 | 里程碑 |
|---|---|---|
| 1 | 1.01 | — |
| **70** | **2.0068** | **翻倍** ← 第一个拐点 |
| 100 | 2.705 | |
| 232 | **10.06** | **10 倍** |
| 265 | 13.969 | |
| 365 | **37.783** | 一年 37.8 倍 |
| 463 | **100.18** | **100 倍** |

**看懂这三个数，你就看懂了正反馈系统的结构**：

```
从  1 倍 到  10 倍   用了 232 天
从 10 倍 到 100 倍   用了 231 天   ← 同样长的时间，但多赚了 90 个原始单位

换句话说：
  第一个 232 天，赚了 9 倍
  第二个 231 天，赚了 90 倍
  → 同样的努力，后一段的产出是前一段的 10 倍
```

**再看"临界点"长什么样**。把一年切成两段：第 1—265 天走完 0 → 13.969（占 73% 的时间），
最后 100 天从 13.969 走到 37.783 —— 即 **(37.783 − 13.969) / 37.783 = 23.814 / 37.783 = 63.0%**。

> **27% 的时间，创造了 63% 的价值。**
> 这就是"临界点"的真相 —— 它不是某一天突然发生的奇迹，
> **它是连续复利在后期必然呈现的形状：绝大部分产出集中在最后一段。**

**反向的对称性**（这也是它可怕的地方）：

```
0.99³⁶⁵ = 0.02552        →  一年后退到 2.55%，−97.4%
1.01³⁶⁵ / 0.99³⁶⁵ = 37.783 / 0.02552 = 1480.7

即：每天 +1% 和每天 −1%，一年后相差约 1480 倍。
```

**和线性增长的对比**：

```
线性：  1 + 0.01 × 365 = 4.65
复利：  1.01³⁶⁵ = 37.783
比值：  8.1 倍
```

> ## 结论
> **正反馈系统里，"坚持到拐点"是全部的胜负手，因为拐点之前的产出低得令人绝望。**
> 1% 日改进在 **第 70 天**才翻倍，在 **第 232 天**才 10 倍。
> **绝大多数人放弃在第 30—60 天之间 —— 也就是曲线最平的那一段。**
> 所以对系统的判断不能靠"最近有没有回报"，只能靠"**还在不在重复**"。
> 反过来，**任何负向的 1% 也复利**。习惯的负向版本同样需要 70 天才看得出后果 —— 这就是为什么坏习惯总是被发现得太晚。

### 5.5 基础概率：99% 准确的检测，阳性也只有 1% 是真

**问题**：一种病的患病率是 **1/10000**。检测的准确率是 **99%**（灵敏度 99%，特异度 99%）。
**你测出阳性。你真正患病的概率是多少？**

**用 100 万人来算**：

```
总人口                    1,000,000
患病人数      = 1/10000 × 1,000,000 =        100
未患病人数    = 1,000,000 − 100     =    999,900

真阳性 = 100     × 0.99 =       99
假阳性 = 999,900 × 0.01 =    9,999
—————————————————————————————————————
总阳性                     =   10,098

P(患病 | 阳性) = 99 / 10,098 = 0.009804 = 0.98%
```

> **约等于 1%。**

**为什么这么低？** 因为假阳性比真阳性多 **9,999 / 99 = 101 倍**。
不是检测不准，是**底数（基础概率）太小**。

**贝叶斯似然比版本**（更便于心算）：

```
先验几率 = (1/10000) / (9999/10000) = 1/9999 ≈ 1.0 × 10⁻⁴
阳性似然比 LR⁺ = 灵敏度 / (1 − 特异度) = 0.99 / 0.01 = 99

后验几率 = 99 / 9999 = 0.0099010
后验概率 = 0.0099010 / 1.0099010 = 0.009804 ≈ 0.98%   ✓ 一致
```

**做第二次、第三次独立检测**：

| 检测次数 | 似然比 | 后验几率 | **后验概率** |
|---|---|---|---|
| 1 次阳性 | 99 | 99/9999 = 0.00990 | **0.98%** |
| 2 次阳性 | 99² = 9,801 | 9801/9999 = 0.98020 | **49.5%** |
| 3 次阳性 | 99³ = 970,299 | 970299/9999 = 97.04 | **98.98%** |

**如果把患病率换成 1/1000（提高 10 倍）**：

```
患病 1,000 → 真阳性 990；未患病 999,000 → 假阳性 9,990；总阳性 10,980
P = 990 / 10,980 = 9.02%
```

> ## 结论
> **基础概率提高 10 倍，阳性预测值从 0.98% 涨到 9.02%（约 9 倍）。**
> **信息从哪来，比信息本身长什么样更重要。**
> "99% 准确"这个数字单独看毫无意义 —— 它必须和**底数**一起看。
>
> **这就是为什么"一个惊人的新研究"通常不改变任何东西**：
> 你原来的信念就是你的先验；如果先验几率是 1/9999，那么一个 99 倍强度的证据，
> 也只是把它推到 1% 而已。
> **要真正改变判断，你需要的是"多次独立且强力的证据"，而不是"一次强力的证据"。**

### 5.6 效应量："统计显著"和"有意义"是两个量

**Cohen's d** 是把差异标准化之后的效应量：

```
d = (M₁ − M₂) / SD_pooled

经验刻度： d = 0.2 小    d = 0.5 中    d = 0.8 大
```

**案例**：一项研究，每组各 **10,000 人**，用的是标准差 **15** 的标准化测试。
观察到的组间差异 = **1 分**。

```
d = 1 / 15 = 0.0667            → 远小于"小"的门槛

差异的标准误 = 15 × √(2/10000) = 15 × 0.014142 = 0.21213
t = 1 / 0.21213 = 4.714
p ≈ 2.4 × 10⁻⁶
```

**结果**：p < 0.00001，**"高度显著"**。
效应量 0.0667，**"几乎不可见"**。

**用"共同语言效应量"看这 1 分有多小**（随机抽一个实验组的人，胜过随机抽一个对照组的人的概率）：

```
CLES = Φ(d / √2)

d = 0.0667 →  Φ(0.04714) = 51.9%   ← 比抛硬币好 1.9 个百分点
d = 0.5    →  Φ(0.35355) = 63.8%
d = 0.8    →  Φ(0.56569) = 71.4%
```

**再做一个决定性的对照**：同样的 1 分差异，换成 **每组 20 人** 的小样本研究。

```
标准误 = 15 × √(2/20) = 15 × 0.31623 = 4.743
t = 1 / 4.743 = 0.211
p ≈ 0.83      →  完全不显著
```

> ## 结论
> **同一个效应，在 N=10,000 时 p ≈ 0.0000024，在 N=20 时 p ≈ 0.83。**
> **p 值不是关于"这个效应存不存在"的陈述，它是关于"你的样本有多大"的陈述。**
> 只要样本足够大（每组 10,000 人，在 80% 检验力下能稳定检出低至 **0.594 分** 的差异，即 **d ≈ 0.04**），
> 你可以把任何微不足道的差异做成"高度显著"。
>
> **反过来同样致命**：要可靠地检出 d = 0.0667 这种效应，每组需要
> ```
> n = 2 × (1.96 + 0.8416)² / d² = 15.698 / 0.004449 ≈ 3,530 人/组
> ```
> **真实世界里多数研究的样本量远低于此** —— 所以真实世界的常态不是"发现小效应"，
> 而是"**发现不存在的大效应**"（低检验力 + 发表偏倚 = 效应量被系统性高估）。
> Open Science Collaboration 2015 年在 *Science* 上报告：100 项心理学研究的重复实验里，
> 原研究 **97%** 显著，重复实验只有 **36%** 显著；平均效应量从 **r = 0.403 腰斩到 0.197**。
> **不是所有科学都不可信，是"统计显著"这四个字承载不了你给它的信任。**

## §6 策略与决策表

**用法**：先判断你面对的是**哪一类系统**（正反馈 / 负反馈 / 有吸收壁 / 一次性），再取对应动作。

| 场景 | 该做什么 | 机制依据 |
|---|---|---|
| **我要开始一件新事** | 先问"这个动作我能重复多少次"。少于 50 次的，别用系统论包装它 —— 那是一锤子买卖 | 支柱一：重复次数决定运气分量 |
| **我在设计一个习惯/事业** | 把反馈信号从"结果"改成"是否执行"。**只监测执行率，不监测结果** | 回路 D：目标驱动的负反馈会自我熄灭 |
| **我在一个正反馈领域（复利型）** | 尽早进入，接受前 70 天的"看起来没效果"，**不要在曲线最平处退出** | §5.4：1% 日改进第 70 天才翻倍 |
| **我在一个负反馈领域（套利型）** | 不要指望方法长期有效。**找"时差"，不找"永动机"**。公开分享即开始衰减 | 回路 B：超额收益会被抹平 |
| **我在决定下注多少** | 用 Kelly：`f* = p − q/b`，然后**取一半**（半凯利），因为你估的 p 一定偏高 | §5.2：f ≈ 2×Kelly 处几何增长归零 |
| **我看到一个高期望值的机会** | 第二问永远是"最坏情况我还活着吗"。**先定破产线，再定仓位** | 回路 C：破产是吸收态，不可逆 |
| **我要评估一个"科学结论"** | 看三件事：① 效应量 d 是多少 ② 样本量多大 ③ 是否独立重复过 | §5.6：显著 ≠ 有意义 |
| **我得到一个阳性检测/信号** | 先问基础概率。**没有先验的概率是无意义的** | §5.5：99% 准确 + 1/10000 患病率 = 1% |
| **我在总结一个成功者的方法** | 先问：他背后有多少个失败的同类？**能想出来的分母，通常是最小分母** | §1 第 5 条：幸存者偏差 |
| **我连续赢了很多次** | 检查你是不是正在正反馈的**临界点附近** —— 崩塌也是正反馈，只是反向向下 | 支柱三：极性决定形状，不决定方向 |
| **我面对无法重复的一次性决策** | **这时目标思维是对的**。集中资源、定死截止、接受运气主导 | §8 边界① |
| **我想提高长期胜率** | 唯一可持续路径：**提高重复次数 + 降低单次方差**，不是提高单次胜率 | 核心定理：g = Σ p·ln(1+fr) |

### 两条反直觉提醒

> **① "系统胜过目标" 是启发式，不是定理**
> 它在**可以大量重复**的领域极其正确（投资、写作、健身、技能积累、客户关系）；
> 但在**窗口极短、必须一次完成**的场合是错的：手术、高考、融资谈判、抢救。
> 这些场合的正确做法恰恰是**集中资源打一次**，因为在你的时间尺度内没有第二次抽样。
> **判据只有一个：这个决策，我这辈子能重复几次？**
> - 能重复 100 次以上 → 系统思维，优化几何增长
> - 只能重复 1—3 次 → 目标思维，优化单次成功概率，并且**尽量降低下注**
>
> **把这两个搞反，是这本书最大的误用方式。**

> **② 波动不是敌人，"致命波动"才是**
> 塔勒布-万维钢这条线真正的意思不是"要稳定"，而是：
> ```
> 好的波动：下行有底，上行开放   →  你希望它越大越好
> 坏的波动：下行无底，上行有顶   →  你希望它越小越好
> ```
> **同样是方差，符号不一样。**
> 所以"分散投资"的目的不是降低方差（那是教科书说法），
> 而是**确保任何单一冲击都不能把你推过吸收壁**。
> **"活下来"是一个约束条件，不是一个优化目标。** 这是本书全部策略的第一性约束。

## §7 八个现场检验

**拿这八条去扫任何一个"该不该做/该做多久/该下多少"的决策。**

```
① 重复检验    这个动作，我这辈子能重复多少次？
   → 少于 10 次用目标思维；多于 100 次才配谈系统。

② 信号检验    我用来判断"做得好不好"的信号，是执行信号还是结果信号？
   → 只监测结果，说明你已经在回路 D 里了。

③ 拐点检验    我坚持了多少天？这条曲线在这个阶段本来应该长什么样？
   → 不到 70 天不要用"没效果"下结论。

④ 吸收壁检验  最坏情况下，我还会不会留在牌桌上？
   → 会出局的选项，无论期望值多高，一律先砍掉。

⑤ 仓位检验    我的下注比例，是不是超过了 Kelly 给出的 f*？
   → 超过 2f* 就是负增长；等于 1 就是迟早归零。

⑥ 基础概率检验 在拿到这个"新证据"之前，我的先验是多少？
   → 说不出先验，就说明这个证据改变不了你的判断。

⑦ 分母检验    这个成功案例背后，和我做同样事情的人有多少，失败的有多少？
   → 分母越大，这个"方法"越可能只是幸存者的叙事。

⑧ 效应量检验  "显著"的效应有多大？用 d 表示是多少？比抛硬币好多少个百分点？
   → d < 0.2 的"显著"，在个人决策层面约等于噪声。
```

## §8 诚实边界：这本书什么时候会骗你

**这一节和前面同样重要。万维钢是一流的译介者，但这本书有明确的、可指认的局限。**

| # | 局限 | 具体问题 | 修正 |
|---|---|---|---|
| 1 | **"系统胜过目标"是启发式，不是定理** | Scott Adams 的 "Goals are for losers" 是一句漂亮口号，**在需要一次性大跳的领域（手术、考试、招标、危机公关、创业的关键一轮）完全失效** | 用**重复次数**做判据：能重复 ≥100 次 → 系统；≤3 次 → 目标。**把口号降级为条件性启发式** |
| 2 | **大量使用"科学表明"，但引用层级偏低** | 书中证据链常常是"某本流行科学书 → 某个实验"，而**不是一手论文**。二手转述会丢失前提条件、效应量和样本量 | 见到"研究表明"，必须追问：**原文的 d 是多少？N 是多少？重复过没有？**（这正是 §5.6 存在的理由） |
| 3 | **幸存者偏差在"高手方法论"类内容中系统性存在** | 任何"成功者都做 X"的归纳，都没有计算分母。**失败者里做 X 的比例可能一样高甚至更高** | 只接受**有人算出过分母**的结论。个人经验叙事一律当作假说 |
| 4 | **部分内容随新证据已经过时** | 书中引用的若干心理学与行为经济学结论（如某些启动效应、意志力耗竭、部分具身认知结果）在后来的重复实验中**效应量大幅缩水甚至消失** | 把 2010—2016 年的心理学结论当作**默认需要打折**的证据。开放科学革命之后的标准更严 |
| 5 | **概念原创性低，且整合时容易抹平分歧** | 本书把 Scott Adams、Taleb、Kahneman、Peters、Thorp 的东西并置，但它们**彼此并不完全兼容**（例如 Taleb 反对 Kelly 的部分应用；Kahneman 的框架与理性期望值最大化直接冲突） | 读的时候要**分开来源看**，不要当成一个自洽体系。下表给出对照 |
| 6 | **"遍历性"的通俗版本容易被滥用** | 用遍历性论证"任何杠杆都是错的"，是把一个**数学条件**当成了**道德禁令**。遍历性说的是"时间平均 ≠ 集合平均"，**它不排除适度杠杆下的正几何增长** | 回到公式本身：`g = Σ p·ln(1+fr)`。**只要 f 在 Kelly 之内，杠杆可以有正增长。** 关键在 f，不在"杠杆"这个词 |
| 7 | **本书对"系统"的定义不够严格** | 万维钢没有给出"什么算系统、什么算目标"的可操作判据，导致几乎任何持续性活动都可以自称系统 | 用 §2 的四要件（可重复动作 / 反馈 / 下注规则 / 无吸收壁）自行判定。**缺一条就不叫系统** |
| 8 | **对结构性/制度性约束着墨太少** | 系统思维预设"你有调整自己动作的自由度"，但很多人的约束是结构性的（时间、资本、信息、健康），不是认知的 | 在应用前先问：**这是我不知道该怎么做，还是我做不到？** 后者不能用思维模型解决 |

### 概念出处对照表（本书的价值是翻译，不是原创）

| 书中概念 | 真正的源头 | 说过什么 / 什么关系 |
|---|---|---|
| **目标 vs 系统** | **Scott Adams**, *How to Fail at Almost Everything and Still Win Big* (2013) | "Goals are for losers. Systems are for winners." 万维钢把它接到概率论上 |

| **遍历性：期望值会骗你** | **Ole Peters**, *The ergodicity problem in economics*, **Nature Physics** (2019)；Peters & Gell-Mann (2016) | 时间平均 ≠ 集合平均。**这是全书最硬的一块地基，也是最常被误读的** |

| **"凡夫畏果，菩萨畏因，佛畏系统"** | 佛家用语的**重写**，作为全书框架由万维钢提出 | 原始的佛教表述里没有"系统"这个词。**这是他的包装，不是古义** |

> ### 一句话总结这本书的性质
> **它是一本优秀的"思维工具导览"，不是一本"原创理论著作"。**
> 最好的使用姿势是：**顺着它的推荐去读源头**。读完万维钢再读 Taleb、Peters、Kelly 原文，
> 你会发现问题被讲得更严格，也更有边界。**把导览当终点，是把地图当成领土。**

## §9 一页纸速查

```
┌──────────────────────────────────────────────────────────────┐
│  核心公式                                                     │
│                                                              │
│    畏果 → 优化结果   畏因 → 优化动作   佛畏系统 → 优化规则      │
│                                                              │
│    单次结果 = 运气 + 实力                                     │
│    长期结果 = ∏(1 + f·rᵢ)      ← 连乘，不是连加               │
│                                                              │
│    ★ 不要 max E[X]，要 max E[log X]                          │
│      （算术期望对人群求平均，几何增长对时间求平均）             │
└──────────────────────────────────────────────────────────────┘

【系统四要件】 ①可重复动作 ②明确反馈 ③下注规则 ④无吸收壁
               缺一条就不叫系统：缺①是项目 缺②是习惯 缺③是赌 缺④是炸弹

【七个翻转】
  盯结果          盯结果 = 在噪声里做动作，方差吃掉均值
  目标给动力      目标达成即动力归零（负反馈消差）
  胜率高才行      30% 胜率 + 不对称（+10/−1）就是好机会
  期望为正就玩    期望为正可以让你必然破产（**遍历性**）
  成功可复制      你看到的是 P(方法|成功)，不是 P(成功|方法)
  显著=有效       大 N 下任何微小差异都显著（**效应量 ≠ p 值**）
  控制才稳定      系统自带负反馈，你的干预是额外扰动

【四条回路】
  A 复利自锁   动作 → 资源↑ → 成本↓ → 更愿做 → 更多次   （唯一刹车：边际递减）
  B 套利抹平   超额收益 → 竞争者涌入 → 被摊薄 → 均衡     （负反馈：收益是时差，不是能力）
  C 遍历毁灭   f 过大 → 触及 −100% → ★出局 → 永久停在吸收态（刹车：Kelly 上限）
  D 目标熄火   目标 → 消差 → 差归零 → ★动力归零 → 回落    （刹车：把反馈信号换成「执行」）

【六组算术】
  ★ 遍历性     +50%/−40% 各半：算术期望 ×1.05（+5%/轮）
                最可能结果 0.9⁵ = 0.590（−41%）
                100 轮 → 0.9⁵⁰ = 0.00515（−99.5%）｜500 轮 → 3.6×10⁻¹²
                赚钱路径只占 37.7%（需 10 局赢 6 局以上）
                几何增速 = √0.9 = 0.9487 → 每轮 −5.13%
  ★ 凯利       p=0.55, b=1 → f* = 0.55 − 0.45/1 = 0.10（押 10%）
                f=0.10 → +0.501%/局，100 局 ×1.65
                f=0.20 → −0.014%/局（归零线，2×Kelly）
                f=0.30 → −1.62%/局，100 局 ×0.198（亏 80%）
                 而算术期望说 1.03¹⁰⁰ = ×19.2  → 差 97 倍
                f=1.00 → ln0 = −∞，必然爆仓
  ★ 不对称     −1 / +10，胜率 30% → E = +2.3，平衡胜率仅 9.09%
                10 次至少中 1 次: 97.2% ｜50 次: 99.999998% ｜100 次: 1−3.2×10⁻¹⁶
                前提：**每次下注必须足够小**，否则 §5.1 来收账
  ★ 复利       1.01ⁿ：70 天 ×2 ｜232 天 ×10 ｜365 天 ×37.8 ｜463 天 ×100
                第 265→365 天（27% 时间）贡献全年价值的 63%
                0.99³⁶⁵ = 0.0255；1.01³⁶⁵/0.99³⁶⁵ = 1481 倍
  ★ 基础概率   患病率 1/10000，检测 99% 准：
                真阳 99 ｜假阳 9999（101 倍）｜P(患病|阳性) = 99/10098 = 0.98% ≈ 1%
                两次阳性 → 49.5% ｜三次阳性 → 98.98%
                患病率提高 10 倍 → 后验 9.02%（约 9 倍）
  ★ 效应量     每组 10,000 人，SD=15，差异 1 分 → d = 0.067，t = 4.71，p ≈ 2.4×10⁻⁶
                共同语言效应量 Φ(0.047) = 51.9%（比抛硬币好 1.9 个点）
                同样差异在每组 20 人 → t = 0.21，p = 0.83（不显著）
                ★ 同一个效应：N 大 → 「高度显著」；N 小 → 「无结果」

【八个检验】
  ①重复   能重复多少次？        ②信号   监测执行还是结果？
  ③拐点   够 70 天了吗？         ④吸收壁 最坏情况还在牌桌上吗？
  ⑤仓位   超过 f* 了吗？         ⑥先验   拿证据前我信多少？
  ⑦分母   失败者有多少？         ⑧效应量 d 是多少？比抛硬币好几点？

【边界】
  ⚠️ 「系统胜过目标」是启发式 —— 判断标准是重复次数，≤3 次请用目标思维
  ⚠️ 引用多为流行科学书而非一手论文 —— 追问 d、N、是否重复过
  ⚠️ 幸存者偏差普遍存在 —— 只接受算过分母的结论
  ⚠️ 部分心理学证据已过时（2010—2016 一批结论重复后缩水）
  ⚠️ 遍历性常被滥用成「杠杆一律禁止」 —— 回到公式，关键在 f 不在杠杆
  ⚠️ 概念原创性低 —— 价值在翻译；**顺着它去读源头**
  ★ 描述 ≠ 保证。这本书给你的是「怎么活足够多次」，不是「怎么保证赢」

【一句收尾】
  你无法优化结果，因为结果里裹着运气。
  你能优化的只有两件事：
  **这个动作能不能被重复，以及每次投入多少。**
  前者决定大数定律会不会来帮你，
  后者决定你能不能活到它来的那一天。
```
