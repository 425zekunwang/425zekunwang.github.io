## §0 一句话模型

> ## 营销不是"把东西卖出去"，而是**让推销变得多余**。
> ## 它的全部工作，是把**顾客要办的事**翻译成一个**可交付、可定价、可复购**的东西；
> ## 并且在两个数上兑现：**CLV 与 CAC**。

写成式子：

```
营销 = 选需求（STP） → 造价值（4P，且四个 P 必须自洽） → 使推销多余
盈利判据：  CLV ≥ 3 × CAC
```

**这是全书的发动机。** 它一次解释掉四个常见误解：

| 常见说法 | 用模型一句话解开 |
|---|---|
| "营销就是打广告、搞促销" | 那只是 4P 里的第 4 个 P 的一部分。**营销的 90% 发生在广告之前**——先决定服务谁、不服务谁 |
| "东西好自然有人买" | "好"是**卖方坐标系**里的词。顾客用的是**任务坐标系**。两个坐标系不重合时，"更好"不产生任何购买 |
| "顾客越多越好" | 只有 `CLV ≥ 3 × CAC` 的顾客才叫顾客。其余的叫**补贴对象** |
| "满足顾客需求" | 顾客会需求一切免费的东西。**营销的目标函数不是满意，是"可盈利地满意"** |

> **德鲁克的原话（科特勒反复引用）**：营销的目的是让销售变得多余；营销的目的是**如此深刻地理解和了解顾客，使得产品或服务自己把自己卖出去。**

**记住这个非对称：卖方的语言是名词（产品、品类、SKU），买方的语言是动词（解决、完成、避免）。**
这跟我们的直觉完全相反——我们以为顾客在比较产品，其实顾客在**比较"完成任务的方式"**。产品只是其中一种方式，而且通常不是唯一一种。

## §1 八个反直觉翻转

| # | 你以为 | 实际上是 | 为什么 |
|---|---|---|---|
| 1 | 营销 = 推销 + 广告 + 促销 | **营销的目的是消灭推销**；推销是营销失败后的补救成本 | 营销在**售前**决定"卖给谁、卖什么、值多少"；推销只是在**售后端**弥补前面三项没做对。推销成本越高，说明营销做得越差 |
| 2 | 产品更好，就应该赢 | **"更好"不进入顾客的比较集，"不同"才进入**。定位不是比谁更优，是比谁占了一个词 | 顾客的注意力是稀缺的、可分类的。无法被归类的产品等于不存在。"更好"若不能在某个词上被记住，等于零 |
| 3 | 好营销要满足所有顾客 | **STP 的本质是放弃**。不写放弃名单的细分，等于没有细分 | 资源有限 + 定位要求排他。试图服务所有人 → 对任何人都不特别 → 回到"无差别商品"，只能拼价格 |
| 4 | 降价能扩大市场，薄利多销 | **价格是定位信号**。降价改变的不是销量，是"你是谁" | 价格是 4P 里唯一一个**同时传递质量和档次信息**的变量。降价在顾客脑中替换的含义是"它原来不值那个价" |
| 5 | 顾客满意就会忠诚 | **"满意"不是二元量，阈值在"极度满意"**。满意到 4 分（5 分制）的顾客，流失率和 3 分差不多 | 满意—忠诚的关系在低转换成本行业近乎断裂。真正锁住顾客的是**转换成本 + 相对吸引力**，不是满意度分数 |
| 6 | 获客越多，增长越快 | **CAC 随规模单调递增**；且净增顾客的 CAC 会先于收入吃掉全部利润 | 人群按"意愿强度"排序。你总是先拿到最容易拿的人。第 100 万个顾客一定比第 1 万个贵 |
| 7 | 品牌就是 logo、VI、知名度 | **品牌是顾客头脑里的联想网络**（CBBE）。知名度只是最底层的一块砖 | 有知名度没联想 = 一个"听说过但说不出好在哪"的名字。这类品牌只能打价格战，因为它没占住任何一个词 |
| 8 | 4P 是四个可以单独调的杠杆 | **4P 是一个约束系统**。动一个，另外三个必须跟着动 | 高定价 + 频繁折扣 = 自我拆台；高端渠道 + 廉价包装 = 认知冲突。**最常见的营销失败不是某个 P 做错了，是四个 P 互相矛盾** |

**其中第 3、5、6 条最容易被低估，也最有杠杆。**
第 3 条决定你能不能被记住；第 5 条决定你的 CLV 分子；第 6 条决定你的 CAC 分母。

## §2 核心区分：这本书在重新定义哪四个词

科特勒做的不是发明新词，是**把四个日常词切出精确的内部结构**。跳过这一步，后面全是空转。

### 2.1 需求：需要 / 欲望 / 需求（Needs / Wants / Demands）

这是全书最基础、也最常被混为一谈的三层结构。

| | **需要 Need** | **欲望 Want** | **需求 Demand** |
|---|---|---|---|
| 定义 | 人类基本的匮乏状态 | 需要被文化与个性塑造成的**具体指向物** | 有购买力支撑的欲望 |
| 举例 | 口渴 | 想喝某个牌子、某种气泡感的饮料 | 今天口袋里这 6 块钱能买的那一瓶 |
| 谁创造了它 | 人性。**营销创造不了，也不该假装能** | 营销**深度参与**塑造 | 营销通过定价与分销**管理** |
| 可变性 | 几乎不可变（马斯洛式的基本缺失） | 高度可变，随潮流、文化、身份 | 随收入与价格快速波动 |
| 营销能做什么 | 只能利用，不能创造 | 定义方向：把同一个需要导向不同载体 | 决定"谁能把欲望转换成需求" |

> ## 营销不创造需要；营销决定需要往哪个方向变形，以及由谁来完成这个变形。

**三个直接推论：**

```
推论 1  广告卖的不是"需求"，是"同一需求下的某一种解法"。
        → 所以"我们创造了一个新需求"通常翻译为："我们给一个旧需要找了个新载体。"
推论 2  需求 = f（欲望, 购买力）→ 定价就是需求管理，不是财务动作。
推论 3  当需要（Need）本身没被满足时，任何品牌说服都是无效投入。
        → 饿的人不在乎品牌。这是所有"高端定位进下沉市场"失败的第一原因。
```

### 2.2 产品：三个层次（以及它们为什么会塌陷）

顾客买的从来不是那个"东西"。

| 层次 | 内容 | 顾客心里的话 | 汽车 |
|---|---|---|---|
| **核心利益** | 顾客真正买的问题解决方案 | "我要安全地从 A 到 B" | 位移与安全 |
| **实际产品** | 形式、质量、特征、设计、品牌名、包装 | "它长什么样、叫什么、什么规格" | 车型、动力、外观 |
| **附加产品** | 安装、配送、质保、售后、信贷、培训 | "买完之后我额外得到什么" | 保修、金融方案、道路救援 |

> **差异化几乎全部发生在第三层。** 当核心利益和实际产品都被同质化时，附加产品是唯一的战场。
> **但附加产品会全部变成期望产品。** 今天免费赠送的质保，是十年前的高端服务。昨天的惊喜 = 今天的标配 = 明天的底线。

```
第三层的优势是「租来的」，不是「买来的」。
租期 = 竞争对手的复制周期。
```

**科特勒的完整版是五个层次**（加"期望产品"和"潜在产品"），但最有操作价值的就是上面的三段：
**核心层决定你有没有资格进场，形式层决定你有没有被比较的余地，附加层决定你能不能收溢价——而附加层会自动归零。**

### 2.3 品牌：CBBE 金字塔（Keller）

品牌不是资产表上的一个数字，是**顾客头脑里的一张联想网络**。它的结构是分层的，底层不牢则上层是幻觉。

```
        ┌── 4. 共鸣 Resonance ──────────── 忠诚 / 社群 / 主动拥护 / 愿意为它说话
        │
        ├── 3. 判断 Judgments ──────────── 质量 · 可信 · 优越
        ├── 3. 感觉 Feelings ───────────── 温暖 · 乐趣 · 安全 · 社会认同
        │
        ├── 2. 性能 Performance ────────── 功能满足程度 · 可靠性 · 服务
        ├── 2. 形象 Imagery ────────────── 谁在用 · 什么场合用 · 什么人格
        │
        └── 1. 显著度 Salience ─────────── "这类东西里，我想得到你吗"
```

**关键读法：**

```
① 四层是「依赖关系」，不是「并列关系」。
   没有显著度 → 上面三层根本没机会被评估。
   有显著度但没有性能/形象 → 你只买到了一个「听说过」，它换不来溢价。
② 只有到第 4 层，品牌才第一次产生「免费的 CAC」——口碑推荐。
   前三层都只在降低你的说服成本，第 4 层才在降低你的获客成本。
③ 自下而上是建设路径，自上而下是崩塌路径。
   一次性能事故可以从第 4 层直接击穿到第 1 层。
```

> ## 品牌资产不是"名气"，是"顾客在无提示情况下能想起你、并且愿意多付一点"。
> ## 前者叫显著度，后者叫溢价。**只有一个都不算资产。**

### 2.4 价值：顾客感知价值（CPV）

营销里最被误用的词。价值不等于价格，也不等于质量。

```
顾客感知价值 CPV = 总顾客利益 − 总顾客成本

总顾客利益 = 产品利益 + 服务利益 + 人员利益 + 形象利益
总顾客成本 = 货币成本 + 时间成本 + 精力成本 + 体力成本
```

**这个拆法的杀伤力在于：它让"涨价"变成一个可以赢的动作。**

**微算术——便利店为什么能比大卖场贵 12% 还活着：**

| | 大卖场 | 便利店 |
|---|---|---|
| 货币成本（价格） | 100 | 112 |
| 时间成本（往返+排队） | 14 | 4 |
| 精力成本（找货、比价、搬运） | 6 | 2 |
| **总成本** | **120** | **118** |
| 产品利益（同品牌同规格） | 100 | 100 |
| **CPV** | **−20** | **−18** |

> ## 结论
> **便利店的 CPV 反而更高，尽管它贵 12%。**
> 因为营销的竞争单位不是"价格"，是"总成本"。
> **能降时间/精力成本的企业，永远有涨价空间**——这是所有"即时零售、订阅制、一站式"生意共同的底层逻辑。

## §3 三根支柱与核心定理

### 支柱一：需要是给定的，欲望是可塑的，需求是可管理的

科特勒对"营销能做/不能做"划的第一条界。

```
需要（Need）   ── 人性层面，营销动不了。声称能"创造需要"是骗人。
欲望（Want）   ── 文化层面，营销在这里工作。广告、内容、社群都在改这一层。
需求（Demand） ── 交易层面，营销用定价、分销、促销来管理。
```

> **营销不改变人想要什么，营销改变人在哪里、以什么代价、得到哪个版本。**

**这条界很重要，因为它同时划出了营销的能力和营销的责任。**
"是营销让人变贪"是错的——贪是 Need 层。但"是营销让人把某个具体东西当成幸福的必要条件"是对的——那是 Want 层。

### 支柱二：STP 的本质是放弃

```
S 细分 Segmentation   按「可识别、可触达、有购买力、有反应差异」把市场切开
T 目标 Targeting      选一批你能服务得比别人好的
P 定位 Positioning    在目标顾客头脑里，占一个词
```

**四个细分有效性判据（缺一不可）：**

| 判据 | 问法 | 不满足的后果 |
|---|---|---|
| 可衡量 | 这个人群数量能估出来吗？ | 无法分配预算 |
| 可触达 | 有渠道能高效触达他们吗？ | 找到了也够不着 |
| 足够大 | 规模能撑起单位经济吗？ | 服务成本 > 利润 |
| 可区分 | 他们对营销刺激的反应**不一样**吗？ | 切了等于没切，白增复杂度 |

> ## 定位的唯一可操作测试
> **如果顾客只能用一句话描述你，他会说什么？**
> 说不出 → 你没有定位，你只有一个产品。
> 说得出的那句里，**有没有包含"不"字**（不做什么、不适合谁）→ 没有"不"字的一句話，通常只是品类名。

**定位测试的三个变体（实战更好用）：**

```
① 填空测试：「___ 是一种 ____，它能 ____，但你不会用它来 ____。」
② 替代测试：「如果这个品牌明天消失，顾客会拿什么替代它？」
              → 答不上来 = 你还没占住任何位置。
③ 反向测试：「为了让这句话成立，我必须放弃哪些顾客、哪些品类、哪些渠道？」
              → 放弃清单为空 = 定位是空话。
```

### 支柱三：4P 是一个自洽系统，不是四个杠杆

| 4P | 决策内容 | 对应 4C（Lauterborn） |
|---|---|---|
| **产品** Product | 种类、质量、设计、特征、品牌名、包装、服务、保证 | **顾客解决方案** Customer Solution |
| **价格** Price | 标价、折扣、返利、付款期、信用条件 | **顾客成本** Cost to Customer |
| **渠道** Place | 覆盖、品类、位置、库存、运输 | **便利** Convenience |
| **促销** Promotion | 广告、销售促进、人员推销、公关、直复 | **沟通** Communication |

**4P → 4C 的翻转不是翻译，是主语的更换**：从"我要卖什么"换成"他要完成什么"。

> **4P 最重要的性质：它们互相约束。**
> ```
> 高端定位（Product/Price）
>    + 折扣促销（Promotion）    → 认知冲突，价格锚被砸
>    + 大卖场铺货（Place）      → 稀缺性消失，溢价崩
> ```
> **营销方案失败的第一大死因，不是某个 P 选错了，是四个 P 互相打架。**

**整合营销传播 IMC（IMC = Integrated Marketing Communications）** 就是这条支柱的推广版：
顾客不区分你投的是广告、是客服、是包装、还是快递盒。**他接收到的所有触点合成一个品牌印象，其中一个触点的噪声可以抵消掉其余全部的信号。**

```
IMC 判据：把任意两个触点的话术摆在一起读。
          如果读起来不像同一个人在说话 → 你的 IMC 是失效的。
```

### ⭐ 核心定理

> ## 顾客买的不是产品，是**要办的事**（Job to be Done）。
> ## 营销近视症 = 卖方按「我造什么」分类，买方按「我要办什么」分类
> ## —— 两套分类法之间的**距离**。

展开成可操作的等式：

```
近视度 = 1 − | 卖方定义的品类 ∩ 买方定义的品类 | / | 买方定义的品类 |

距离越大 → 越容易被替代品从侧面杀死
距离 = 0 → 你和服务对象完全对齐
```

**Levitt 1960 年的原始例子**：铁路公司以为自己卖的是"铁路"，顾客要的是"运输"。
于是公路、航空、管道来了，铁路公司全部没有反应——因为在它的字典里，那些不叫竞争对手。

**现代重演清单：**

| 卖方以为自己在做 | 顾客实际要办的事 | 谁从侧面杀死了它 |
|---|---|---|
| 数码相机 | 留住瞬间 | 手机 |
| 出租车 | 从 A 到 B | 网约车、共享单车、地铁 |
| 商学院教材 | 通过考试 / 拿到技能 | 在线课程、认证、AI 辅导 |
| 报纸 | 知道今天该关心什么 | 信息流、播客、社群 |
| 百货商场 | 一次性比较很多选项 | 电商搜索 + 评价 + 退货 |

**这跟同库其他几份的核心定理是同构的：**

| 模型 | 核心定理 | 形式 |
|---|---|---|
| 小岛经济学 | 财富 = 产能；货币/债务 = 索取权 | 实物 vs 凭证 |
| 博弈论 | **内卷 = 帕累托最优 − 纳什均衡** | 两个点的距离 |
| 乌合之众 | **群体意见 = 最响意见 ≠ 平均意见** | 两个量的错位 |
| 营销管理 | **产品 ≠ 任务完成；卖方分类 vs 买方分类** | 两套分类法的距离 |

**四本都在讲同一件事：系统会停在一个跟"应该"不一样的地方，而且它很稳。**
小岛说"停在了凭证上"，博弈论说"停在了次优上"，乌合之众说"停在了最响上"，营销管理说"**停在了卖方自己的语言里**"。

## §4 四条因果回路

### 回路 A：营销近视自锁回路（正反馈）

```
        产品曾经卖得好
              ↓
     组织把「我们是什么」定义为产品本身
              ↓
     资源全部投向「把产品做得更好」，而非「顾客的任务怎么变了」
              ↓
     顾客的任务被替代品用另一种方式完成了
              ↓
        销量下滑
              ↓
     归因：一定是我们的产品还不够好
              ↓
     更用力改良产品（回到起点，且更偏）
```

**自锁点**：**归因错误**。下滑被内部解释为"执行问题/产品问题"，永远不会被解释为"定义问题"。
因为"定义问题"意味着承认过去几十年做的都偏了——组织会本能地拒绝这个解释。

**唯一的外部刹车**：**把"我们做什么生意"这句话重写一遍，主语必须是顾客的任务，不能是我们的产品。**

```
刹车测试：「我们做什么生意？」
  ❌ "我们做胶片。"          → 主语是产品
  ✅ "我们帮人保存记忆。"     → 主语是顾客的任务
```
重写这句话的成本极低，但它的**政治成本极高**——因为它否定了过去所有投入的方向。这就是它为什么很少发生。

---

### 回路 B：CAC 通胀回路（增长的反噬）

```
        增长目标 ↑
              ↓
     加大投放 / 拓宽人群定向
              ↓
     先触达「最想要的人」（转化率最高、CAC 最低）
              ↓
     剩下的人越来越不想要 → 转化率 ↓
              ↓
        CAC ↑
              ↓
     维持同样的新增，必须投更多钱
              ↓
        增长目标 ↑（回到起点）
```

**自锁点**：**人群天然按"意愿强度"排序，先摘低垂果实。** CAC 对规模的导数是正的，而且是单调的。
这不是团队执行不力，是**数学必然**。任何"我们投得还不够猛"的诊断，都会让回路转得更快。

**唯一刹车**：**改变目标函数**——把 KPI 从"新增人数"换成 `CLV/CAC` 或 `回本周期`。
一旦目标函数变了，回路会自动把预算从拉新推向留存（见回路 C），因为留存的边际成本远低于拉新。

> **诊断信号**：如果一个团队的汇报里，CAC 是唯一一个不被拆成人群分层来讨论的数字，
> 那么它一定处在回路 B 的加速段，而且自己不知道。

---

### 回路 C：满意 ⇄ 忠诚 ⇄ CLV 飞轮（双稳态，有阈值）

```
        顾客体验超过「惊喜阈值」
              ↓
        复购 + 主动口碑推荐
              ↓
        推荐带来的顾客 CAC ≈ 0
              ↓
        CAC 平均值 ↓ → 可承受更高的服务投入 / 更低的毛利
              ↓
        体验投入 ↑ → 满意 ↑（回到起点）
```

**自锁点**：**这个回路只在满意度超过阈值之后才启动。阈值以下它是反向的。**

```
       体验低于阈值
            ↓
       不满意 → 复购↓ + 负面口碑
            ↓
       负面口碑使 CAC ↑
            ↓
        CAC ↑ 挤压体验预算
            ↓
       体验进一步 ↓（回到起点）
```

**所以满意—忠诚不是一个线性函数，是一个双稳态系统**：要么在飞轮里越转越省，要么在死亡螺旋里越转越贵。中间没有稳定平衡点。

**唯一刹车**：**一致性**。飞轮的全部势能来自"体验可预期"。一次重大事故同时摧毁复购和推荐，把系统从稳态 A 直接推到稳态 B。
**这就是为什么服务型生意的第一 KPI 不是满意度均值，是"重大事故数"。**

---

### 回路 D：定位稀释回路（品牌延伸陷阱）

```
     品牌在一个词上建立了清晰定位（比如「安全」）
              ↓
     为了提高单客价值 / 完成增长目标，向相邻品类延伸
              ↓
     顾客头脑里的那个词开始变模糊
              ↓
     定位模糊 → 溢价能力 ↓ 且 说服成本 ↑
              ↓
     增长不达预期 → 再延伸一次，以补收入缺口
              ↓
     品牌变成「什么都做」→ 哪个词都不占（回到起点，且更糟）
```

**自锁点**：**延伸的短期收入是确定的、当期的；定位稀释的长期成本是延迟的、分散的。**
于是每一期单独算账，延伸都划算。这是典型的"账期错配型自锁"——和《博弈论》里的贴现率陷阱是同一个结构。

**唯一刹车**：**为品牌预先设定"禁入品类清单"，并写进品牌管理章程**（不是营销部门的备忘录，是董事会级的约束）。
替代方案：用**背书品牌 / 子品牌**做隔离，让稀释发生在子品牌层，不污染母品牌。

> **可观测的早期信号**：品牌的"一句话描述"开始变长。
> 从"最安全的车"变成"安全、智能、年轻、有性价比的车"——**每一个新增的形容词，都是一次定位的折价。**

## §5 六组算术

### 5.1 CLV / CAC：整本教材最终收敛到的两个数

**公式（简化版，教材通用形式）：**

```
CLV = 客单价 × 年购买次数 × 毛利率 × 留存年数
```

**代入一组具体数字：**

```
客单价 AOV        = 500 元
年购买次数 f      = 4 次
毛利率  g         = 40%
平均留存年数 N    = 5 年

年毛利贡献 = 500 × 4 × 0.40 = 800 元 / 年
CLV        = 800 × 5        = 4,000 元
```

**健康线判据（业内常用）：`CLV / CAC ≥ 3`**

```
CAC 上限 = 4,000 / 3 = 1,333 元
回本周期 = 1,333 / 800 = 1.67 年
```

**换成一张可查的表：**

| 实际 CAC | CLV/CAC | 判定 | 含义 |
|---|---|---|---|
| 400 元 | 10.0 | 极健康 | 大概率**投放不足**，应加预算 |
| 800 元 | 5.0 | 健康 | 可加速 |
| 1,333 元 | 3.0 | **临界线** | 分界线 |
| 2,000 元 | 2.0 | 危险 | 每单在烧钱，规模越大烧越多 |
| 4,000 元 | 1.0 | 净亏损 | 卖一单亏一单（不含固定成本） |

> ## 结论
> **`CLV/CAC ≥ 3` 不是道德判断，是一个"误差冗余"设计。**
> 因为 CLV 是估计值（见 5.5，两个参数各差 5 个点，CLV 就差 2 倍），3 倍线留出的 2 倍冗余，就是用来吸收这个误差的。
> **比值低于 3 时，你不是"效率低"，是"在一个估计不准的数上赌命"。**

**同时注意两件事：**

```
① CAC 应该按「渠道 × 人群」分层看。一个平均值 1,200 的 CAC，
   常常是「A 渠道 400 + B 渠道 3,000」的平均。平均值会同时掩盖
   最好的机会和最坏的出血点。
② CLV 应该按「获客批次」算，不按「全体用户」算。
   全体用户的 CLV 里混着最早那批高质量用户，会系统性高估新批次的价值。
```

---

### 5.2 留存率的杠杆：为什么 5 个百分点比涨价 5% 值钱得多

**这次用等比数列（正确的算法），因为顾客是逐年按概率留存的：**

```
年毛利贡献 m = 800 元
年留存率   r

期望 CLV = m·(1 + r + r² + r³ + …) = m / (1−r)
期望顾客年数 = 1/(1−r)
```

> 注意这条式子与 §5.1 的一致性：§5.1 假设"留存 5 年"，而 `1/(1−0.80) = 5 年`。
> **"平均留存 5 年"这个说法，等价于"年留存率 80%"。** 两者不是两个假设，是同一个假设的两种写法。

| 年留存率 r | 期望顾客年数 1/(1−r) | CLV = 800/(1−r) | 相对 r=0.80 |
|---|---|---|---|
| 0.70 | 3.33 年 | 2,667 元 | −33.3% |
| 0.75 | 4.00 年 | 3,200 元 | −20.0% |
| **0.80** | **5.00 年** | **4,000 元** | **基准** |
| 0.85 | 6.67 年 | 5,333 元 | **+33.3%** |
| 0.90 | 10.00 年 | 8,000 元 | **+100.0%** |

**同一批数字换成 CLV/CAC（设该生意的实际 CAC = 1,200 元）：**

```
r = 0.75 → 3,200/1,200 = 2.67  ✗  跌破 3 倍健康线
r = 0.80 → 4,000/1,200 = 3.33  ✓  勉强合格
r = 0.85 → 5,333/1,200 = 4.44  ✓  显著健康
```

**留存率掉 5 个百分点，一门生意就从"合格"变成"烧钱"。**

**杠杆有多大？求弹性：**

```
CLV = m / (1−r)
d(CLV)/dr = m / (1−r)²
弹性 = [d(CLV)/CLV] / [dr/r] = r / (1−r)

r = 0.80 时，弹性 = 0.80/0.20 = 4
```

> **留存率相对提升 1%，CLV 提升 4%。**
> 而客单价相对提升 1%，CLV 只提升 1%（线性）。
> **同样是"提升 5%"，留存的杠杆是客单价的 4 倍。**

（精确算：r 从 0.80 到 0.85 是 **+6.25%** 的相对提升，CLV 从 4,000 到 5,333，**+33.3%**——
一阶近似只给 6.25% × 4 = 25%，**实际高出三分之一**，因为分母 (1−r) 在同步变小。）

> ## 结论
> **CLV 对留存率的敏感度是 `r/(1−r)`，随 r 升高而爆炸。**
> r = 0.80 → 4 倍杠杆；r = 0.90 → 9 倍杠杆；r = 0.95 → 19 倍杠杆。
> **这就是为什么所有成熟生意最终都会从"拉新部门"变成"留存部门"**——不是因为留存更"正确"，是因为它的导数大一个数量级。
> **换个说法：把客单价提 20% 是线性收益；把留存提 20% 是复利收益。**
> 而且留存率越高的生意，边际上再提 1 个点的价值越大——**好生意和坏生意的差距会被这个分母放大。**

---

### 5.3 价格弹性：涨价 10%，销量最多能掉多少

**保本推导（纯边际情形，变动成本 = 0）：**

```
原状态： P₀ · Q₀
涨价后： P₁ = P₀(1+x)，  Q₁ = Q₀(1−y)
保本条件： P₁Q₁ = P₀Q₀
      ⇒  (1+x)(1−y) = 1
      ⇒  1−y = 1/(1+x)
      ⇒  y = x/(1+x)
```

**代入 x = 10%：**

```
y = 0.10 / 1.10 = 0.0909 = 9.09%

判据：只要销量下降不到 9.09%，涨价 10% 就是增收的。
等价地：只要真实价格弹性 |ε| < 9.09%/10% = 0.909，就该涨价。
```

**但要加进变动成本，结论会大变。设毛利率 g = (P−VC)/P：**

```
保本条件： (P₀(1+x) − VC)·Q₀(1−y) = (P₀ − VC)·Q₀
        ⇒  1−y = (P₀ − VC) / (P₀(1+x) − VC)
        ⇒  y = x·P₀ / (P₀(1+x) − VC)
```

| 毛利率 g | 变动成本 VC | 涨价 10% 后可容忍的销量跌幅 y | 可容忍的价格弹性 |
|---|---|---|---|
| 100%（纯服务） | 0 | **9.09%** | 0.91 |
| 60% | 0.40P | 0.10/0.70 = **14.3%** | 1.43 |
| 40% | 0.60P | 0.10/0.50 = **20.0%** | 2.00 |
| 20% | 0.80P | 0.10/0.30 = **33.3%** | 3.33 |
| 10% | 0.90P | 0.10/0.20 = **50.0%** | 5.00 |

> ## 结论
> **毛利率越低，越应该涨价。** 这与直觉完全相反。
> 因为涨价的收益走的是"每单位贡献"这条通道，而低毛利生意的单位贡献基数小，同样涨 10%，贡献额增幅更大。
> **代价是：低毛利生意通常也面对高弹性顾客。所以这条不是"低毛利就该涨"，是"低毛利时，必须先把弹性测出来"。**
> **实测方法**：不要用回归估计弹性（内生性太强），用**分区域/分时段的价格实验**。

**反向：降价 10% 需要多少增量才保本？**

```
(1−0.10)(1+z) = 1  ⇒  z = 1/0.9 − 1 = 11.1%
```
**降价 10% 必须换来 11.1% 的销量增长才不亏。** 注意它比涨价端的 9.09% 更苛刻——**降价比涨价更难保本。**

### 5.4 促销折扣对毛利的侵蚀：打 8 折要卖多少才保本

**推导：**

```
设毛利率 g，折扣幅度 d（打 8 折 → d = 0.20）
原单位贡献 = g·P
折后单位贡献 = (1−d)P − (1−g)P = (g − d)·P
保本所需销量倍数 k = g / (g − d)
```

| 毛利率 g | 折扣 | 所需销量倍数 k | 需要的增量 |
|---|---|---|---|
| 60% | 9 折 (d=0.10) | 0.60/0.50 = 1.20 | +20.0% |
| 60% | 8 折 (d=0.20) | 0.60/0.40 = 1.50 | +50.0% |
| 40% | 9 折 (d=0.10) | 0.40/0.30 = 1.33 | +33.3% |
| **40%** | **8 折 (d=0.20)** | **0.40/0.20 = 2.00** | **+100%** |
| 40% | 7 折 (d=0.30) | 0.40/0.10 = 4.00 | +300% |
| 20% | 8 折 (d=0.20) | 0.20/0.00 = **∞** | **毛利归零，卖多少都补不回** |

**关键的除法关系（这是最反直觉的一点）：**

```
打 8 折（价格 −20%）→ 毛利率从 40% 掉到 20% → 毛利额 −50%
价格只降了 20%，毛利掉了一半。
```

> ## 结论
> **折扣对毛利是除法，不是减法。**
> 毛利被压缩的倍数不是 `d`，是 `d/(g−d)+1 = g/(g−d)`。
> **经验判据**：`g ≤ 2d` 时禁止打折（因为 k ≥ 2，翻倍销量基本不可能达成）；
> `g ≤ d` 时打折等于销毁毛利。
> 对 40% 毛利率的生意，**20% 是折扣的绝对上限，且需要翻倍销量——这几乎总是一个幻觉。**

### 5.5 参数敏感度：CLV 是一个 2 倍宽的区间，不是一个小数点

**加入折现率，保持与 §5.2 同一套约定：**

```
CLV = Σ (m · r^(t−1)) / (1+i)^t  =  m / (1 + i − r)        m = 800 元/年

验证：i = 0 时退化为 m/(1−r)，与 §5.2 一致 ✓
```

**固定 r = 0.80，扫折现率 i：**

| 折现率 i | CLV | 相对 i=10% |
|---|---|---|
| 5% | 800/(1.05−0.80) = 800/0.25 = **3,200** | +20.0% |
| **10%** | 800/(1.10−0.80) = 800/0.30 = **2,667** | 基准 |
| 15% | 800/(1.15−0.80) = 800/0.35 = **2,286** | −14.3% |
| 20% | 800/(1.20−0.80) = 800/0.40 = **2,000** | −25.0% |

**固定 i = 10%，扫留存率 r：**

| 留存率 r | CLV | 相对 r=0.80 |
|---|---|---|
| 0.75 | 800/(1.10−0.75) = 800/0.35 = **2,286** | −14.3% |
| **0.80** | 800/(1.10−0.80) = 800/0.30 = **2,667** | 基准 |
| 0.85 | 800/(1.10−0.85) = 800/0.25 = **3,200** | +20.0% |

**两个参数各自都只是"合理的估计"：**

```
r 的不确定性：±5 个百分点（很常见，取决于你怎么定义"活跃"）
i 的不确定性：±5 个百分点（取决于你对这笔钱的用途假设）

最坏：r=0.75, i=15% → 800/(1.15−0.75) = 800/0.40 = 2,000
最好：r=0.85, i= 5% → 800/(1.05−0.85) = 800/0.20 = 4,000

区间宽度：4,000 / 2,000 = 2.0 倍
```

> ## 结论
> **同一门生意，CLV 可以算出 2,000，也可以算出 4,000——整整差 2 倍。**
> 而这两个参数之间没有任何相互抵消的机制：**它们同向叠加，误差会相乘放大。**
> 而 `CLV/CAC ≥ 3` 这条线，是在一个 2 倍宽的分子上画的。
> **所以正确做法不是算出 CLV 的"值"，是算出 CLV 的"区间"，然后看 CAC 落在区间的哪一段：**
> ```
> CAC 落在区间下沿以下        → 可以放心加预算
> CAC 落在区间内部            → 决策取决于你对 r 的信心，不是对数字的信心
> CAC 落在区间上沿以上        → 直接停
> ```
> **任何把 CLV 报成单一小数点的方案，都应该被退回。**
> **注意哪一端更安全**：CAC 落在 2,000 以下时才叫"无条件安全"；
> 落在 2,000–4,000 之间时，你赌的是"r 真的能稳在 0.80 以上"——而那正是 §5.2 里杠杆最大的那个变量。

### 5.6 品牌溢价：它到底是不是一项资产

**用一组干净的数字检验。同一家代工厂，同一成本：**

```
白牌售价 80 元，成本 60 元  → 单位毛利 20 元
品牌售价 120 元，成本 60 元 → 单位毛利 60 元
品牌溢价 = 40 元/件
年销量   = 100 万件
→ 年溢价收入 = 40 × 100 万 = 4,000 万元
```

**但品牌不是免费的。维持它要花钱：**

```
年营销投入（广告、内容、代言、公关、会员权益） = 5,000 万元
```

```
净贡献 = 4,000 − 5,000 = −1,000 万元
```

**到此为止：这个品牌资产是负的。**

**但品牌还有第二条收益通道——降低 CAC：**

```
无品牌时 CAC = 200 元，年新增顾客 30 万 → 获客支出 6,000 万
有品牌时 CAC = 120 元，年新增顾客 30 万 → 获客支出 3,600 万
CAC 节省 = 2,400 万元
```

```
品牌资产净贡献 = 4,000（溢价）− 5,000（维持） + 2,400（CAC 节省）
              = +1,400 万元 / 年
```

> ## 结论
> **品牌资产的收益，主要来自 CAC 下降，不是来自溢价本身。**
> 在上面这组数字里，溢价通道单独看是亏的（−1,000 万），是 CAC 通道把它救回来的。
> **可操作判据：**
> ```
> 品牌资产存在 ⟺ 溢价 × 销量 + CAC 节省 > 维持成本
> 品牌资产不存在 ⟺ 上面三项相减为负（此时"品牌"只是用利润买来的一个故事）
> ```
> **推论**：在 CAC 本来就很低的渠道（比如纯自然流量、B 端关系型销售），
> **重金做品牌的 ROI 会显著低于直觉**——因为品牌最值钱的那条通道（降 CAC）在你这里本来就不贵。

## §6 策略与决策表

**用法**：先定位你在哪个决策点上，再取对应动作。所有动作都指回 §5 的算术。

| 场景 | 该做什么 | 机制依据 |
|---|---|---|
| **新产品，无替代，需求价格弹性低** | **撇脂定价（skimming）**：先高价收割最不敏感的那批，再逐级下探 | 需求曲线的高端段弹性最低；先拿到愿意付最多的人，且为后续降价留空间 |
| **新产品，有强网络效应/规模经济** | **渗透定价（penetration）**：先低价抢规模，用规模换单位成本 | 单位成本随规模下降时，早期低价是投资不是亏损；错过规模窗口不可逆 |
| **产品已被同质化** | 差异化只能发生在**附加产品层**或**品牌层**；不要在功能层继续加码 | 核心利益层和技术层会被复制；附加层和联想层复制成本高（但附加层会归零，见 §2.2） |
| **要给产品定价到 .9（心理定价）** | 只在**决策由系统 1 完成**的低价快消品类用；高价品类用整数价 | 左位数效应只在低介入决策中生效；高价品类需要"可信"而非"便宜" |
| **要涨价** | 先算 §5.3 的保本销量变化；同时尝试**降低时间/精力成本**来补 CPV | CPV = 总利益 − 总成本；非货币成本的下降可以抵消货币成本上升（§2.4） |
| **要打折** | 先算 §5.4 的保本倍数 k = g/(g−d)。**g ≤ 2d 时禁用**。优先用非价格手段（赠品、延保、会员权益） | 折扣对毛利是除法；非价格手段不改变价格锚 |
| **CAC 持续上升** | 把预算从拉新转向留存。KPI 从"新增人数"改成"回本周期 ≤ 12 个月" | §5.2 留存杠杆 = r/(1−r)，r=0.8 时 4 倍、r=0.9 时 9 倍；§4 回路 B 的唯一刹车是换目标函数 |
| **品牌想延伸到相邻品类** | 先写**禁入品类清单**；或者用子品牌/背书品牌做隔离 | §4 回路 D 的自锁来自"短期确定收益 vs 长期延迟成本"的账期错配 |
| **线上与线下渠道冲突** | 不做同品同价，做**任务分工**：线上负责"发现+比价+复购"，线下负责"体验+即时+服务" | 渠道冲突的本质是"同一个任务被两个渠道用不同成本结构服务"；分工能消除直接比价 |
| **要推 IMC / 统一品牌口径** | 把任意两个触点的话术并排读，检查是否像同一个人在说话 | 顾客不区分触点；一个触点的噪声可抵消其余全部信号 |
| **要投内容 / 做私域 / 建社群** | 先问：它是降 CAC 还是提留存？**两者都不是，它就是成本，不是营销** | §5.1 全书的收敛点是 CLV 和 CAC 两个数；不作用于这两个数的动作无法评估 |
| **面对"增长黑客"打法** | 顺序必须是 **留存 → 激活 → 获客**，不能倒过来。先补漏水桶，再开大水龙头 | §4 回路 B：先拉新会让 CAC 在漏斗底部被放大；§5.2：留存是唯一有指数杠杆的变量 |
| **定位模糊，想不清楚** | 用 §3 的"一句话测试 + 反向测试"倒推：先写放弃清单，再写定位语 | 没有"不"字的一句话只是品类名，不构成定位 |
| **数据不足，但有大量相关性数据** | 做**增量实验**（holdout / geo-lift / PSI），不要用相关性做归因 | 相关性归因会高估营销效果；平台报表天然倾向于把自然转化归给自己的触点 |
| **顾客要求更多、更便宜、更快** | 区分"需要"和"欲望"：需要必须满足，欲望要**选择性满足**，并且只满足**愿意付费的那一段** | 营销的目标函数是"可盈利地满足"，不是"满足"（§0） |

### 两条反直觉提醒

> **① "满足顾客"不是目标，"可盈利地满足"才是**
> 顾客会合理地要求一切免费的东西：更快的配送、无限退货、24 小时客服、永不过期的积分。
> 这些都是**真实的需求**，满足它们都能提高满意度。
> **但它们不是营销目标，是成本项。**
> 营销的活儿是：找出其中**顾客愿意为之付费的那一段**，把那一段做到超出预期，把其余部分做到"可接受"。
> **无差别地满足需求的团队，最终会做出一家满意度极高、毛利为零的公司。**

> **② 4P 不是四个杠杆，是一个约束系统**
> 大多数人把 4P 当清单用：产品做了吗？价格定了吗？渠道铺了吗？广告投了吗？——全打勾，方案完成。
> **正确的用法是当约束用**：任选一个 P，问"另外三个必须长什么样，这个 P 才成立？"
> ```
> 高定价  ⇒  产品必须有可感知的独占性 + 渠道必须有筛选性 + 促销不能是价格
> 低定价  ⇒  产品必须把成本结构做到极限 + 渠道必须极致覆盖 + 促销可以是价格
> ```
> 实际失败几乎都出在这里：**高端定位的品牌，用折扣做增长。** 它在第 2 个月见效，在第 18 个月致命。

## §6.5 专题：4P 失效之后（数字化时代的营销迁移）

> 视频指向"数字化时代的营销变革"。这一段处理的是：**当 4P 的四个格子被平台和算法重新划界后，还剩什么。**

### 4P 的四个格子为什么被打散了

| 传统 4P | 传统含义 | 数字环境下的变化 | 失效点 |
|---|---|---|---|
| **Place** | 货架、门店、经销商层级 | 流量入口变成**推荐算法的排序** | "铺货"不再等于"有货可买"，而是"能不能被排进前 3 屏" |
| **Promotion** | 广告 + 促销 + 公关 | 变成**内容资产 + 社群 + 算法分发** | 广告是可买的曝光；内容是**可能被分发**的曝光。前者线性，后者幂律 |
| **Price** | 标价 + 折扣政策 | 变成**动态定价 + 比价透明 + 平台补贴** | 价格锚被全网比价摧毁，促销的边际效果被平台流量补贴稀释 |
| **Product** | 功能与形式 | 变成**持续迭代的软件化交付** | "产品"从一次交付变成一段持续关系，SKU 概念部分失效 |

> ## 核心判断
> **4P 没有错，它是"大众媒体 + 连锁零售"时代的坐标系。**
> 当曝光由算法决定、渠道由平台拥有、价格由比价抹平，**四个 P 的边界互相渗透，单点优化的收益递减。**
> **补上来的框架是「增长模型」——它不是替换 4P，是把 4P 的"一次性方案"改成"可迭代的漏斗"。**

### 增长模型（AARRR）与 4P 的对应

```
   Acquisition   获客     ← 对应 Promotion + Place（算法的部分）
        ↓
   Activation    激活     ← 对应 产品三层次里的「核心利益 + 附加产品」
        ↓
   Retention     留存     ← 4P 里没有对应的 P ★ 这是旧框架最大的空缺
        ↓
   Revenue       变现     ← 对应 Price
        ↓
   Referral      推荐     ← 对应 CBBE 第 4 层「共鸣」（唯一免费的 CAC）
```

**关键：4P 里没有"留存"这个格子。**
这就是为什么大量按 4P 做完整的公司，仍然在增长上失败——**它们优化了四个一次性动作，漏掉了唯一一个复利动作。**

| 增长模型的概念 | 用本书的语言翻译 | 归属 |
|---|---|---|
| **内容营销** | 用可被算法分发的形式，持续降低 CAC 与提高显著度 | Promotion × 品牌 Salience |
| **社群** | 把 CBBE 第 3 层的"感觉"外化成同伴关系，提高留存与推荐 | 品牌 Feelings/Judgments + Referral |
| **私域** | 把渠道从"平台的"变成"自己的"，本质是**降低 CAC 的长期成本**并提高复购频次 | Place 的所有权 + Retention |
| **增长黑客** | 用实验方法替代方案方法，把 4P 从"策划"改成"迭代" | 全部 4P + 实验方法论 |

> **一句话判据（贯穿本节）：**
> ```
> 任何数字营销动作，只要不能落回 CLV 或 CAC 中至少一个，
> 它就只是一个成本，不是营销。
> ```
> **"内容、社群、私域"不是新 4P，是同一台机器换了传动方式。**
> 传动方式的改变不改变机器的判据——**还是那两个数。**

### 私域的真实算术（一句话版）

```
私域的收益 = 复购频次提升带来的 CLV 增量 + CAC 下降
私域的成本 = 内容与运营的人力 + 平台费 + 折旧

判据：若私域只能提高"触达率"但不能提高复购频次或降低 CAC，
      它就是一块换了名字的广告牌。
```

**这就是绝大多数"私域项目"失败的原因**：它们把私域当成了**新的推送渠道**，而不是**留存工具**。
推送渠道的收益随频次递减（用户会屏蔽）；留存工具的收益随 r 复利（§5.2 的 r/(1−r)）。

## §7 八个现场检验

**拿这八条去扫任何一个营销方案、一个增长计划、一次定价决策。**

```
① 任务检验
   顾客「雇佣」这个产品，是要完成什么任务？
   → 用动词回答，不能用名词。答成名词 = 你还在卖方坐标系里。

② 一句话检验
   如果顾客只能用一句话描述你，他会说什么？
   → 说不出 = 没有定位。说得出但含"什么都好" = 品牌正在被稀释。
   → 这句话里有没有"不"字？没有 = 只是品类名。

③ 弃客检验
   为了服务这批人，我明确放弃了谁？
   → 写不出放弃名单 = 你没有目标市场，你只有"所有人"。

④ 自洽检验
   把 4P 摆在一起，有没有哪个 P 在拆另外三个 P？
   → 典型：高定价 + 折扣促销；高端定位 + 全渠道铺货。

⑤ 单位经济检验
   CLV/CAC 是多少？它的区间是多少？
   → 只给点估计不给区间的，直接退回（§5.5 显示区间可达 2 倍宽）。

⑥ 留存检验
   留存率提高 5 个百分点，CLV 会变成多少？
   → 算不出来 = 你没有留存数据 = 你在用拉新的钱补漏水的桶。

⑦ 归因检验
   这个增长是我的动作带来的，还是季节、大盘、平台流量变化带来的？
   → 有没有 holdout / 对照组 / geo 实验？没有 = 你只是相关性数据的读者。

⑧ 品类检验
   顾客在货架上（或搜索结果里）把我归到哪一类？和我自己的归类一致吗？
   → 不一致的程度，就是你的营销近视度（§3 核心定理）。
```

**加一条元检验（用来检验前八条本身）：**

```
⑨ 成本检验
   这个方案里，每一项支出分别作用于 CLV 还是 CAC？哪一项都不作用的，删掉。
```

## §8 诚实边界：这本书什么时候会骗你

**科特勒的框架极其好用，但它有一个根本性质，必须先说清楚：**

> ## 它是**描述性的分类学**，不是**预测性的理论**。
> 4P、STP、三层次、CBBE、AARRR——这些是**帮你把问题摆整齐的格子**，
> 不是**告诉你结果会怎样的方程**。
> **一个分类框架永远无法被证伪。** 因为任何现象都可以被塞进某个格子里，
> 而"塞进去"这个动作本身，就已经完成了它的全部功能——它不预测任何东西。

**在这个前提下，逐条列出具体问题：**

| # | 局限 | 具体问题 | 修正 |
|---|---|---|---|
| 1 | **不可证伪** | 4P/STP/五层次是清单，不是模型。任何一个失败案例都能被解释为"某个 P 没做好"——**连失败都不能反驳它** | 把它当**检查清单**用，不当因果模型用。任何"因为 4P 做好了所以成功"的说法都是事后叙事 |
| 2 | **教材案例的幸存者偏差** | 书中案例（可口可乐、耐克、苹果、宝洁）全是**活下来且成功的品牌**。失败的同策略品牌不会进教材 | 需要主动补**基础率**：新品牌三年存活率、新 SKU 首年失败率。**没有分母的成功案例，只能当故事听** |
| 3 | **4P 在平台经济/算法分发下明显不够用** | 4P 里没有"留存"，没有"算法曝光"，没有"平台补贴"，没有"网络效应"。Place 的所有权已经不在品牌手里 | 用 AARRR 补结构缺口，用 JTBD 补分类缺口。**科特勒自己在 Marketing 3.0/4.0/5.0 里不断打补丁——一本教材出到第 16 版，本身就是框架需要持续补丁的证据** |
| 4 | **CLV/CAC 对参数极端敏感** | §5.5 已算：r ±5pp、i ±5pp → CLV 相差 **2 倍**（2,000 vs 4,000），且两个误差同向叠加、相乘放大。而这两个参数在实际业务里都是估计值 | **只报区间，不报点值**。`CLV/CAC ≥ 3` 视为启发式而非定理；决策依据应该是"我对 r 的信心"，不是"算出来的数" |
| 5 | **品牌资产难以量化** | 溢价法、成本法、Interbrand 法、BrandZ 法给出的数字可以差一倍以上，且都依赖主观折现假设 | 只用品牌资产的**方向**（在变强还是在变弱），不用它的**数值**做定价或并购决策 |
| 6 | **"满意 → 忠诚"的因果链被系统性高估** | 实证上满意—忠诚的相关性在**低转换成本行业近乎为零**。"满意但不忠诚"是常态，不是异常 | 用**转换成本 + 相对吸引力**两个变量替代满意度。雷尼尔森的"忠诚度阶梯"在现代市场里常常是断的 |
| 7 | **大量概念已被证伪或大幅修正** | ① "广告必须重复到有效频次（effective frequency）"——数字归因下的**增量实验**大量显示，在超过某一点后投放的增量近乎为零。② "市场份额必然带来利润"（早期 PIMS 研究）——被证明是相关性而非因果，且能被"投入换份额"反转。③ "4P 覆盖营销全部"——已被服务营销（7P）、关系营销、JTBD 部分替代 | 对每个"必然"句式保持警惕。教材里凡是写成**定律**的定量主张，都要找原始实证来源 |
| 8 | **归因方法缺失** | 教材大量讲"要做什么"，几乎不讲"**怎么知道是你做的**"。而这是现代营销最大的技术难题 | 强制引入：**holdout 组、geo-lift、增量实验、MMM（营销组合模型）+ 实验校准**。没有对照组的营销效果，本质上是信仰 |
| 9 | **制度与文化适用性** | 框架成形于 1960–2000 年的美国：大众媒体 + 全国连锁零售 + 成熟的品牌法律体系 | 在缺少全国性媒体、缺少连锁渠道、缺少商标执法的市场里，STP 和品牌资产的推论会系统性走偏。**"定位"在一个人际信任主导的市场里，可能不如"渠道关系"重要** |
| 10 | **规范性偏差：它假定增长是好的** | 全书隐含前提是"企业应当增长、应当扩大市场、应当满足更多顾客"。可持续性、负外部性、以及"不增长也是一种策略"基本不在框架内 | 明确把它当**企业视角的工具**，而不是社会视角的分析框架。用它来分析公共问题（如公共卫生传播）时，需要显式替换目标函数 |

> ### 一条使用纪律
> **这本教材最危险的时候，不是它说得不对的时候，是它说得"都对"的时候。**
> 因为 4P 清单打满勾的方案，读起来永远无懈可击——
> 而真实世界里的胜负，取决于**清单之外**的那个变量：
> 顾客的任务有没有变、CAC 有没有通胀、留存有没有在漏水。
> ```
> 用法 A（正确）：把框架当探照灯 —— 用它照亮盲区，然后去实地测量。
> 用法 B（错误）：把框架当考卷 —— 把四个格子填满，就以为做完了营销。
> ```
> **用法 B 的产物，通常是一份逻辑完整、数据齐全、ROI 为正（按平台报表计算）的方案，
> 和一个季度后不知所踪的增长。**

## §9 一页纸速查

```
┌──────────────────────────────────────────────────────────────┐
│  核心公式                                                     │
│                                                              │
│    营销 = 选需求(STP) → 造价值(4P，须自洽) → 使推销多余        │
│    盈利判据：  CLV ≥ 3 × CAC                                  │
│                                                              │
│    顾客买的不是产品，是要办的事（Job to be Done）              │
│    营销近视症 = 卖方分类 与 买方分类 之间的距离                │
└──────────────────────────────────────────────────────────────┘

【四个被重新定义的词】
  需求  需要(不可造) → 欲望(可塑) → 需求(有购买力的欲望，可管理)
  产品  核心利益 → 实际产品 → 附加产品        ★ 附加层会全部变成期望层
  品牌  CBBE 四层：显著度 → 性能/形象 → 判断/感觉 → 共鸣
        有显著度无联想 = 只买到一个名字；到共鸣层才产生免费 CAC
  价值  CPV = 总利益 − 总成本；成本含 货币/时间/精力/体力
        ★ 便利店贵 12% 仍赢，因为它把总成本从 120 降到 118

【三根支柱】
  ① 需要给定，欲望可塑，需求可管理 —— 营销动的是后两层
  ② STP 的本质是「放弃」；定位测试：顾客只能用一句话说你，他说什么？
     （那句话里必须有「不」字，否则只是品类名）
  ③ 4P 是约束系统不是清单；4C 是主语的更换（从我卖什么 → 他要完成什么）
     ★ 营销失败第一大死因：四个 P 互相打架（高端定位 + 折扣促销）

【核心定理】
  顾客买的是「任务的完成」，不是产品。
  近视度 = 1 − |卖方品类 ∩ 买方品类| / |买方品类|
  ★ 同构：小岛=凭证 vs 实物 │ 博弈论=两点的距离
         乌合之众=两量的错位 │ 营销=两套分类法的距离

【四条回路】
  A 近视自锁   卖得好 → 定义自己为产品 → 只改良产品 → 被替代 → 归因"产品不够好"
               ★ 唯一刹车：重写"我们做什么生意"，主语必须是顾客的任务
  B CAC 通胀   增长目标↑ → 先摘低垂果实 → 剩下的人更贵 → CAC↑ → 目标↑
               ★ 唯一刹车：换目标函数（从新增人数 → CLV/CAC 或回本周期）
               ★ CAC 对规模的导数是正的、单调的。这是数学必然，不是执行问题
  C 满意飞轮   惊喜 → 复购+推荐 → CAC≈0 → 体验投入↑
               ★ 双稳态，有阈值。阈值以下反向旋转成死亡螺旋
               ★ 第一 KPI 不是满意度均值，是「重大事故数」
  D 定位稀释   占住一个词 → 延伸 → 词变模糊 → 溢价↓ → 再延伸 → 什么都不占
               ★ 自锁来自账期错配：短期收益确定，长期成本延迟
               ★ 刹车：禁入品类清单 / 子品牌隔离

【六组算术】
  5.1 CLV   500 × 4 × 0.40 × 5 = 4,000 元；CAC 上限 = 4,000/3 = 1,333 元
            ★ CLV/CAC ≥ 3 是「误差冗余设计」，不是道德判断
  5.2 留存  CLV = m/(1−r)；弹性 = r/(1−r)
            r 0.80 → 4,000 │ 0.85 → 5,333（+33.3%）│ 0.75 → 3,200（跌破 3 倍线）
            ★ 留存 1% ≈ 客单价 4%（r=0.8 时）；r 越高杠杆越大
            ★ 「平均留存 5 年」≡「年留存率 80%」，不是两个假设
  5.3 涨价  y = x/(1+x)；涨 10% 只能容忍销量掉 9.09%（纯边际）
            毛利率 40% → 可容忍 20%；毛利率 10% → 可容忍 50%
            ★ 毛利率越低越应该涨价（反直觉）；降价 10% 需 +11.1% 才保本
  5.4 折扣  k = g/(g−d)；40% 毛利打 8 折 → 毛利砍半，需销量 ×2
            ★ 折扣对毛利是除法不是减法；g ≤ 2d 禁用折扣
  5.5 敏感  CLV = m/(1+i−r)；最坏 r=0.75,i=15% → 2,000
            最好 r=0.85,i=5% → 4,000（差 2 倍，误差同向叠加）
            ★ 只报区间不报点值。CAC 落在区间内部时，
              决策取决于你对 r 的信心，不是对数字的信心
  5.6 品牌  溢价 4,000 万 − 维持 5,000 万 + CAC 节省 2,400 万 = +1,400 万
            ★ 品牌资产的收益主要来自 CAC 下降，不是溢价本身
            ★ 在 CAC 本来就很低的渠道，重金做品牌 ROI 会显著低于直觉

【八个检验】
  ①任务 用动词说顾客要办什么事    ②一句话 顾客会怎么描述你？（含"不"字吗）
  ③弃客 明确放弃了谁？            ④自洽 哪个 P 在拆另外三个 P？
  ⑤单位经济 CLV/CAC 的区间？      ⑥留存 +5pp 后 CLV 是多少？
  ⑦归因 有 holdout 吗？           ⑧品类 顾客把我归到哪一类？
  （⑨元检验：每项支出作用于 CLV 还是 CAC？都不作用的删掉）

【数字化迁移】
  4P 缺的那一格是「留存」→ 用 AARRR 补：Acquisition/Activation/Retention/Revenue/Referral
  顺序必须是 留存 → 激活 → 获客，不能倒过来
  内容营销 = 可被算法分发的曝光（幂律，非线性的广告）
  社群     = 把 CBBE 第 3 层的「感觉」外化成关系 → 提留存 + 降 CAC
  私域     = 渠道所有权的转移，本质是长期降 CAC + 提复购
  ★ 判据：落不回 CLV 或 CAC 的动作，是成本，不是营销
  ★ 大量私域失败，是因为把它当「新的推送渠道」而不是「留存工具」

【边界】
  ❌ 不可证伪 —— 是分类学，不是预测理论。当清单用，不当因果用
  ❌ 幸存者偏差 —— 教材案例全是活下来的；必须自己补基础率（分母）
  ⚠️ 4P 在平台/算法经济下不够用 —— 缺留存、缺算法曝光、缺网络效应
  ⚠️ CLV/CAC 参数极端敏感 —— 区间可达 2 倍宽；只报区间
  ⚠️ 品牌资产难以量化 —— 各法相差一倍以上；只用方向，不用数值
  ⚠️ 满意→忠诚被高估 —— 低转换成本行业里近乎不相关
  ⚠️ 部分定量主张已被证伪 —— effective frequency、份额必带利润
  ⚠️ 归因方法缺失 —— 没有对照组的营销效果，本质是信仰
  ⚠️ 制度/文化适用性 —— 成品于美国大众媒体+连锁零售环境
  ⚠️ 隐含规范性 —— 它假设增长是好的；做公共分析须换目标函数

【一句收尾】
  顾客不买产品，顾客买「事情办成了」。
  你的产品只是他完成这件事的众多方式之一，
  而他在你的字典里找不到的那个竞争对手，
  才是真正会杀死你的那一个。
  ★ 所以唯一必须常年挂在墙上的问题是：
    「顾客雇我，是要办成什么事？这件事在怎么变？」
