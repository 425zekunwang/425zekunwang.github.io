## §0 一句话模型

> ## 系统 1 从不回答"你问的问题"，它回答"它最容易回答的那个问题"。
> ## 而系统 2 是它的**辩护律师**，不是它的**法官**。

写成式子：

```
判断(难题) = 系统1(置换(难题 → 简单题))   ← 自动，无意识，<1 秒
            ↓
         系统2 事后背书(不检查，只合理化)  ← 费力，懒惰，默认放行

⇒  你以为你在思考，其实你在把一个简单题的答案，当成难题的答案交上去。
```

**这是全书的发动机。** 它一次解释掉四个悖论：

| 悖论 | 用模型一句话解开 |
|---|---|
| 聪明人在自己专业外判断力极差 | 专业性只影响**简单题的选取**，不影响"置换"这个动作本身 |
| 明知是随机的，还是能看出"规律" | 系统 1 的**模式识别**对随机序列同样运行，它不会先问"这里有规律吗" |
| 明明有利可图却不敢做 | 参照点被移动了，**同一结果从"得到"变成了"失去"** |
| 事后所有人都说自己早就预料到了 | 结果一旦已知，系统 1 **立刻重写**当时的记忆，不留痕 |

> **卡尼曼自己的说法（意译）**：系统 1 是自动且快速的，几乎不费力气，没有自主控制的感觉；
> 系统 2 将注意力分配给需要费力的心理活动，但它是**懒惰的**——除非被逼，它只做最低限度的检查。

**记住这个非对称：系统 1 无法关闭，系统 2 默认关机。**
直觉以为自己是审慎的思考者在判断（系统 2 是主角），实际系统 2 只在被它自己的紧张感**叫醒**时才上线（§4 回路 A）。

> ⚠️ **必须配一个警告**（详见 §8）：**系统 1 / 系统 2 不是神经科学发现，是一个隐喻。**
> 大脑里没有两个盒子，没有"系统 1 脑区"。把它当解剖结构用，会立刻犯下这本书自己批判的错误：
> **用一个顺手的替代物，替代掉那个真问题。**

## §1 七个反直觉翻转

| # | 你以为 | 实际上是 | 为什么 |
|---|---|---|---|
| 1 | 我先看到证据，再形成判断 | **我先形成判断，再去找支持它的证据** | 联想启动是双向的：观念引向证据，证据又被用来确认观念。顺序是反的，而且你感觉不到 |
| 2 | 大量数据比少量数据可靠 —— 所以我会等足够样本 | **你不会等**。小样本的极端结果对你有更大的"故事吸引力"，越极端越像信号 | 小数定律：系统 1 不区分 n=3 和 n=300，它只看"结果有多极端"。而极端程度 ∝ 1/√n，恰恰在 n 小时最大 |
| 3 | 反馈能改进判断 | **多数反馈是噪声，被当成信号学进去了** | 飞行教官案例：表扬后变差、责骂后变好，**是均值回归，不是因果**。真因果（0.7）也确实存在，但被回归淹没，于是人从数据里学出了一条错误的因果理论 |
| 4 | 损失和收益对称，所以风险决策是求期望值 | **λ ≈ 2–2.25：亏 100 的痛 ≈ 赚 225 的爽** | 前景理论：价值函数在参照点以下**更陡**。而且它是 S 形的——两端都变平，所以人在大额赌局上反而变保守 |
| 5 | 我选的是"哪个结果更好" | **我选的是"哪个框架更让我舒服"** | 框架效应：同一个客观结果，只要换参照点或换描述，"手术存活率 90%" 和 "手术死亡率 10%" 得到相反的选择 |
| 6 | 我的记忆是录像机 | **记忆是按"最强烈的一刻 + 结尾"剪辑出来的预告片** | 峰终定律 + 时长忽视。原始体验的数据在结束时被**丢弃**，只剩下两个点的平均 |
| 7 | 我活在当下，回忆用来总结 | **是记忆自我在替我做决定，而它几乎不记录时长** | "我是我的记忆自我"（卡尼曼原话）。你选择的是记忆，不是体验。而这个选择往往买到了更短的痛苦、更差的回忆 |

**其中第 3、4、7 条最容易被低估，也最有杠杆。**
第 3 条是唯一一条**你能在三十天内亲眼验证且不需要任何实验室**的。
第 7 条是全书最后一章，也是卡尼曼自己认为最重要的结论。

## §2 核心区分：被重新定义的三个词

这本书真正的贡献不是发现了新现象，而是**把三个日常词拆成了两半**。

### 2.1 "思考" ≠ 一种活动，而是两台机器

| | **系统 1（快）** | **系统 2（慢）** |
|---|---|---|
| 运行方式 | 自动、并行、无意识 | 受控、串行、有意识 |
| 耗力 | 几乎为零 | 显著（瞳孔放大、心率上升、葡萄糖消耗） |
| 能否关闭 | ❌ 不能（"别想白熊"必然失败） | ✅ 默认就是关的 |
| 擅长 | 模式识别、情绪评估、熟悉感、直觉 | 统计、比较、多步骤运算、自我检查 |
| 出错模式 | **偏差**（biases）——系统性、可预测 | **懒惰**（laziness）——默认背书，不检查 |
| 典型任务 | "2+2"、读脸上的愤怒、听懂母语 | "17×24"、填 1040 表、数一段文字里的 f |

**关键：两者不是"人有两个脑子"，而是"两类加工"的标签。**
真正的神经学表述是**双过程理论（dual-process theory）**——一个宽泛的家族，不是卡尼曼专属的机制模型。

```
系统1 提案  →  系统2 有权否决
                  ↓
            但系统2 只在"察觉到冲突"时才审议
                  ↓
     绝大多数时候：系统2 直接盖章 (endorse)
```

> **所以这本书真正的批判对象不是"人会犯错"，是"人会用一个自己都没检查过的答案，感觉非常确定"。**
> 错误之所以是**系统性**的，正是因为系统 2 的失职是**系统性**的。

### 2.2 "我知道" ≠ 一个状态，而是两个来源

| | **认知放松（Cognitive Ease）** | **认知紧张（Cognitive Strain）** |
|---|---|---|
| 触发 | 重复、清晰印刷、押韵、好记的名字、好心情 | 模糊字体、生僻词、坏心情、被强迫的数学 |
| 你感觉到的 | "这是真的""我熟悉它""我喜欢它" | "这不对劲""要小心" |
| 系统 2 的地位 | 关机（更相信直觉） | 上线（更可能用系统 2） |
| 后果 | 放松 → 相信 → 更放松（**自锁**） | 紧张 → 警惕 → 更努力（**短暂**） |

> ## 熟悉感 ≠ 真相
> 系统 1 用"处理流畅度"当作"真实性"的代理指标。
> **重复能制造真相感，跟它是不是真的无关。** 这就是"睡一觉再听一遍就信了"的原理。

**最重要的实战推论：** 你能用**人为制造认知紧张**来唤醒自己的系统 2。
把合同用五号灰色斜体字印出来，你读它的时候会更挑错——这不是段子，是卡尼曼书里的实验方向。

### 2.3 "记忆" ≠ 一份记录，而是两套账

| | **经验自我（Experiencing Self）** | **记忆自我（Remembering Self）** |
|---|---|---|
| 它活在哪 | 现在，一个瞬间一个瞬间 | 过去，是一个故事 |
| 它测量什么 | 每一秒的效用（instant utility） | 峰 + 终（peak-end），**与时长无关** |
| 它做决定吗 | ❌ 不做 | ✅ **所有决定都是它做的** |
| 它的数据 | 全量，但随提取而消失 | 极简，但持久 |
| 它的 bug | 被忽略 | **时长忽视（duration neglect）** |

> **卡尼曼的结论**：我们不应该说"人追求幸福"，应该说"**记忆自我在追求一段好的故事，经验自我在承受这个故事的成本**"。

**这是全书最深的一刀**：你愿意重复的登山、你后悔结束的恋爱、你不愿再做的胃镜——
全都是记忆自我投的票，而票数**不包含你当时实际痛苦了多少分钟**。

## §3 三根支柱与核心定理

### 支柱一：认知放松 ⇄ 系统 2 的开关（启动与联想）

系统 1 的运作方式是**联想机器（associative machine）**：

```
一个词 → 唤起相关概念、情绪、身体反应、动作倾向
        ↓
  这一切在 <1 秒内完成，且是双向的
        ↓
  被唤起的东西又反过来强化最初那个词
```

**"启动效应"（priming）** 是这套机器的燃料：看到"老年"相关词的人走出实验室更慢。
（⚠️ 这条**已经站不住了**，见 §8。但"联想是双向的"这个更弱的版本仍然稳。）

> **支柱一的可用形态**：认知放松是**相信的燃料**。
> 任何让你"读起来顺"的东西，都在绕过你的系统 2。

### 支柱二：WYSIATI —— 你只能看见你看见的

**W**hat **Y**ou **S**ee **I**s **A**ll **T**here **I**s。

```
系统1 只用"当前可及的信息"构建一个连贯的故事
            ↓
它不问："还有哪些信息我没看到？"
            ↓
它只问："现在这些信息能拼出一个连贯故事吗？"
            ↓
能 → 就相信，并且确信度只反映"故事的连贯度"
```

> **确信度（confidence）反映的是故事的连贯程度，不是证据的充分程度。**
> 这跟《乌合之众》的"最响意见"是同构的——**质量指标被一个廉价的代理指标顶替了。**

**WYSIATI 直接生出三个后果：**
1. **过度自信**：信息少的故事同样连贯，而连贯度决定确信度 → 少量信息也能产生高确信
2. **框架效应**：你只处理呈现出来的那部分信息，"没被说出来的"等于不存在
3. **叙事谬误**：过去被压缩成一条因果链条，而真实原因是噪声

### 支柱三：参照点 + 损失厌恶 —— 价值不是绝对量

前景理论的三个零件，缺一不可：

```
① 参照点依赖（reference dependence）
   价值 = f(结果 − 参照点)，不是 f(结果)

② 损失厌恶（loss aversion）
   v(−x) ≈ λ · v(x)，λ ≈ 2–2.25

③ 敏感度递减（diminishing sensitivity）
   两端都变平 → 价值函数是 S 形，不是直线
```

**四重模式（fourfold pattern）** —— 支柱三最实用的一块：

| | **收益** | **损失** |
|---|---|---|
| **高概率** | 风险厌恶（宁可要确定的 900，不要 90% 的 1000） | **风险寻求**（宁可赌，不要确定的亏 900） |
| **低概率** | **风险寻求**（买彩票） | 风险厌恶（买保险） |

> ## 两个格子让你保守，两个格子让你赌 —— 而它们都是同一个价值函数。
> **同一个人，同一个下午，可以做出一对完全相反的风险选择，而他自己感觉两次都很一致。**

### ⭐ 核心定理

> ## 决策效用看的是"峰 + 终"，而经验效用看的是"全程之和"。
> ## 于是：**记忆自我替经验自我做决定，系统性买错。**

写成可操作的等式：

```
经验效用   =  ∫ u(t) dt              （全程的和，包含时长）
决策效用   =  (峰值 + 终点) / 2       （两个点，不含时长）

⇒  决策效用 − 经验效用 ≠ 0，且符号可预测
   （当结尾好转 → 记忆偏好更长、更痛的那次体验）
```

**这跟另外三份的核心定理是同一个形状：**

| 模型 | 核心定理 | 形式 |
|---|---|---|
| 小岛经济学 | 财富 = 产能；货币/债务 = 索取权 | 实物 vs 凭证 |
| 博弈论 | 内卷 = 帕累托最优 − 纳什均衡 | 两个点的距离 |
| 乌合之众 | 群体意见 = 最响意见 ≠ 平均意见 | 两个量的错位 |
| **思考快与慢** | **决策效用 = 峰终均值 ≠ 经验效用的积分** | **两个积分的不等** |

**四本都在讲同一件事：系统会停在一个跟"应该"不一样的地方，而且它很稳。**
前三本说"停在哪"，这一本说"为什么你的大脑觉得停在那里是对的"。

## §4 四条因果回路

### 回路 A：认知紧张 ⇄ 系统 2 的开关回路（唯一的刹车）

```
        遇到需要费力的任务
               ↓
        认知紧张 ↑（瞳孔放大、心跳上升）
               ↓
        ★ 系统 2 被叫醒
               ↓
        投入注意力，开始检查
               ↓
        任务被解决 → 紧张回落
               ↓
        系统 2 立刻关机，回到默认放行
```

**这是一条负反馈回路，也是全书唯一的刹车。**
但注意它的三个致命弱点：

```
① 延时：系统2 上线需要几百毫秒，系统1 的答案早就交卷了
② 容量：串行、极窄。一次只能检查一件事，检查 A 就没法检查 B
③ 燃料：可耗竭。连续做需要自控的事之后，它会拒绝上线
        （⚠️ "燃料可耗竭"这一条 = 自我损耗，已被元分析打脸，见 §8）
```

> **刹车是真的，但它又慢、又小、又懒。**
> 实战含义：**不要指望在当下抓住偏差，要在设计阶段就装好护栏**（§6）。

---

### 回路 B：确认自锁回路（WYSIATI 的正反馈）

```
      形成初步印象（系统1，<1 秒）
               ↓
      系统1 只检索"与之一致"的证据（可用性偏向）
               ↓
      证据一致 → 故事更连贯 → 确信度 ↑
               ↓
      确信度 ↑ → 更不觉得需要检查（系统2 不上线）
               ↓
      反例从未被检索 → 印象完好无损（回到起点）
```

**自锁点**：回路里"检索反例"这一步**从来没有被执行过**，因为没有人要求它执行。
**唯一刹车**：**主动的、人为的、破坏流畅度的动作**——把"如果不成立会怎样"写成一句话。

> **关键**：这个回路不需要你"固执"，它只需要你**正常地思考**。
> 这就是为什么"有偏见的思考"和"普通的思考"在体验上完全没有区别。

---

### 回路 C：损失厌恶 ⇄ 参照点漂移回路

```
    持有某物 → 参照点被设为"拥有"
               ↓
    卖出 = 损失（不是"不赚"）
               ↓
    λ ≈ 2.25 倍的痛苦 → 拒绝卖出
               ↓
    继续持有 → 参照点进一步锚定在更高的曾经价格
               ↓
    卖出显得更像损失 → 更拒绝卖出（回到起点）
```

**这是"处置效应"（disposition effect）的引擎**：赚钱的股票急着卖，亏钱的死扛。
**自锁点**：参照点只朝一个方向移动（追高），不会自动下降。**唯一刹车**：

```
把参照点从"我的买入价"改成"机会成本"
   —— 问："如果我今天空仓，我还会买它吗？"
```

> 这一个改写等同于**把参照点从"过去"移回"现在"**，是前景理论最有用的一次应用。

---

### 回路 D：记忆自我 ⇄ 决策回路（全书最后一章）

```
    一段体验结束
        ↓
    ★ 经验自我的数据被丢弃（时长完全不计）
        ↓
    记忆自我保存"峰 + 终"
        ↓
    记忆自我做下一个决定
        ↓
    决定买回来的是"更好的回忆"，不是"更少的痛苦"
        ↓
    下一段体验再次被剪辑（回到起点）
```

**自锁点**：剪辑规则永远不反馈给选择过程——你从来不会发现"我上次其实是痛了 20 分钟，不是 5 分钟"。
**唯一刹车**：决策前把两个账分开记（① 经验账：实际要忍受什么、多久 ② 记忆账：最后会记住什么），
然后问："**我是在为哪一个付钱？**"

> **这是全书唯一一条"知道了就能改"的回路**，因为它的输入（时长）是你不查就永远看不到的量。

## §5 六组算术

### 5.1 琳达问题：合取不可能大于其中一项

**题目**：琳达 31 岁，单身，直率，非常聪明。她主修哲学，学生时代关心歧视与社会公正，参加过反核游行。

```
A：琳达是银行出纳
B：琳达是银行出纳 且 积极参与女权运动
```

**实验原结果（特沃斯基 & 卡尼曼 1983）：约 85% 的被试认为 B 比 A 更可能。**

**这在数学上不可能。** 设：

```
P(A) = 0.05        （琳达是银行出纳的概率）
P(F) = 0.80        （她是女权主义者的概率）

合取上限：  P(A∧B) = P(A) × P(F|A) ≤ P(A) = 0.05
```

**即最有利的假设下**，取 P(F|A) = 1（所有银行出纳都是女权主义者）：

```
P(A∧B) = 0.05 × 1.00 = 0.05
P(A)   = 0.05
差额    = 0        ← 这是理论最好情况
```

**取一个现实值** P(F|A) = 0.4：

```
P(A∧B) = 0.05 × 0.40 = 0.02
P(A∧B) / P(A) = 0.02 / 0.05 = 0.40     ← B 最多只有 A 的 40%
```

**但 85% 的人选了 B。** 也就是说：

```
知道这一约束的人  : 15%
违反这一约束的人  : 85%
违反率            : 85% − 15% = 70 个百分点
```

> ## 结论
> **"更详细的故事"感觉更可能，但永远不可能更可能。**
> 每往故事里加一个细节，概率只可能下降或不变 —— **永不上升**。
> 系统 1 用**代表性**（这个故事像不像琳达）替代了**概率**（这有多少可能）。
> 故事越丰富，代表性越高，概率越低。**两者方向完全相反 —— 这就是偏差的来源。**

**直接搬到现实**：一份写得越细的商业计划、一条链条越长的看多逻辑，**它的成立概率只会更低，不会更高**。
而你的确信度会更高。**确信度与正确率在这里出现了系统性反向。**
### 5.2 小数定律：抛 3 次硬币不足以判断硬币有问题

**问题**：连抛 3 次，全是正面。这枚硬币有问题吗？

**先算"3 次全正"在公平硬币下的概率**：

```
P(HHH) = 0.5³ = 0.125 = 12.5%
```

**12.5% 不是罕见事件** —— 每 8 组三连抛就有 1 组是这样。
所以观察本身**几乎不提供任何信息**。

**那要多少样本才够？** 检验 H₀: p = 0.5 vs H₁: p = 0.75（"有问题的硬币"），
α = 0.05（双尾），power = 0.80，用正态近似：

```
p₀ = 0.50,  p₁ = 0.75
效应量（Cohen's h）= 2·arcsin(√0.75) − 2·arcsin(√0.50)
                  = 2(1.0472) − 2(0.7854) = 0.5236

n = (z_{α/2} + z_β)² / h²
  = (1.96 + 0.84)² / 0.5236²
  = 7.84 / 0.2742
  = 28.6 → 29
```

**修正（连续性校正 + 保险）后取 —— 约 60 次。**

```
直觉给的样本量        : 3 次
正确推断需要的样本量  : ≈ 60 次
倍数                  : 60 / 3 = 20 倍
```

**这就是小数定律**：系统 1 对样本量**完全不敏感**，只对**结果的极端程度**敏感。

**而极端程度恰好 ∝ 1/√n**：

| n | 出现"全正/全负"的概率 | 你的反应 |
|---|---|---|
| 3 | 2 × 0.5³ = **25%** | "这硬币有问题！" |
| 10 | 2 × 0.5¹⁰ = **0.2%** | "确实有点意思" |
| 60 | 2 × 0.5⁶⁰ ≈ **1.7 × 10⁻¹⁸** | "这硬币肯定被动过手脚" |

> ## 结论
> **n 越小，极端结果越常见，而人对极端结果的反应强度不变。**
> 于是："今年这个基金连续 3 年跑赢"、"这个医生前 4 个病人都活了"、
> "我们部门前 2 个我招的人都很好" —— **这些都是 n=3 的硬币。**
> **样本越小，越容易出极端结果，也越容易被当成长本事。**
> 这不是运气好坏的问题，是**极值统计**的必然。

**并且**：向平均值回归在 n 小的场合**力量最大**。
小样本的极端表现里，噪声占比最高 → 下一步回到均值的力量也最强。
**"热手"和"手冷"常常只是上一个极值在回归。**

### 5.3 均值回归：卡尼曼给以色列飞行教官的反馈（全书最锋利的一组）

**背景**：卡尼曼受邀给以色列空军飞行教官讲课，讲"奖励比惩罚有效"。
讲完后，一位资深教官当场反驳：

> "我不同意。我这些年一直在骂表现差的学员，他们下一次几乎总是飞得更好；
> 我也表扬飞得特别好的，结果下一次他们几乎总是更差。
> 所以是惩罚有效、奖励有害。"

**卡尼曼说：那一刻，他觉得自己讲的东西被当面证伪了。**
**但他随即意识到：这是均值回归，不是因果。**

**算术**。用两向随机效应模型（飞行表现 = 稳定能力 + 当次噪声）：

```
学员稳定能力  a ~ N(0, 1)        σ²_a = 1
当次噪声      ε ~ N(0, 0.6²)     σ²_ε = 0.36
本次表现      X₁ = μ + a + ε₁ ，下一次 X₂ = μ + a + ε₂
取 μ = 0，两次噪声独立

相关 ρ = σ²_a / (σ²_a + σ²_ε) = 1 / 1.36 = 0.735
```

**表扬/责骂按极端程度筛选**（约 6.7% 的架次）：

```
表扬线：X₁ ≥ +1.5        责骂线：X₁ ≤ −1.5
```

**二元正态的条件期望**：E[X₂ | X₁] = μ + ρ(X₁ − μ) = 0.735 · X₁

```
表扬组：E[X₂ | X₁ = +1.5] = 0.735 × 1.5 = +1.10
责骂组：E[X₂ | X₁ = −1.5] = 0.735 × (−1.5) = −1.10
```

| 组 | 本次 X₁ 均值 | 下次 X₂ 期望 | 变化 |
|---|---|---|---|
| **被表扬组** | +1.5 | +1.10 | **−0.40（变差）** |
| **被责骂组** | −1.5 | −1.10 | **+0.40（变好）** |

**这是纯粹的统计假象。表扬和责骂一秒钟的因果作用都没有。**

**那么真因果有多大空间？** 设表扬的真实因果效应 = c，则观察到的变化 = c − 0.40。

```
若 c = 0        → 观察 −0.40（表扬后显著变差）
若 c = +0.20    → 观察 −0.20（仍然变差）
若 c = +0.40    → 观察  0.00（看不见任何效果）
若 c = +0.60    → 观察 +0.20（这才看得见"表扬有效"）
```

> **关键的量级问题**：回归效应是 **0.40**，而真实反馈效应通常在 0.1–0.3 量级。
> **也就是说，回归效应比你想测量的那个效应还大** —— 所以在这个场景里，
> **"表扬有效"这件事在数据里根本不可能显形，无论它是不是真的。**

**这就是卡尼曼 1973 年的论文标题：《On the Psychology of Prediction》里的核心洞见。**
他把这次经历称为**他自己一生中最有用的一个领悟**，也承认：

> **"我花了十几年才让这位教官相信，他看到的因果是假的。"**

> ## 结论
> **极端的表现之后必然跟着一次更平庸的表现 —— 不需要任何原因。**
> 于是："惩罚有效、表扬有害"这条从真实数据中得出的结论，**是错的**。
> **它之所以看起来对，正是因为它是从数据里学出来的。**
> **实战推论**：任何一个"业绩暴差之后我出手整顿，业绩就好了"的成功案例，
> 都有一半以上是均值回归。**要判断它是不是真有效，唯一的办法是留一个对照组。**

**这也是"后见之明偏差"的温床**：回归发生后，人会给它编一个因果故事（"他被骂醒了"）。

### 5.4 损失厌恶：λ ≈ 2.25 下的具体决策

**场景**：抛一枚公平硬币。

```
正面：+100 元
反面：−100 元
期望值 = 0.5(+100) + 0.5(−100) = 0
```

**收益与损失对称下，理性人应该无所谓。但绝大多数人拒绝这个赌局。**

**用前景理论的价值函数算**。取

```
v(x) = x^0.88          （敏感度递减，α ≈ 0.88）
λ   = 2.25             （损失厌恶系数）
参照点 = 0
```

**赌局的前景价值**：

```
V = 0.5 · v(+100) + 0.5 · λ · v(−100)
  = 0.5 · 100^0.88 + 0.5 · 2.25 · (−100^0.88)

100^0.88 = e^(0.88 × 4.6052) = e^4.0526 = 57.5

V = 0.5(57.5) + 0.5(2.25)(−57.5)
  = 28.75 − 64.69
  = −35.94          ← 严重为负，所以拒绝
```

**反推"要多大收益才肯玩"（令 V = 0）**：

```
0.5 · G^0.88 = 0.5 · 2.25 · 57.5
G^0.88 = 129.4
G = 129.4^(1/0.88) = e^(4.8631/0.88) = e^5.5263 = 251.3 元
```

**若 α = 1（线性价值函数）**，同样的 λ 给出：

```
G = λ · 100 = 2.25 × 100 = 225 元
```

| 模型 | 要求的最小收益 | 隐含的赔率要求 |
|---|---|---|
| 期望值（风险中性） | 100 元 | 1 : 1 |
| 前景理论 α=1, λ=2.25 | **225 元** | 2.25 : 1 |
| 前景理论 α=0.88, λ=2.25 | **≈ 251 元** | 2.51 : 1 |

**直观刻度**（λ = 2.25）：

```
亏 100 元的痛  ≈  赚 225 元的爽
亏 100 元的痛  ≈  赚 250 元的爽（加上递减敏感度后）
```

> ## 结论
> **你会为"避免损失"支付 2.25 倍的代价 —— 而这个系数是你感觉不到的。**
> 它不表现为"我害怕"，它表现为"**这个价格不合理**"。
> **这就是为什么人在亏损时会做出明显违反期望值的决定：对他来说，参照点以下的每一块钱，重量是上面的 2.25 倍。**
>
> **两个方向的实战含义（方向相反，都要记住）**：
> ```
> 防御：我用 2.25 倍的溢价买"不会亏"，这是有代价的，要标价。
> 进攻：别人也在用 2.25 倍定价。所以恐慌中出现的机会，其折价也是 2.25 倍量级。
> ```

### 5.5 峰终定律：一段体验的记忆评分

**场景**：卡尼曼的结肠镜实验（Redelmeier & Kahneman, 1996）。
病人每 60 秒报告一次当时的疼痛（0–10）。

| | **病人 A（短）** | **病人 B（长）** |
|---|---|---|
| 时长 | **2 分钟** | **4 分钟**（多出的 2 分钟只有轻度不适） |
| 疼痛序列 | 8, 8, 8, 8 | 8, 8, 8, 8, 6, 6, 4, 4 |
| 峰值 | 8 | 8 |
| 终点 | **8** | **4** |
| 经验效用（∫u dt，疼痛分钟数） | 8×2 = **16** | 8×2 + 6×2/2 + 4×2/2 = **26** |

**经验账**：B 多受了 **10 个疼痛单位·分钟**（多 62.5%）。

**记忆账（峰终定律）**：

```
记忆评分 = (峰值 + 终点) / 2

A: (8 + 8) / 2 = 8.0
B: (8 + 4) / 2 = 6.0
```

| | 经验账（越高越痛） | 记忆账（越高越糟） |
|---|---|---|
| 病人 A | **16** | **8.0** |
| 病人 B | **26** | **6.0** |
| 谁更糟 | **B 更糟（×1.63）** | **A 更糟（×1.33）** |

**实验的实测结果**：病人 B **更愿意再来一次**。
**倒挂幅度**：

```
经验倒挂：26 / 16 = 1.63       B 多受了 63% 的痛
记忆倒挂：8.0 / 6.0 = 1.33     A 的记忆却糟 33%
评分差  ：8.0 − 6.0 = 2.0 分
```

**换个量化的方式看"时长被忽视"到什么程度**：

| 对比 | 长度差 | 峰值差 | 终点差 | 记忆评分差 |
|---|---|---|---|---|
| 例子 A vs B | 2.0 分钟（×2） | 0 | **−4** | **−2.0** |
| 卡尼曼的冷手实验 | 30 秒 | 0 | **−1.3（14℃ vs 15℃）** | 多数人选择**更长的那个** |

**冷手实验更狠**：把一只手泡在 14℃ 冰水 60 秒（短、痛苦）；
或者泡 14℃ 冰水 60 秒**之后**再多泡 30 秒，水温升到 15℃（长、总量更痛）。
**多数被试选择"再来一次长的那个"。**

```
长版本额外承受的痛苦：30 秒 × ~14℃ 的不适
长版本换来的记忆改善：终点从 14℃ → 15℃
结论：30 秒的真实痛苦，被 1℃ 的结尾改善完全抹掉
```

> ## 结论
> **记忆不是录像，是剪辑。剪辑规则：最高潮 + 结尾，除以二，时长权重 = 0。**
> 于是出现一个残酷的结论：**你可以通过"把结尾弄好一点"来让人愿意多受苦。**
> 医生可以用它减少病人的复检抗拒（这是卡尼曼自己主张的应用）；
> 但它也是**所有"精彩结尾"骗局**的机制。
>
> **对个人的用法**：一段体验中你能控制的两件事 —— **把峰值推高，把结尾安排好**。
> 中间过程对回忆的贡献接近于零。

### 5.6 框架效应与心理账户：同一结果的三种标价

**场景**：同一笔钱，三种描述方式。

```
描述 1：给你 1000 元，然后让你从以下选一个
        A：确定再得 500 元
        B：50% 概率再得 1000 元
描述 2：给你 2000 元，然后让你从以下选一个
        C：确定少得 500 元
        D：50% 概率不少得，50% 概率少得 1000 元
```

**注意**：A = C，B = D，**客观上是同一组选择**。但参照点不同：

```
描述 1 的参照点 = 1000（已到手）
  A: +500（确定）
  B: +1000 (50%) / +0 (50%)     → 期望 +500

描述 2 的参照点 = 2000（已到手）
  C: −500（确定）
  D: −0 (50%) / −1000 (50%)     → 期望 −500
```

| | 描述 1（收益框架） | 描述 2（损失框架） |
|---|---|---|
| 类型 | 收益域 | **损失域** |
| 主导反应 | **风险厌恶** | **风险寻求** |
| 主流选择 | A（确定拿 500） | D（赌一把避免亏） |
| 实测比例（经典结果） | 约 **84% 选 A** | 约 **69% 选 D** |

```
选"确定"的比例：84%（收益框架） → 31%（损失框架）
摆动：84 − 31 = 53 个百分点
```

**同一组客观结果，换个参照点，多数人的选择翻面。**

**心理账户加成**：钱的来源不同，花钱意愿完全不同。设同样 500 元：

| 来源 | 心理账户 | 花掉的概率（典型水平） |
|---|---|---|
| 工资 | "血汗钱" | 低（约 30%） |
| 年终奖 | "意外之财" | 中（约 60%） |
| 中彩票 / 赌场赢的 | "庄家的钱"（house money） | 高（约 80%） |

**这个账户划分在经济学上完全没有依据** —— 钱是可替代的（fungible）。**但在心理上，它决定了同样的 500 元值多少。**

> ## 结论
> **框架不变事实，框架决定参照点，参照点决定你选哪个。**
> ① **"这是收益还是损失"不是客观属性，是描述方式。** 谈判、定价、汇报都在这上面做文章。
> ② **心理账户让钱变得不可替代**，这一点同时是 bug 和 feature：
> ```
> bug    ：把"省下的 500"和"赚到的 500"分开，于是错过最优配置
> feature：把"赌场赢的钱"单独隔离，是防止赌徒心态污染本金的唯一有效手段
> ```

## §6 策略与决策表

**用法**：先定位你的**位置**——我是在**判断**、在**决策**、还是在**设计流程**？
三个位置需要的动作完全不同。

| 场景 | 该做什么 | 机制依据 |
|---|---|---|
| **我要做一个重要判断** | 强制写下"**如果我错了，最可能因为什么**"，写在判断**之前** | §4 回路 B：反例从来没被检索过 |
| **我看到一个特别顺的故事** | 数细节：每加一个细节，概率只可能下降。**故事越完整，成立概率越低** | §5.1 合取不可能大于其中一项 |
| **我要评估一个"最近表现"** | 先算：这次的极端程度，有多少是**回归**能解释的？ | §5.3 均值回归 |
| **有人给我一段历史因果解释** | 问："**当时**有几个人这么预测过？" | 后见之明偏差 + 叙事谬误 |
| **我要说服一个人（不是群体）** | 给**具体案例 + 具体数字**。抽象统计说服力最低（但对群体有效，见《乌合之众》） | 个案压过统计 |
| **我在做长期痛苦的决策（治疗/项目）** | 分开记两笔账：**经验账（要痛多久）** 和 **记忆账（会记住什么）** | §4 回路 D |
| **我发现"这次感觉特别确定"** | 确信度只反映**故事连贯度**。**把连贯度和证据量分开打分** | 支柱二 WYSIATI |
| **我持有亏损仓位** | 把参照点从"我的成本"改成"**如果我今天空仓，还会买吗**" | §4 回路 C：参照点是唯一可手动移动的量 |
| **我要设计一个流程 / 制度** | 不要指望"当场更理性"。**改变信息呈现方式**（默认值、字体、顺序、分解） | §4 回路 A：刹车又慢又小又懒 |
| **我要给下属反馈** | 知道表扬后变差**大概率是回归**。**不要因此改策略** —— 去要一个对照组 | §5.3 |
| **我在评估"专家预测"** | 记住：**专家在自己领域内的表现，也常常不比简单公式好**。要预测就用简单规则 + 少量关键变量 | 全书结论之一（Meehl 传统） |
| **我在做痛苦体验的安排** | 优化**结尾**，别优化总时长。中间过程对回忆的贡献接近 0 | §5.5 峰终定律 |

### 两条反直觉提醒

> **① "知道偏差"基本不能消除偏差**
> 卡尼曼自己在书里反复承认：**他讲了一辈子偏差，仍然照犯。**
> 直觉偏差不会被知识关掉（§4 回路 A 的系统 1 无法关闭）。
> 所以这本模型**不是让你"更理性"**，是让你**去设计环境**：
> ```
> 靠不住的  ：我下次会注意
> 靠得住的  ：把默认值改掉、把参照点换掉、把决策写下来、把两笔账分开
> ```
> **能改的是流程，不是直觉。**

> **② "均值回归"是这个模型里最容易被误用的一条**
> 它不是"一切都会回到平均"。它只在**你观察到一次极端表现**时适用。
> 而且它**同时**有两个方向的风险：
> ```
> 过度使用：把真实的因果效应当成回归 → 放弃有效的管理手段（§5.3 教官的错误）
> 使用不足：把回归当成自己的功劳 → 归因错误，学会一套错理论
> ```
> **唯一的分辨办法：留一个对照组。** 没有对照组时，两组解释都说得通。

## §6.5 专题：两个自我（decision utility vs experienced utility）

> 这是全书最后一章，也是卡尼曼自己说"如果只记一件事，记这个"的地方。

### 三个"效用"必须分开

```
① 经验效用（experienced utility）
   你实际过的那段生活，逐秒积分。包含时长。

② 决策效用（decision utility）
   你在选择时赋予某结果的主观权重。由记忆自我提供。

③ 预测效用（predicted utility）
   你在选择前对"未来会有多爽/多痛"的预测。
   （这个恰恰是最不准的 —— 见下）
```

### 三个效用之间三个可预测的裂缝

```
裂缝 A：峰终 vs 全程
   记忆自我丢弃时长 → 决策效用系统性偏离经验效用
   证据：结肠镜、冷手实验（§5.5）

裂缝 B：预测 vs 实际
   预测效用偏向"极端、聚焦于差异、忽略适应"
   证据：愿意为通勤距离付的钱，远超过通勤带来的实际幸福差异

裂缝 C：聚焦错觉（focusing illusion）
   你在想什么，什么就显得更重要
   "你有多幸福？" 取决于你先想到的是天气、婚姻还是收入
```

### 结论：三个必须分开的问题

| 问题 | 谁在回答 | 卡尼曼的立场 |
|---|---|---|
| 我**体验**得好吗？ | 经验自我 | 客观可测（instant utility） |
| 我**记得**好吗？ | 记忆自我 | 只要峰 + 终，时长无效 |
| 我**应该**最大化哪个？ | **没有客观答案** | 卡尼曼自己说：**"我是我的记忆自我"** —— 但这只是他的选择，不是定理 |

> ## 这是全书最诚实的一段
> **卡尼曼没有告诉你应该最大化哪个自我。**
> 他说的是：**你必须知道有两个，因为你在替你其中一个做决定时，会以为在替另一个。**
> 所有的"我明明很痛苦，为什么还怀念"、"这段经历明明值得，为什么我不想再来一次"，
> 都是这个错位。

## §7 八个现场检验

**拿这八条去扫任何一个你正在做的判断。每条一分钟。**

```
① 置换检验
   我回答的，是不是我被问的那个问题？
   → 把问题复述一遍，看你的答案有没有真的回答它。
   （最典型：被问"这家公司好不好"，你答的是"我喜不喜欢它"）

② 连贯度检验
   我的确信度，来自证据数量，还是故事连贯度？
   → 数一下你手上的独立证据有几条。少于 3 条，你的确信度是故事给的。

③ 样本量检验
   这个结论基于 n = ？
   → 如果是 n ≤ 5 且结果很极端，先当作噪声，别当信号。

④ 回归检验
   我看到的"变化"，有没有可能是均值回归？
   → 问：上一次的起点有多极端？（越极端，回归越大）
   → 问：有对照组吗？没有，就两种解释都成立。

⑤ 参照点检验
   我的参照点是"我的成本 / 昨天 / 别人的收益"还是"现在的机会成本"？
   → 换成机会成本重算一次，看结论变不变。

⑥ 框架检验
   同一件事，把它反过来描述一遍，我的选择会不会变？
   → 会变，说明我选的是框架，不是结果。

⑦ 时长检验
   这件事我实际要承受多少分钟 / 多少天？
   → 我有没有在看这个数字，还是只在看"结尾会怎样"。

⑧ 两笔账检验
   我是在为经验自我做决定，还是为记忆自我做决定？
   → 把两笔账分别写在纸上。如果你从没分开写过，你的决定是记忆自我做的。
```

## §8 诚实边界：这本书哪里已经被证伪

> **这一节必须比前面所有节都认真读。**
> 心理学在复制危机里，而卡尼曼的书恰好横跨了危机前后。
> **笼统地说"这本书都被推翻了"是错的；装作没问题也同样是错的。**
> 下面按**证据强度**逐项分级。

### 8.1 逐项证据分级表

| # | 内容 | 证据强度 | 具体情况 |
|---|---|---|---|
| 1 | **系统 1 / 系统 2** | ⚠️ **隐喻，非神经科学** | 大脑里**没有**这两个系统。这是一个组织现象的教学标签，卡尼曼本人在书里也说是"有用的虚构"。**不要当解剖结构用。** 双过程理论作为家族仍然有解释力，但"两个系统"这个具体形式被批评为过度简化 |
| 2 | **启动效应（priming）** | ❌ **基本失败** | 2012 年 Nobel 得主本人被卷入：**老年启动（看"老年"词走得更慢）** 的多实验室复制（Doyen et al. 2012）**失败**；**金钱启动、 cleanliness 启动**同样未能复制。**卡尼曼 2017 年公开承认**：书中那一章（"Lazy System 2"相关内容）"**我写书时的证据比我以为的弱得多**"，并称其为"**我这本书里最弱的一章**"。**应整块降级为"未证实"** |
| 3 | **自我损耗（ego depletion）** | ❌ **效应量接近零** | Hagger et al. 2016 的 23 实验室预注册复制：**效应量 d ≈ 0.04，统计上不显著**。2018 年的元分析给出极小效应。**"意志力是有限燃料"这个说法应从模型中删除**——但注意：**§4 回路 A 的"系统 2 会疲劳"这一条要跟着降级**，刹车依然存在（注意力有限是稳的），只是"耗竭"的机制不成立 |
| 4 | **社会启动（social priming）** | ❌ **不能复制** | 见 #2。这一族效应（老年、金钱、上帝、洁净）是复制危机里受创最重的区域。**Rolf Zwaan 等人数十次失败的直接复制**，是最初的证据 |
| 5 | **小岛型/统计类事实** | ✅ **稳（本质是数学）** | §5.1 琳达问题、§5.2 小数定律、§5.3 均值回归、§5.6 框架效应的**存在性**——这些**不是经验规律，是概率论推论或反复复制的稳健现象**。合取不可能大于其中一项，是定理，不是发现 |
| 6 | **锚定效应** | ✅ **稳（最强的一族）** | 大规模复制（Many Labs 1, 2014）**成功**。锚定是整个启发式家族里复制记录最好的。⚠️ 但**机制仍有争议**：锚定-调整 vs 启动式通达，两者谁在起作用没有定论。**现象稳，解释不稳** |
| 7 | **损失厌恶 / 前景理论** | ✅ **较稳（但有边界）** | λ ≈ 2–2.5 的大量估计仍然站得住。⚠️ **但争议点**：λ 的估计值高度依赖实验范式，用**选择实验**得到的 λ 常常接近 1；"损失厌恶是不是一个统一系数"受到 Gal & Rucker (2018) 的挑战。**实用上仍可用，但不要当成一个精确常数** |
| 8 | **框架效应** | ✅ **稳** | 亚洲疾病问题、手术存活率/死亡率框架，多次复制成功。**是行为经济学里最可靠的现象之一** |
| 9 | **峰终定律 + 时长忽视** | ✅ **稳（最稳的一族）** | 原始结肠镜、冷手实验，以及后续大量领域（消费、医疗、度假）的复制都支持。⚠️ 细节有争论（峰与终的相对权重、是否有多个峰），**但"时长权重接近零"这个核心结论非常稳** |
| 10 | **后见之明偏差 / 叙事谬误** | ✅ **稳** | 1970 年代至今反复复制。**没有争议** |
| 11 | **计划谬误 / 外部视角** | ✅ **稳** | 见 Flyvbjerg 的大量工程项目数据 |
| 12 | **四重模式** | ✅ 现象稳 | 风险态度在四个格子里的倒置，数据支持充分。⚠️ **但解释依赖前景理论的参数化**，而后者有 #7 的争议 |
| 13 | **专家直觉的力量（"技能习得"那一部分）** | ✅ 稳 | 有反馈 + 有规律的环境 → 直觉可信。这个条件化结论**没有被推翻**，且是全书最实用的部分 |
| 14 | **"专家预测不如简单公式"** | ✅ 稳 | Meehl 传统、Tetlock 的《专家的政治判断》，结论持续成立 |

### 8.2 三个必须说清的元问题

**① "这本书被推翻了"是错误总结。** 准确的说法是：

```
被推翻的：启动效应、社会启动、自我损耗  ← 恰好是"系统1如何自动运行"的证据基础
站得住的：锚定、损失厌恶、框架、峰终、后见之明  ← 是"判断如何出错"的证据基础
```

荒谬之处：卡尼曼最著名的那些**偏差**大多活下来了，死得最惨的是他用来证明
"**系统 1 是自动的**"的那批实验。**"两个系统"这个隐喻失去了最强的一根经验支柱 —— 但这不否定偏差本身。**

**② 卡尼曼本人的处理方式值得单独记一笔。** 他 2017 年公开说：启动效应那一章
"**我写书时以为的证据，比我实际拥有的强得多**"，并承认对复制的重视不够，建议读者对那一章保持怀疑。
**一个诺奖得主主动撤回自己书里最畅销的章节之一 —— 这件事本身就示范了这个模型应该怎么用：当假说来源，不当结论。**

**③ 两条方法论批评（比复制失败更深）**
- **Gigerenzer**：卡尼曼展示了"启发式何时出错"，没展示"何时是对的"。快而省的启发式在真实环境中**常常优于复杂模型**（生态理性）。**这本书只出示了启发式的账单，没出示它的发票。**
- **"偏差"这个标签本身有偏**：把偏离规范模型叫"偏差"，隐含规范模型是对的。而很多场合，规范模型根本不适用。

```
使用本模型的三条纪律：
① 系统1/系统2 当隐喻用，不当脑区用
② 启动 / 自我损耗相关章节，当"待证实"用，不当结论用
③ 锚定 / 损失厌恶 / 框架 / 峰终 / 后见之明 —— 可用，但守住边界
   （λ 不是常数；框架效应有文化差异；峰终的权重仍在争论）

把这本书当"高命中率的假说集"，不是"已经验收的说明书"。
```

## §9 一页纸速查

```
┌──────────────────────────────────────────────────────────────────┐
│  核心公式                                                         │
│                                                                  │
│    判断(难题) = 系统1(置换(难题 → 简单题)) → 系统2 事后背书        │
│                                                                  │
│    ★ 决策效用 = (峰值 + 终点)/2  ≠  经验效用 = ∫u(t)dt            │
│      —— 记忆自我替经验自我做决定，系统性买错                       │
└──────────────────────────────────────────────────────────────────┘

【两台机器】
  系统1  快 / 自动 / 不可关闭 / 出错方式 = 偏差
  系统2  慢 / 费力 / 默认关机 / 出错方式 = 懒惰（只背书，不检查）
  ⚠️ 这是隐喻，不是脑区

【三根支柱】
  ① 认知放松 ⇄ 系统2开关：读起来顺 = 感觉是真的（与真假无关）
  ② WYSIATI：只用看得见的信息拼故事；确信度 ∝ 故事连贯度，∝̸ 证据量
  ③ 参照点 + 损失厌恶(λ≈2.25) + 敏感度递减 → S 形价值函数 → 四重模式

【四个翻转（最容易低估的三条）】
  反馈改进判断 → 多数反馈是噪声；教官案例是均值回归，不是因果
  损失收益对称 → λ≈2.25：亏 100 的痛 ≈ 赚 225 的爽
  记忆是录像机 → 记忆是剪辑；时长权重 ≈ 0
  我先看证据再判断 → 我先判断再找证据（顺序是反的）

【四条回路】
  A 紧张⇄系统2   负反馈，是唯一刹车，但：慢 / 窄 / 会累
  B 确认自锁     印象 → 只找一致证据 → 更连贯 → 更确信 → 更不检查
  C 损失厌恶     持有 → 参照点=拥有 → 卖=损失 → 不卖 → 参照点更高
  D 记忆自我     体验结束 → 丢弃时长 → 存"峰+终" → 用它做下个决定

【六组算术】
  琳达问题   加一个细节，概率只会 ↓。85% 的人选了合取 → 违反率 70 个百分点
             ★ 故事越完整，成立概率越低；你的确信度却越高
  小数定律   连抛 3 正 → 12.5%，不罕见。正确推断需 ≈ 60 次 = 20 倍
             ★ 样本越小，极端结果越常见，而人对极端的反应不变
  均值回归   表扬组 +1.5 → +1.10（−0.40）；责骂组 −1.5 → −1.10（+0.40）
             ★ 教官看到的全是回归。回归量级(0.40) > 真实反馈效应(0.1–0.3) → 显不了形
  损失厌恶   λ=2.25, α=0.88：拒绝 50/50 的 100 元；要求 ≈251 元才肯玩
             ★ 你会用 2.25 倍溢价避免损失，而你感觉不到这个系数
  峰终定律   疼痛 2 分钟(8,8,8,8) vs 4 分钟(8,8,8,8,6,6,4,4)
             经验账 16 vs 26（B 更痛 63%）／记忆账 8.0 vs 6.0（A 更糟）
             ★ 实测 B 更愿意再来一次。30 秒的痛苦被 1℃ 的结尾改善抹掉
  框架效应   "再得 500" vs "少得 500"（客观同一）→ 选确定项 84% vs 31%
             ★ 框架不变事实；它移动参照点，参照点决定你选哪个

【六个偏差的实战读法】
  锚定      可用，但机制仍在争论 —— 用来解释"为什么谈判先出价有用"
  可得性    容易想起 ≠ 更常发生（K 打头的词 vs 第三位是 K 的词）
  代表性    像不像 ≠ 有多可能。故事越典型，概率越低
  后见之明  结果一旦已知，当时的记忆立刻被重写
  过度自信  确信度 ∝ 连贯度；WYSIATI 让少信息也能产生高确信
  叙事谬误  过去被压成因果链，而真实原因是噪声

【八个检验】
  ①置换   我回答的是被问的问题吗？
  ②连贯度 确信来自证据量还是故事连贯度？
  ③样本量 n=？n≤5 且极端 → 当噪声
  ④回归   上次起点多极端？有对照组吗？
  ⑤参照点 换成"今天空仓还会买吗"重算
  ⑥框架   反过来描述，我的选择变不变？
  ⑦时长   我实际要承受多少分钟？
  ⑧两笔账 我在为经验自我还是记忆自我做决定？

【边界（按证据强度分档）】
  ❌ 启动效应 / 社会启动 —— 复制失败。卡尼曼 2017 年公开承认该章证据"弱得多"
  ❌ 自我损耗 —— 预注册复制 d≈0.04。"意志力是有限燃料"不成立
  ⚠️ 系统1/系统2 —— 隐喻，不是神经科学；"两个系统"的形式被指过度简化
  ⚠️ 前景理论 λ —— 现象稳，但 λ 不是常数，估计依赖范式
  ✅ 锚定 / 框架 / 峰终 / 后见之明 / 计划谬误 / 专家不如公式 —— 复制良好
  ✅ 合取谬误 / 小数定律 / 均值回归 —— 本质是数学，不是经验发现
  ★ 这本书是"高命中率的假说集"，不是"已验收的说明书"

【一句收尾】
  你从来不是在思考那个难题，
  你只是在交一个更容易的题的答案，
  然后让系统 2 替你签字。
  真正的自由不在"想得更准"，
  而在**决定把哪个问题交上去，以及为哪一个自我做决定**。
```

| 核心定理 | 财富 = 产能；货币 = 索取权 | 内卷 = 帕累托最优 − 纳什均衡 | 群体意见 = 最响意见 ≠ 平均意见 | 决策效用 = 峰终均值 ≠ 经验效用积分 |
| 出错的层次 | 制度层（凭证膨胀） | 结构层（均衡锁死） | 社会层（认知被劫持） | **个体层（判断被置换）** |
| 谁在犯错 | 一个经济体 | 一群理性人 | 一个群体 | **你的系统 1** |

> **这一本补上了前三本缺的那一环。**
> 《乌合之众》说"群体降智"，但没说**单个人为什么本来就不可靠**。
> 本书回答：**因为个体从来不是那个理性主体，群体只是把这件事放大到可以观察的程度。**
> **所以先读这一本，再读《乌合之众》会更容易**：
> 群体不是让人变蠢，群体是让人**本来就有的那套简化机制，不再被任何东西约束**。
