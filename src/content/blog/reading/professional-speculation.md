## §0 一句话模型

> ## 决定生死的不是胜率，是**风险管理**；
> ## 不是预测能力，是**期望值和重复次数**。

写成式子：
```
长期结果 = (胜率 × 平均盈利 − 败率 × 平均亏损) × 交易次数

         而   单笔亏损 ≤ 账户 × 1% ~ 2%
```

拆开看，这是**三个独立的乘数**：
```
账户终值 = 初始资金
         × 期望值（每笔的 R 倍数）   ← 由胜率结构决定，不由聪明决定
         × 交易次数                  ← 由系统纪律决定，不由勤奋决定
         × 仓位因子                  ← 由资金管理决定 —— 唯一能杀死前两项的因子
```
**这是全书的发动机。** 它一次解释掉四个悖论：
| 悖论 | 用模型一句话解开 |
|---|---|
| 为什么"看对了"还是亏 | 看对 ≠ 期望值为正。**单笔结果与长期期望是两个量** |
| 为什么高手胜率只有 40% | 40% 胜率配 3:1 盈亏比 = +0.6R/笔，**比 60% 胜率配 1:1（+0.2R）好三倍** |
| 为什么同一个策略有人赚有人爆 | **策略相同，仓位不同**。下注大小决定生死 |
| 为什么"再等等就能回本"是幻觉 | 亏 50% 要涨 100% 才回本。**回本难度是凸函数** |

> **斯波朗迪原话（意译）**：投机是掌握有利胜算时的下注；赌博是承担无法评估的风险。
> 区别不在于"有没有风险"，而在于**风险是否被量化且被限制**。

**记住这个不对称：收益是线性的，亏损是凸的。**
这跟直觉相反——我们以为"赚 50% 和亏 50% 是对称的"。
**不对称的。亏损对终值的伤害，永远大于同等比例的盈利对终值的贡献。**

## §1 六个反直觉翻转
| # | 你以为 | 实际上是 | 为什么 |
|---|---|---|---|
| 1 | 胜率高才能赚钱 | **低胜率 + 高盈亏比可以远优于高胜率 + 低盈亏比** | 期望值是**胜率与赔率的乘积式**，不是单变量。40%/3:1 = +0.6R，60%/1:1 = +0.2R，**差 3 倍** |
| 2 | 风险是"可能亏多少"，所以该按感觉下注 | **风险是"下注大小"，是可主动设定的唯一变量** | 胜率你不知道、赔率市场给、**只有仓位是你 100% 控制的**。控制的正是唯一能救命的那个 |
| 3 | 亏了要扛住，扛住才有翻身机会 | **扛住是小概率的大灭绝，止损是高频的小出血** | 止损的痛苦立刻兑现（可感知），爆仓的痛苦延后（不可感知）→ **大脑系统性地做错选择** |
| 4 | 止损是承认错误，伤自尊 | **止损是买入"继续下注的权利"** | 你付的不是亏损，是**留在牌桌上的保险费**。出局的人没有下一笔 |
| 5 | 要学会预测才能赚钱 | **市场是唯一的裁判，你无法说服它** | 预测是"我要市场怎样"，跟随是"市场正在怎样"。**前者制造立场，后者制造仓位** |
| 6 | 交易靠天赋和盘感 | **能长期活下来的是被机械化、可重复的流程** | 主观判断无法审计、无法复盘、无法改进。**不可重复 = 不可积累 = 不可学习** |

**其中第 2、3、6 条最容易被低估，也最有杠杆。**
第 2 条是全书全部算术的来源；第 3 条是对人类大脑的**结构性对抗**；第 6 条是"能不能教"的分界线。

## §2 核心区分：什么才算"投机"

**这是全书最容易被跳过、但最关键的切割。** 斯波朗迪花在定义上的篇幅，比花在方法上的还多。
```
投机的成立条件：
  ① 判断对象是未来的价格变动（不是"相信某家公司"）
  ② 判断基于可重复的方法（可写下来、可复盘、可交给别人执行）
  ③ 风险被预先量化（知道最坏情况是多少，且知道它何时发生）
  ④ 风险被预先限制（单笔亏损有上限，且上限由仓位控制）
```
**反例**：听了消息买入，跌了以后改口说"长期看好" → **不是投机，是赌博**。
**正例**：定义好"跌破某价位就认错离场，离场只亏账户 1.5%" → **这才是投机**。

> **关键推论**：**"赌"与"投机"的区别不是风险大小，是风险是否被评估。**
> 一个仓位很小但完全没想清楚的下注，仍然是赌博。
> 一个仓位很大但风险被量化并被限制的下注，是投机。
> **这里的裁判是"有没有方法"，不是"亏得多不多"。**

### 三个必须拆开的词

| 词 | 对象 | 判断标准 | 失败模式 |
|---|---|---|---|
| **预测** | 未来价格 | 对不对（二元） | 对的时候记住，错的时候忘记 → **自我欺骗** |
| **投机** | 期望值 + 风险 | 是否为正 + 是否可控 | 正期望但仓位过大 → **被方差杀死** |
| **赌博** | 无法评估的风险 | 无标准 | 无法复盘，无法改进 → **重复同样的错误** |

**三者不是程度的差别，是结构的差别。**
预测问的是"我会不会对"；投机问的是"我对的时候赚多少，错的时候亏多少，我承受得起几次错"。

### 趋势的定义（道氏理论的骨架）

斯波朗迪的趋势定义极简，但它是全部方法的地基：
```
上升趋势 = 一系列更高的高点 + 一系列更高的低点
下降趋势 = 一系列更低的高点 + 一系列更低的低点
无趋势   = 二者都不成立（横盘/震荡）
```
**这个定义的三个后果**：
```
① 趋势是"已经发生的事实的序列"，不是"对未来的判断"
   → 所以"跟随"在逻辑上先于"预测"

② 趋势的结束是"序列被破坏"，可以被精确定义
   → 所以 1-2-3 法则和 2B 法则有可能存在（§3）

③ "无趋势"是第三种状态，不是趋势的失败
   → 所以"不做"是一个合法的、经常正确的决策
```

### 1-2-3 法则：趋势反转的三步确认
```
前提：先有一条趋势线（连接近期的高点或低点）

第 1 步：趋势线被突破
         上升趋势 → 价格跌破上升趋势线
         （这是"警报"，不是"信号"）

第 2 步：不再创新高（或不再创新低）
         上升趋势 → 随后的反弹未能超过前一个高点
         （这是"趋势动能耗尽"的证据）

第 3 步：穿越前一个回档高点（或回档低点）
         上升趋势 → 价格跌破前一个回调的低点
         （这是"确认"，此时原趋势被判定为终止）
```
> **三步的顺序不可交换，且必须全部满足。**
> 只满足 1 → 可能只是回踩。
> 满足 1+2 → 趋势变弱，但未反转。
> 满足 1+2+3 → 结构被破坏，**这才是可下注的时点**。

### 2B 法则：假突破的捕获
```
2B 法则（上升趋势末端）：
  价格创出新高  ──→  立刻（很短的时间内）回落到前高之下
                    ↓
              这是一个"失败的突破"
                    ↓
              通常意味着反转已经开始
```
**"2B"的含义**：**第二次**（Second）**突破失败**（Breakout failure）。
即——**创新高这件事本身，就是最后一次卖出的机会**。

> **1-2-3 与 2B 的关系**：
> 1-2-3 是**确认型**（慢、少错、晚），2B 是**预警型**（快、多错、早）。
> 两者是**同一个结构在两个时间尺度上的成像**。
> **1-2-3 给你确定性，2B 给你价格。二者不可兼得。**

## §3 三根支柱与核心定理

### 支柱一：期望值结构 ≠ 单笔结果

交易者最容易犯的认知错误是：**用单笔结果评价方法**。

| 观察对象 | 个体交易者看的东西 | 专业投机者看的东西 |
|---|---|---|
| 单笔盈亏 | ✅ 全部注意力 | 忽略（它是随机的） |
| 胜率 | ✅ 越高越好 | 与赔率**一起**看 |
| **盈亏比** | ❌ 常被忽略 | ✅ **核心变量** |
| **期望值（R/笔）** | ❌ 几乎没人算 | ✅ **唯一有意义的目标函数** |
| **回撤分布** | ❌ 事后才想起 | ✅ **事前用概率算** |
```
一笔交易 = 一个随机事件      （结果不可预测）
一系列交易 = 一个分布         （统计量可估计）
```
> **不是单笔结果"骗"了你，是单笔结果根本不含信息。**
> 抛硬币连出 5 次正面，不能说明硬币有问题。
> 但从单笔结果里找规律的本能，是刻在神经系统里的——**这叫"赌徒的归纳"**。

### 支柱二：风险由仓位控制，不由止损价控制

这是一个**决定性的技术区分**，多数人搞混：
```
止损价 ──→ 决定"我在哪里认错"        （方向问题，市场决定可行性）
仓位   ──→ 决定"我认错时亏多少"      （金额问题，你 100% 决定）

单笔风险金额 = 仓位规模 × (入场价 − 止损价)
             ↑ 这个乘积，可以也必须在开仓前被钉死
```
**关键操作顺序**：
```
① 先定单笔风险上限：账户 × 1.5%
② 再看图表定止损位：跌破某结构就认错
③ 最后反推仓位：  仓位 = (账户 × 1.5%) ÷ (入场价 − 止损价)
```
> **顺序反了，一切全错。**
> 绝大多数人的顺序是"先决定买多少，再看能亏多少"——**这是把方向盘交给市场。**

### 支柱三：机械化不是为了聪明，是为了可重复
```
主观交易的问题链：
  判断无法写下来  →  无法复盘  →  无法区分"方法错"还是"执行错"
                →  无法改进  →  每次都是从零开始

机械化交易：
  规则写下来  →  每笔可归因  →  样本可累积  →  统计量可估计  →  可以改进
```
**机械化的真正价值不是提高胜率，是把"交易"从艺术变成可积累的工程。**
一个胜率只有 40% 但被严格遵守的系统，**优于**一个胜率 60% 但每次凭感觉的系统——
因为**前者的期望值可被统计验证，后者的 60% 可能只是最近三个月的运气**。

---

### ⭐ 核心定理

> ## 长期结果 = 期望值 × 次数 × 仓位因子
> ## 而**仓位因子是唯一能把这整个乘积归零的项**。
>
> 期望值为负 → 慢慢亏死（可救）。
> 仓位过大 → **归零**（不可救，且不可逆）。

展开成可操作的等式：
```
账户终值 N 笔后 = 本金 × ∏(1 + f × Rᵢ)
                     i=1..N

其中 f = 单笔风险占账户比例，Rᵢ = 第 i 笔的盈亏倍数（以风险为单位）

E[R] > 0 是必要条件，f 过大会让 ∏ 发散到 0  ← 这一步才是致命的
```
**这跟前面三份模型是同构的**：
| 模型 | 核心定理 | 形式 |
|---|---|---|
| 小岛经济学 | 财富 = 产能；货币/债务 = 索取权 | 实物 vs 凭证 |
| 博弈论 | 内卷 = 帕累托最优 − 纳什均衡 | 两个点的距离 |
| 乌合之众 | 群体意见 = 最响意见 ≠ 平均意见 | 两个量的错位 |
| **专业投机原理** | **账户终值 = 期望值 × 次数 × 仓位因子** | **三项相乘，末项可归零** |

**四本都在讲同一件事：系统的长期归宿由乘法决定，而乘法里只要有一个因子趋近 0，前面所有的正确都作废。**

## §4 四条因果回路

### 回路 A：亏损后加仓自锁回路（最致命，正反馈）
```
一笔亏损（本该止损却未止损）
      ↓
账户回撤 → 回本压力 ↑
      ↓
"要涨回本，必须赚更多" → 加仓 / 放大仓位
      ↓
单笔风险敞口 ↑
      ↓
下一次亏损的绝对金额 ↑
      ↓
回撤更深（回到起点，且更陡）
```
**自锁点**：回路里没有任何一环会自然刹车。**"回本压力"本身就是上一次的产物，它会自我强化。**
**唯一的刹车**：**单笔风险上限与市场情绪、与盈亏状态完全无关**——它是一个常数，不是变量。

> **这就是"越亏越赌"的数学形式。**
> 关键洞察：**这个回路不需要你是笨蛋才能启动，它只需要你"想回本"——而这是默认人性。**
> 断路方法只有一个：**让仓位规则在开仓前就锁死，且不由当时的心情调整。**

---

### 回路 B：连续亏损 → 纪律崩塌回路
```
连续亏损（例如 5 连错）
      ↓
对系统产生怀疑（"它是不是失效了"）
      ↓
放弃规则，回到凭感觉（"至少我能控制"）
      ↓
失去可归因性 → 无法区分运气与错误
      ↓
亏损继续 → 怀疑加深（回到起点）
```
**关键**：这条回路的触发点**不是亏损本身，是"亏损看起来太长了"**。
而 §5.5 会算出：**胜率 40% 的系统在 100 笔交易里遇到至少一次 5 连亏的概率约 80%。**
也就是说——**这个触发点不是意外，是系统的常规部件。**

**自锁点**：怀疑 → 放弃规则 → 更难验证规则 → 更值得怀疑。
**唯一的刹车**：**事前算出"这个系统正常回撤的最大值是多少"**，把它当预算，不当警报。

> **实战含义**：进场前就要写下"我预期会连亏 __ 次，届时我**不**改系统"。
> 因为毁掉系统的不是你亏了，是你在连亏时**改了系统**。

---

### 回路 C：趋势自强化回路（市场侧的那条）
```
价格创新高
      ↓
趋势跟随者被触发买入（规则驱动，非情绪驱动）
      ↓
买压继续推高价格
      ↓
更多跟随者被触发（突破更多阈值）
      ↓
价格创新高（回到起点，且更陡）
```
**自锁点**：这一回路**只在趋势中运行**，而"什么时候停止"没有任何先行信号。
**唯一的刹车**：**趋势的结构被破坏**——即 1-2-3 法则的第 3 步完成，或 2B 法则出现。
**并且这个刹车不是预测得来的，是价格走出来才确认的。**

> **这解释了"跟随"的代价与价值**：
> 跟随的价值是**你在趋势中，不在赌趋势**；代价是**你必须接受"从顶部到确认"的那一段回吐**。
> **想要"顶部卖出"的人，本质上是想在回路 C 停止之前就知道它会停止——这是要求预测。**

---

### 回路 D：纪律消耗回路（交易者的心理侧）
```
频繁交易 / 盯盘时间过长
      ↓
决策疲劳 ↑（意志力是有限资源）
      ↓
规则执行质量 ↓（开始"这一次例外吧"）
      ↓
出现计划外亏损
      ↓
焦虑 ↑ → 更频繁盯盘 / 更快平仓 / 更想扳回来
      ↓
疲劳 ↑（回到起点）
```
**关键**：**这条回路把"纪律"从道德问题变成了资源问题。**
纪律不是"你够不够坚强"，是"你今天的决策预算还剩多少"。

**自锁点**：疲劳降低执行质量 → 亏损 → 焦虑 → 更多交易 → 更疲劳。
**唯一的刹车**：**降低决策频率**——定好规则后减少在场时间，把决策外包给写好的条件。

> **这是全书与《乌合之众》直接接壤的地方**：
> 市场本身就是勒庞笔下的一个巨型心理群体——**你盯盘时，你的智力在取 min，情绪在取 max。**
> 回路 D 就是"你被市场同化"的过程。

## §5 六组算术

> **这一节是全文的核心。交易的一切判断最终都要落到数字上。**
> 每组算完给结论。

---

### 5.1 期望值：胜率高 ≠ 赚钱（最基础，也最被忽略）

**问题**：两个策略，哪个更好？

**策略甲**：胜率 **40%**，盈亏比 **3:1**（赚时赚 3R，亏时亏 1R）
**策略乙**：胜率 **60%**，盈亏比 **1:1**

以 R 为单位（R = 单笔风险金额）：
```
期望值 = 胜率 × 平均盈利 − 败率 × 平均亏损

策略甲 E = 0.4 × 3 − 0.6 × 1 = 1.2 − 0.6 = +0.6 R / 笔
策略乙 E = 0.6 × 1 − 0.4 × 1 = 0.6 − 0.4 = +0.2 R / 笔
```
**策略甲的期望值是策略乙的 3 倍 —— 而它的胜率低了 20 个百分点。**

再看**盈亏平衡所需的最低胜率**（令 E = 0）：
```
盈亏比 b        最低胜率 p* = 1/(1+b)
  0.5 : 1    →   66.7%     ← 大多数日内交易者实际处在这个赔率区间
  1   : 1    →   50.0%
  2   : 1    →   33.3%
  3   : 1    →   25.0%
```
**换算成实际收益**（假设单笔风险 1%，一年 200 笔，按算术近似）：
```
策略甲：1% × 0.6 × 200 = +120%   （未计摩擦成本与复利效应）
策略乙：1% × 0.2 × 200 =  +40%
```
> 注：这是**算术近似**（把每笔盈亏直接相加）。真实结果由 `∏(1 + f×Rᵢ)` 决定，会低于上面的线性值——
> **因为亏损的复利效应大于盈利的复利效应**（§5.3）。所以上面的数字是**上限**，不是预期值。
> ## 结论
> **胜率是一个"感觉好"的指标，期望值才是"能活"的指标。**
> 人对胜率有天然的偏好，因为**赢的感觉是即时奖励**，而期望值只在几百笔之后才显现。
> 所以市场会系统性地奖励那些**能忍受低胜率的人**——因为多数人忍不了，于是他们被迫去追求高胜率，
> 而在追求高胜率的过程中，他们必然**牺牲盈亏比**（把止损放近、把止盈放远），
> 结果拿到一个高胜率、负期望值的组合。**这是散户最典型的死法。**

### 5.2 破产概率：同样的策略，下注大小决定生死

**问题**：同一个正期望值策略，单笔风险设 1% / 10% / 25%，连亏 10 次之后分别还剩多少？
```
账户余额 = (1 − 单笔风险比例)^连续亏损次数

风险 1%  ： 0.99^10 = 0.9040  →  剩 90.4%   （回撤 9.6%）
风险 10% ： 0.90^10 = 0.3487  →  剩 34.9%   （回撤 65.1%）
风险 25% ： 0.75^10 = 0.0563  →  剩  5.6%   （回撤 94.4%）
```
**从残值到"回到原点"需要的涨幅**：
```
1%  风险：需 +10.6%   ← 一次正常的好交易就能覆盖
10% 风险：需 +186.8%  ← 需要一个翻倍行情
25% 风险：需 +1673%   ← 事实上等于出局
```
**注意 10 连亏不是极端假设。** 胜率 40% 的系统：
```
10 连亏概率 = 0.6^10 = 0.00605 ≈ 0.6%
在 1000 笔交易中，至少出现一次的概率 ≈ 1 − (1 − 0.00605)^100 ≈ 45%
```
**也就是说：你有接近一半的概率，在有生之年遇到一次 10 连亏。**

> ## 结论
> **同样的策略、同样的胜率、同样的赔率，只是下注大小不同：**
> ```
> 风险 1%  → 一次常规回撤，继续下注
> 风险 10% → 一次重伤，被迫缩小仓位（且此时最该重仓）
> 风险 25% → 出局
> ```
> **这就是"风险管理是唯一变量"的算术形态。**
> 1~2% 这个数字不是保守，是**为了让"必然发生的连亏"落在可承受区间内**。
> 它的真正含义是：**我按"我一定会遭遇 10 连亏"来设计仓位，而不是按"我希望不会"。**

### 5.3 回本难度：不对称性的算术

**问题**：亏了以后，要涨多少才回本？
```
亏损比例 L  →  需要的涨幅 = L / (1 − L)
```
| 亏损 | 需要涨幅 | 直觉感受 |
|---|---|---|
| −10% | **+11.1%** | 几乎对称 |
| −20% | **+25.0%** | 开始不对称 |
| −30% | **+42.9%** | 明显不对称 |
| −50% | **+100.0%** | 需要翻倍 |
| −70% | **+233.3%** | 需要翻三倍多 |
| −90% | **+900.0%** | 需要涨十倍 |

**再做一步：把"回本"折算成"需要几笔成功交易"**（假设正期望值策略，每笔期望 +0.5R，单笔风险 1%）：
```
亏 50%  → 需要 100% 收益 → 需要约 200 笔期望交易
亏 70%  → 需要 233% 收益 → 需要约 466 笔期望交易
```
**这还没算上"重伤之后你会被迫缩小仓位"这个二次伤害。**

> ## 结论
> **亏损是凸的，盈利是线性的。**
> ```
> 亏 50% 需要赚 100% —— 这两个数字不等，而人脑默认它们相等。
> ```
> **这是交易中最重要的一个不对称。** 它直接推出了"鳄鱼原则"：
> 鳄鱼咬住你的腿，你不砍腿，它就吃掉你全身。
> **断臂的代价是确定的、有限的、一次性的；不断臂的代价是不确定的、无限的、复利的。**
> 所以止损不是"止损"，是**用一个已知的小数，换掉一个未知的大数**。

### 5.4 凯利公式：理论上最优的下注，实操上必须打折扣

**凯利公式**：给定胜率 p、赔率 b（盈利/亏损），最优下注比例为
```
f* = (b × p − q) / b          其中 q = 1 − p
```
**用 §5.1 的策略甲（p = 40%，b = 3）代入：**
```
f* = (3 × 0.4 − 0.6) / 3
   = (1.2 − 0.6) / 3
   = 0.6 / 3
   = 0.20  =  20%
```
**其他的组合：**
| 胜率 p | 赔率 b | 凯利最优 f* | 1/2 凯利 | 1/4 凯利 |
|---|---|---|---|---|
| 40% | 3:1 | **20.0%** | 10.0% | 5.0% |
| 50% | 3:1 | **33.3%** | 16.7% | 8.3% |
| 30% | 3:1 | **6.7%** | 3.3% | 1.7% |
| 50% | 1:1 | **0%** | 0% | 0% |
| 60% | 2:1 | **40.0%** | 20.0% | 10.0% |

**注意两件事**：
```
① 50% 胜率 + 1:1 赔率 → f* = 0  → 零期望，凯利告诉你不下注
② 凯利对估计误差极度敏感 —— 胜率从 40% 掉到 30%，f* 就从 20% 掉到 6.7%
```
**敏感性算术**（如果真实赔率只有 2:1，而你以为有 3:1）：
```
以为：f* = (3×0.4 − 0.6)/3 = 20%
实际：f* = (2×0.4 − 0.6)/2 = (0.8−0.6)/2 = 10%
真实期望值 = 0.4×2 − 0.6×1 = +0.2R
```
**你按 20% 下注，但实际最优只有 10% —— 你比最优重了一倍。**

**更糟的情形**：如果这 40% 其实只是最近三个月的运气，真实胜率是 30%：
```
真实 f* = (3×0.3 − 0.7)/3 = 0.2/3 = 6.7%
真实期望值 = 0.3×3 − 0.7×1 = +0.2R
```
**你按 20% 下注 —— 比最优重了三倍。**

> ## 结论
> **凯利公式给出的是"如果你完全知道参数"时的最优解。**
> **而你不知道参数。** 你的胜率和赔率都是从有限样本估出来的，**估计误差永远存在**。
> 而凯利的特点是：**下注超过最优的两倍，期望增长就转为负**——它惩罚高估极度严厉。
> **实务做法：1/2 凯利 或 1/4 凯利。** 理由不是"保守"，是"参数的置信区间"。

**这直接解释了 §0 里"单笔 1~2%"的来源**：凯利算出 20%，1/10 折是 2%，1/20 折是 1% —— 不是因为你胆小，是因为**你宁可跑在最优解的左侧（增长慢一点），也绝不跑在右侧（增长变负）。** 注意这里比 §5.4 的 1/2、1/4 凯利还要再保守一档：**当你的参数估计来自几十笔的样本时，再打一折是理性的，不是懦弱。**

### 5.5 连续亏损的概率：回撤是必然的，不是意外

**问题**：胜率 40% 的系统，遇到 5 连亏正常吗？
```
5 连亏概率 = 0.6^5 = 0.07776 ≈ 7.78%
```
**单次不算高。但交易不是一次，是几百次。** 用"块"近似（每 5 笔看作一个独立块）：
```
100 笔交易 = 20 个块
至少出现一次 5 连亏 ≈ 1 − (1 − 0.0778)^20
                     = 1 − 0.9222^20
                     ≈ 1 − 0.1975
                     ≈ 0.8025  = 80.3%
```
**换个更精确的问法（用连亏串的期望个数）**：
```
起始位置有 n − 4 = 96 个，每个位置开始连亏 5 次的概率 = 0.6^5 = 0.0778
近似期望出现次数 ≈ 96 × 0.0778 = 7.5 次
（每个串必须以盈利结束，乘 0.6 → ≈ 4.5 次）
```
| 连亏次数 k | 单次概率 0.6^k | 100 笔中至少遇到一次（近似） | 单笔风险 2% 的累计回撤 |
|---|---|---|---|
| 3 连亏 | 21.6% | ≈ 100% | −5.9% |
| 5 连亏 | **7.78%** | **≈ 80%** | **−9.6%** |
| 7 连亏 | 2.80% | ≈ 40% | −13.2% |
| 10 连亏 | 0.605% | ≈ 45%（1000 笔尺度） | **−18.3%** |

**再把回撤换算成"需要多久恢复"**（按年化 +20% 的正常表现）：
```
回撤 10% → 约 0.5 年      回撤 20% → 约 1.1 年      回撤 30% → 约 1.8 年
```
> ## 结论
> **一个正期望值的系统，必然经历让你怀疑它的回撤。**
> 这不是系统的缺陷，这是**系统的常规部件**。
> ```
> 胜率 40% → 100 笔交易中遇到 5 连亏的概率约 80%
> ```
> **所以"连续亏损时该不该改系统"这个问题，答案在进场之前就写好了：**
> - 如果连亏次数在**事前算出的正常范围内** → 不改，继续
> - 如果超出了范围 → 检查是"方法失效"还是"参数漂移"（而不是情绪）
> **没有这个事前预算的人，一定会在第 5 次连亏时改系统 —— 而那一刻恰好是概率上最不该改的时刻。**
> **这就是"回撤杀死的是纪律，不只是资金"的算术证明。**

### 5.6 摩擦成本：高换手如何吃掉期望值

**问题**：手续费 + 滑点，一年能吃掉多少？

**假设每次交易（一进一出）综合成本 0.15%**（佣金 + 印花税 + 滑点，对频繁交易者偏乐观）：
```
成本拖累（简化算术）= 0.15% × 交易次数

 20 笔/年  →  3.0%
 50 笔/年  →  7.5%
100 笔/年  → 15.0%
200 笔/年  → 30.0%   ← 每天不到一笔
```
**更精确地按复利算**：
```
(1 − 0.0015)^200 = 0.9985^200 ≈ 0.7405
→ 本金只剩 74.05%，即被吃掉 25.95%
```
**关键：成本是从"毛期望值"里扣的，而毛期望值本来就不大。**
```
假设毛期望值 +0.6R/笔，单笔风险 1%
   毛收益 ≈ +120%（算术近似，见 §5.1 注）→ 乘成本因子 0.7405 → 净 ≈ +78%
```
**但如果策略的毛期望值只有 +0.2R/笔：**
```
毛收益 ≈ +40%  → 乘成本因子 0.7405 → 净 ≈ +3.6%
```
**再危险一点：如果毛期望值只有 +0.1R/笔（很常见）：**
```
毛收益 ≈ +20%  → 乘成本因子 0.7405 → 净 ≈ −11.1%   ← 正期望策略变成负收益
```
**再看"降频"的威力**：
```
同样的策略，交易 200 次 vs 20 次：
 （单笔质量相同）
  成本因子：0.7405  vs  0.9985^20 = 0.9704
  差额 ≈ 23 个百分点 —— 几乎全部转化为净收益
```
> ## 结论
> **摩擦成本是对"交易次数"征收的税，而不是对"资金"征收的税。**
> ```
> 一笔交易的期望值 +0.2R，扣掉 0.15% 成本后还剩多少，
> 完全取决于 R（单笔风险）有多大。
> ```
> **这推出两条硬规则**：
> ```
> ① 单笔期望值必须显著大于摩擦成本 —— 否则交易次数不是朋友，是敌人
> ② 降频是提高净收益的最确定手段（不需要提高胜率，不需要提高赔率）
> ```
> **"过度交易"不是因为手痒，是因为它做了一件残酷的事：把一个正期望值的系统，乘以一个小于 1 的成本系数，直到系数使它变负。**

## §6 策略与决策表

**用法**：先判断你在这张表里的**位置**（我是在找入场点，还是在管仓位？我是在执行，还是在怀疑系统？），再取对应动作。
| 场景 | 该做什么 | 机制依据 |
|---|---|---|
| **我要开一笔仓** | 先定 `账户 × 1~2%` 的风险上限，**再看图定止损，最后反推仓位**。顺序不可反 | 支柱二：风险由仓位控制 |
| **我看到了一个"机会"** | 先写下：入场条件、止损位、目标位、单笔风险金额。**写不出第四条就不做** | §2：投机的成立条件③④ |
| **趋势反转疑似发生** | 用 1-2-3 法则：趋势线破 → 不创新高 → 破前回档低点。**三步不全不入场** | §2 三步确认 |
| **价格创新高后立刻回落** | 启动 2B 法则检验。这是**预警**不是确认，仓位应小于 1-2-3 确认后 | §2：1-2-3 是确认，2B 是预警 |
| **我连亏了 3~5 笔** | 查事前算好的"正常连亏范围"。**在范围内 → 不改系统，只按规则继续** | §5.5：回撤是常规部件 |
| **我想"加大仓位快速回本"** | ⛔ **绝对禁止**。这是回路 A 的启动信号。**风险上限是常数，不是变量** | §4 回路 A |
| **我算不清凯利参数** | 用 1/2 凯利，最多 1/4 凯利。**永不使用满凯利** | §5.4：参数估计误差 |
| **我一天想做 10 笔** | 数成本：`0.15% × 次数`。问"这笔的期望值能不能盖住成本" | §5.6：摩擦成本按次数征税 |
| **我被套了，不舍得砍** | 算：亏 50% 需涨 100% 回本。**问自己"我凭什么认为它会翻倍"** | §5.3：不对称性 + 鳄鱼原则 |
| **我想凭盘感做一笔** | 先问：这笔能不能写下来复盘？不能 → 它是赌博不是投机 | §2：可重复性是分界线 |
| **市场很狂热/很恐慌** | 记住你正处在一个心理群体里：**智力 ↓，情绪 ↑**。规则在盘前写好，盘中只执行 | §4 回路 D + 《乌合之众》 |
| **系统正在赚钱，我想加大仓位** | 可以加分批加仓（趋势跟随），但**总风险上限不变**。加仓 = 用浮盈换敞口，不是用本金 | 支柱二 |
| **我不知道该不该做** | **不做。**"无趋势"是第三种合法状态 | §2 趋势定义③ |

### 两条反直觉提醒

> **① "跟随市场"不是被动，是放弃了一个你最想要的东西**
> 跟随的真义不是"不思考"，而是**把判断权交给价格，把决定权留在自己手里**。
> ```
> 价格决定：现在是什么状态（趋势/无趋势/反转）
> 你决定：  暴露多少风险、在哪里认错、做几次
> ```
> 你想保留的那个东西叫"预测"，而预测的代价是：**一旦你预测了，你会开始为预测辩护，而不是为账户辩护。**
> 这就是为什么 1-2-3 法则和 2B 法则的全部价值在于——**它们把"我觉得要转了"变成了"结构是否被破坏"**。

> **② "止损"这个词本身在误导你**
> 它让你以为你付的是**亏损**。实际上你付的是**保险费**：
> ```
> 保险的标的是：继续在市场里下注的权利
> 保费是：这一次的固定小额亏损
> 拒付保费的结果：出局（不可逆）
> ```
> **所以止损的心理阻力大，恰恰因为它是"立刻兑现的确定损失"——而爆仓是"延后且不可感知的损失"。**
> 人脑对这两者的定价是反的。
> **对抗大脑的唯一办法不是意志力，是让止损成为开仓前就写好的机械条件。**（§3 支柱三）

## §7 八个现场检验

**拿这八条去扫任何一笔你即将做或已经做的交易。**
```
① 期望值检验
   这笔交易的胜率估计是多少？赔率是多少？期望值算出来是正的吗？
   → 算不出来 = 你没在投机，你在赌。

② 仓位反推检验
   我是先定了买多少，还是先定了亏多少？
   → 先定金额 = 顺序对了；先定数量 = 顺序反了，回去重算。

③ 单笔风险检验
   这笔亏损如果发生，占账户的百分之几？
   → 超过 2% → 砍仓位。超过 5% → 停手。

④ 最大连亏检验
   我事前算过这个系统正常会连亏几次吗？
   → 没算过 = 你在连亏时一定会改系统，而那是最糟的时点。

⑤ 回本算术检验
   我现在的回撤是 ___%，回到原点需要涨 ___%？
   → 把两个数字都写出来。如果第二个数字让你一惊，说明你低位补仓了。

⑥ 机械化检验
   我能不能把这一笔的判断过程完整写下来，让另一个人照做？
   → 写不下来 = 不可复盘 = 无法改进。

⑦ 成本检验
   这笔交易的成本是 ___%，它的期望盈利是 ___%？
   → 成本占期望值的比例超过 30% → 这笔不值得做。

⑧ 状态检验
   我现在是在执行规则，还是在为上一次的结果找补偿？
   → 如果是后者，这是回路 A 或 D 的入口。停下来，不要在盘中做决定。
```

## §8 诚实边界：这本书什么时候会骗你

**这一节和前面同样重要。这是一本 1991 年的实战书，它的框架有严重缺陷。**

> ### 必须首先说清的一句话
> **这本书的价值主要在于风险管理框架和心理纪律，而不在于预测方法。**
> 1-2-3 法则、2B 法则、趋势线——这些**技术工具的有效性是有争议的**；
> 但"单笔风险 ≤ 1~2%""亏 50% 要涨 100% 才回本""连亏是必然的"——这些**是算术，不依赖任何市场假设**。
> **读这本书的正确方式是：拿走它的算术和纪律，把它的预测方法当假说。**
| # | 局限 | 具体问题 | 修正 |
|---|---|---|---|
| 1 | **幸存者偏差** | **所有交易书都是活下来的人写的，爆仓的人不写书。** 出版本身就是一个筛选器：能出书说明他至少没在出书前爆掉 | 把书当**一个样本**，不是**一个证据**。问："用同一套方法爆掉的人有多少？他们的书在哪？" |
| 2 | **不可证伪性** | "趋势""纪律""跟随市场""结构被破坏"——**这些概念很难被证伪**。价格涨了是"趋势确认"，跌了是"1-2-3 确认反转"，事后总能解释 | ⚠️ **一个什么都能解释的模型，等于什么都没解释。** 用之前必须自己先定死：**什么情况算我错了？**（必须是可量化的价格条件） |
| 3 | **样本问题** | 斯波朗迪的公开实盘记录**缺乏可审计的完整数据**。书里的案例是精选的，回撤和失败交易披露不完整 | 书中的"战绩"当**叙事**，不当**统计**。要看统计，需要逐笔可对账的完整流水 |
| 4 | **时代变化** | 书出版于 **1991 年**。当时：无算法交易、无零佣金、无 24 小时市场、散户信息劣势极大 | ⚠️ **市场微观结构已完全不同。** 尤其：<br>• 摩擦成本结构变了（佣金降、滑点/冲击成本升）<br>• 趋势的持续性与噪声比变了<br>• 一条规则的"发现 → 套利 → 失效"周期被压缩到几个月 |
| 5 | **技术分析的有效性争议** | 学术界对技术分析的预测力**证据薄弱**。相当一部分研究显示，**剔除交易成本后，多数技术策略无超额收益** | 这是**最实质的挑战**。修正：把技术工具降级为**风险管理工具**（提供止损位、提供仓位计算的分母），而非**收益预测工具** |
| 6 | **可复制性问题** | 书中的方法**依赖主观判断**："趋势线怎么画"**没有唯一解**。不同人画同一条趋势线会得到不同结论 | 这使得 §7-⑥（机械化检验）在实践中很难真正通过。**主观成分越高，"方法"越接近"艺术"，越不可教** |
| 7 | **"能盈利"与"能教会"是两件事** | 作者能盈利，不等于他能把自己的能力**传递**给你。很多交易能力来自**多年形成的隐性模式识别**，无法编码 | 明确区分：**书本能传递的是框架和纪律（可编码）；不能传递的是判断力和盘感（不可编码）** |
| 8 | **正期望值可能不存在** | 全书假设"存在一个正期望值的可重复方法"。**这个前提本身没有被证明** | 如果市场在扣除成本后接近有效，那么**多数人的最优策略是"不下注"**。书的框架里没有这个选项——但现实里有 |

> ### 三个特别需要警惕的地方

> **① "鳄鱼原则"的隐藏成本**
> 快速止损在单笔上是对的（§5.3 的算术无可辩驳），但它有一个**未被充分讨论的副作用**：
> ```
> 止损越紧 → 单笔亏损越小 → 但被触发的概率越高
> 结果是：同样的价格路径，你被"洗"出去的次数更多
> ```
> **止损紧不紧是一个权衡，不是一个道德选择。** 书里"必须果断止损"的表述，
> 容易被读成"止损越紧越好"——**这是错的**。正确的表述是：
> **止损位置应由"结构是否被破坏"决定，然后由仓位来适配这个距离。**

> **② 凯利公式在交易中的适用性被高估**
> 凯利要求**参数已知且稳定**（§5.4）。而交易的胜率和赔率是：
> ```
> ① 从有限样本估计的（有误差）
> ② 随时间漂移的（不稳定）
> ③ 彼此相关的（连亏会同时改变胜率和你的心理状态）
> ```
> **三个条件全部不满足。** 所以凯利在交易中的正确用法不是"算最优仓位"，
> 而是**"给出一个上界，然后你远远地待在它下面"**。

> **③ 最大的问题：书没有告诉你"什么时候不该做"**
> 全书 300 多页在讲"怎么做"，但**对散户最有价值的一页应该是"什么情况下不下注"**。
> ```
> 期望值 ≤ 0 时          → 不做
> 无趋势时               → 不做
> 成本占比过高时         → 不做
> 连亏超出预算、心理耗竭时 → 不做
> 参数估计的置信区间太宽时 → 不做
> ```
> **"不做"是这本框架里最缺少、也最重要的一个动作。**
> §6 决策表最后一行补上了它——但原书对此着墨极少。

> ### 一个必须说清的边界：这本书教的是"如何活下来"，不是"如何赚大钱"
> ```
> 它可以给你的：不确定性下的风险定价框架、心理纪律、可复盘的系统思维
> 它不能给你的：一个稳定的正期望值来源、预测能力、你个人的执行能力
> ```
> **把这套框架用在"减少亏损"上，它极其有效（这部分是算术）。**
> **把它用在"找到必胜方法"上，它会让你失望（这部分是假说）。**
> 读这本书最好的结果是：**你不再问"哪只股票会涨"，而是开始问"我这笔交易的风险是多少、我还能承受几次错"。**

## §9 一页纸速查
```
┌──────────────────────────────────────────────────────────────┐
│  核心公式                                                     │
│                                                              │
│    长期结果 = (胜率 × 平均盈利 − 败率 × 平均亏损) × 交易次数    │
│                                                              │
│    而  单笔亏损 ≤ 账户 × 1% ~ 2%                              │
│                                                              │
│    三项相乘：期望值 × 次数 × 仓位因子                          │
│    ★ 只有「仓位因子」能把整个乘积归零，且不可逆                 │
└──────────────────────────────────────────────────────────────┘

【一个定义】
  投机 = 可重复的方法 + 量化的风险 + 预先限制的风险上限
  赌博 = 承担无法评估的风险
  ★ 区别不是「风险大小」，是「风险是否被评估」

【三根支柱】
  ① 期望值结构 ≠ 单笔结果    （单笔结果不含信息）
  ② 风险由「仓位」控制，不由「止损价」控制
      单笔风险 = 仓位 × (入场价 − 止损价)
      顺序：定风险上限 → 定止损位 → 反推仓位  （不可反）
  ③ 机械化不是为了聪明，是为了可重复 → 可复盘 → 可改进

【核心定理】
  账户终值 = 期望值 × 次数 × 仓位因子
  期望值为负 → 慢慢亏死（可救）；仓位过大 → 归零（不可救）

【六个翻转】
  胜率高才赚钱       低胜率+高盈亏比可以更优：40%/3:1(+0.6R) 胜 60%/1:1(+0.2R)
  风险靠止损控制     风险靠「仓位」控制，止损只决定「在哪里认错」
  扛住才翻身         亏 50% 要涨 100% 回本；扛住是小概率大灭绝
  止损伤自尊         止损是买入「继续下注的权利」= 保险费
  学会预测才赚钱     市场是唯一裁判，你无法说服它
  交易靠天赋盘感     能活下来的是被机械化、可重复的流程

【四条回路】
  A 亏损加仓   亏损 → 回本压力 → 加仓 → 更大亏损
               ★ 唯一刹车：风险上限是常数，与情绪/盈亏无关
  B 连亏崩塌   连亏 → 怀疑系统 → 放弃规则 → 更无法验证 → 更怀疑
               ★ 唯一刹车：事前算好「正常连亏范围」，当预算不当警报
  C 趋势自强   创新高 → 跟随者买入 → 更高 → 更多跟随者
               ★ 唯一刹车：结构被破坏（1-2-3 第 3 步 / 2B）
  D 纪律消耗   频繁交易 → 决策疲劳 → 执行质量↓ → 亏损 → 更焦虑
               ★ 唯一刹车：降低决策频率，把决策外包给写好的条件

【趋势与反转】
  上升趋势 = 更高的高点 + 更高的低点
  下降趋势 = 更低的高点 + 更低的低点
  无趋势   = 二者都不成立（「不做」是合法状态）

  1-2-3 法则（确认型，慢、少错、晚）
    ① 趋势线被突破  ② 不再创新高/新低  ③ 破前一个回档低点/高点
    ★ 三步必须全满足，顺序不可换

  2B 法则（预警型，快、多错、早）
    创新高 → 立刻回落到前高之下 = 假突破 = 反转信号
    ★ 1-2-3 给你确定性，2B 给你价格。二者不可兼得

【六组算术】
  ① 期望值      40%/3:1 → +0.6R ；60%/1:1 → +0.2R
                盈亏平衡胜率：0.5:1 → 66.7% │ 1:1 → 50% │ 3:1 → 25%
    ★ 胜率是「感觉好」的指标，期望值才是「能活」的指标

  ② 破产概率    单笔风险 1% → 10 连亏剩 90.4%
                单笔风险 10% → 剩 34.9%
                单笔风险 25% → 剩  5.6%
    ★ 同样的策略，下注大小决定生死

  ③ 回本难度    −10%→+11.1% │ −30%→+42.9% │ −50%→+100% │ −70%→+233%
    ★ 亏损是凸的，盈利是线性的。这是交易中最重要的不对称

  ④ 凯利公式    f* = (bp − q)/b ；p=40%, b=3 → f* = 20%
                参数错一点，f* 掉一半（40%→30% 胜率：20% → 6.7%）
    ★ 实务用 1/2 或 1/4 凯利：宁可跑在最优左侧，绝不跑在右侧

  ⑤ 连亏概率    5 连亏 = 0.6^5 = 7.78%
                100 笔中至少遇到一次 ≈ 80%
    ★ 回撤是必然的，不是意外；回撤先杀纪律，再杀资金

  ⑥ 摩擦成本    0.15% × 200 笔 = 30%（算术）
                (0.9985)^200 ≈ 74.05% → 实际吃掉约 26%
                毛期望 +0.1R/笔 时：+20% → 乘 0.7405 → 约 −11%
    ★ 成本按「交易次数」征税。降频是最确定的提净收益手段

【八个检验】
  ①期望值 算得出正的吗？        ②仓位   先定买多少还是先定亏多少？
  ③单笔风险 占账户几 %？        ④最大连亏 事前算过吗？
  ⑤回本算术 需涨几 %？          ⑥机械化 能写下让别人照做吗？
  ⑦成本   占期望盈利几 %？      ⑧状态   在执行规则还是在找补偿？

【边界】
  ❌ 幸存者偏差 —— 爆仓的人不写书；把它当一个样本，不是证据
  ❌ 不可证伪 —— 用前必须自己定死「什么情况算我错了」
  ⚠️ 样本问题 —— 战绩当叙事，不当统计
  ⚠️ 时代变化 —— 1991 年的市场微观结构已完全不同
  ⚠️ 技术分析有效性存争议 —— 降级为风险管理工具，而非预测工具
  ⚠️ 可复制性 —— 「趋势线怎么画」没有唯一解
  ⚠️ 能盈利 ≠ 能教会 —— 框架可编码，判断力不可编码
  ⚠️ 正期望值可能不存在 —— 若市场足够有效，最优策略是「不下注」
  ★ 本书的价值在风险管理框架与心理纪律，不在预测方法

【一句收尾】
  决定生死的不是胜率，是风险管理；
  不是预测能力，是期望值和重复次数。
  你要做的不是猜对下一次，
  而是**保证自己在下一次猜错之后，还在牌桌上**。
```
