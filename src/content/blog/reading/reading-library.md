> 把一本（或一门）书的核心逻辑，压成一张**可以推演的图**。
> 不是读书笔记，不是要点罗列——是**能自己走一遍的因果链**。

---

## 这个库要解决什么问题

读一本书，最常见的结果是：**记住了结论，但推不出过程。**

于是遇到新情况就用不上，因为：
- 只记住了"是什么"，没记住"为什么必然是这样"
- 只记住了结论，没记住**结论成立的条件**
- 记住了十本书的结论，但它们互相不搭话

**"直觉模型"的定义**（本库的统一规格）：

```
一个直觉模型 = 一个核心等式
             + 这个等式为什么成立（因果回路）
             + 它成立需要什么条件（诚实边界）
             + 用它做决策的具体动作（策略表）
```

判断一份模型是否合格，看一条：**读者能不能不看原文，自己把结论重新推出来。**

## 统一规格

每份模型都是同一套骨架，可以横向对比：

| 章节 | 内容 | 作用 |
|---|---|---|
| §0 | **一句话模型** | 全书压成一个等式 |
| §1 | **反直觉翻转表** | 你以为 / 实际上是 / 为什么 |
| §2 | **核心区分** | 这本书在重新定义哪个词 |
| §3 | **三根支柱 + 核心定理** | 定理用 `> ##` 突出，能跨书呼应 |
| §4 | **因果回路** | 3-4 条自锁回路 + 唯一刹车 |
| §5 | **算术证明** | 具体数字算出来，不是打比方 |
| §6 | **策略与决策表** | 场景 / 该做什么 / 机制依据 |
| §7 | **现场检验** | 6-8 条可执行自问 |
| §8 | **诚实边界** | 这本书什么时候会骗你 |
| §9 | **一页纸速查** | 整页速查卡 |

> **§5 和 §8 是这个库和普通读书笔记的分水岭。**
> §5 要求把定性论断变成算术——**如果一个理论算不出数，它就没法指导决策。**
> §8 要求把这本书的时代局限和被证伪之处写清楚——**不写边界的模型是信仰，不是工具。**

## 跨书呼应：四条主线

这个库真正的价值不在单本，而在**书和书之间的咬合**。19 份模型可以挂到四条主线上。

### 主线一：财富的物理层 —— 钱从哪来，又流向谁

```
国富论        分工 → 生产率 → 财富从哪来
政治经济学原理  生产规律是自然规律（不可改），分配规律是人为规则（可以改）
资本论        价值从劳动来，剩余价值在生产环节被拿走
曼昆微观      价格是信号，边际量决定决策
曼昆宏观      长期只看生产率，短期只看总需求
小岛经济学     鱼是产能，钱和债是索取权——索取权能凭空造，鱼不能
置身事内      地方政府的预算约束，与土地的双重身份（要素 + 抵押品）
```

**核心张力**：财富是**生产**出来的，还是**分配**出来的？

| 立场 | 主张 |
|---|---|
| 斯密 / 曼昆 | 生产是第一性的，分配是结果 |
| **穆勒** | **生产规律不可改，分配规律可以改** ← 全部争论的枢纽 |
| 马克思 | 分配不是结果，是生产关系的必然产物 |
| 兰小欢 | 分配由**财政体制**决定——不描述应然，只描述实际怎么运转 |

> **最实用的一句**：遇到任何"这就是市场规律"的说法，先分类——
> 这是**生产规律**（只能认），还是**分配规律**（可以谈）？
> 大部分被包装成前者的话，其实是后者。

---

### 主线二：认知的失效层 —— 为什么"知道"也保不住

```
乌合之众     智力 → min，情绪 → max
思考快与慢    系统1 默认接管，系统2 是懒惰的
认知觉醒     理智脑年轻、耗能、力量弱；用式子表示时没有"意志力"这一项
博弈论       理性不是道德问题，是格局问题
```

**核心张力**：人到底是不是理性的？

| 视角 | 答案 |
|---|---|
| 曼昆教材 | 假设是——理性人是一切的起点 |
| 卡尼曼 | 系统性地不是（但**具体哪些偏差可复制、哪些不可复制**要分开看） |
| 勒庞 | 在群体中彻底不是 |
| 博弈论 | **不用管他理不理性，看格局** |

> 四份连起来构成一个递进：
> **大脑有出厂缺陷（卡尼曼）→ 群体把缺陷放大（勒庞）→ 缺陷被结构利用（博弈论）→ 但可以靠元认知部分夺回控制权（认知觉醒）。**

---

### 主线三：决策与系统层 —— 面对不确定怎么办

```
佛畏系统     畏果 → 畏因 → 畏系统
专业投机原理  长期结果 = 期望值 × 重复次数；生死由风险管理决定，不由预测决定
管道的故事    提桶 = 时间换钱（线性、有上限）；管道 = 资产换钱（可复制、边际成本趋零）
营销管理     需求不是被满足的，是被定位和创造的
人比AI凶     产出 = 判断力 × AI 杠杆 − 可被替代的部分
```

**核心张力**：该优化**单次结果**，还是优化**系统**？

```
目标是一次性的、有终点的
系统是持续的、自我维持的
```

**答案在遍历性**：单次期望值为正的赌局，重复下注也可能**必然破产**——
因为期望值算的是"很多个平行世界的平均"，而你只有**一条命**。
这解释了为什么"专业投机原理"和"管道的故事"讲的是同一件事：**控制单次下注的大小，让系统活到复利生效。**

> 三份最锋利的重复：
> **决定生死的不是胜率，是仓位大小**（投机原理）；
> **不是你能赚多少，是你停止投入后还剩多少**（管道）；
> **不是 AI 多强，是你的产出多容易被验证**（人比AI凶）。

**外加一份工具箱**：`控制论·信息论·系统论`（#19）不从决策者角度切入，而是给**三个通用零件**——
**可能性空间**（控制 = 在可能性空间里选择并施加约束）、**信息 = 不确定性的减小**、**边界决定系统**。
它和这条主线的其余五份是"零件 vs 成品"的关系。

### 主线四：深层结构 —— 世界为什么长成这个样子

```
枪炮病菌与钢铁  近似因（枪炮/病菌/钢铁）不是原因，终极因（地理禀赋）才是
熵增与时间箭头  微观定律时间对称，宏观箭头来自统计——时间方向是概率的产物
```

**核心张力**：**结构决定结果，还是能动性决定结果？**

- 戴蒙德：结构。地理禀赋在 1.3 万年前就埋下了伏笔
- 反对方（Acemoglu 等）：制度与选择。地理不是宿命
- 统计力学：结构。**但"结构"本身是概率的产物**，不是某个意志的安排

> **这两份是全库的"地基"。**
> 前三层主线讨论"人怎么想、怎么选、怎么被卷进去"；
> 这两份追问"那套规则本身是从哪来的"。
>
> 而它们和主线二的呼应极其精确：
> 统计力学要求**粒子碰撞前相互独立**（分子混沌假设），
> 群体幻觉的数学根源正是**独立性消失了**（见 `乌合之众` §5.1 与 `熵增与时间箭头` §6）。
> **同一把钥匙，开两把锁。**

> **还有第二条跨线呼应，藏在"熵"这个词里**：
> `熵增与时间箭头` 里定义 `H = ∫ f ln f`，取负号就是 Shannon 的信息熵——**差一个 Boltzmann 常数**。
> 而 `控制论·信息论·系统论` 讲的正是"**信息 = 不确定性的减小**"。
> 所以 **信息论和热力学在数学上是同一个函数**，只是一个数分子、一个数比特。
> 这也解释了为什么"获取信息"总是要付出代价——**你是在对抗熵增**。


## 怎么用这个库

**读的顺序**（推荐）：

```
1. 小岛经济学      建立"鱼 vs 券"的底层分辨力
2. 曼昆微观        把"边际"装进脑子
3. 博弈论          理解为什么坏局面很稳定
4. 乌合之众        理解为什么自己也会被卷进去
5. 思考快与慢      理解大脑的出厂缺陷
6. 其余按兴趣
```

**用的方法**：

```
遇到一个现象
   ↓
问：这是哪一层的问题？
   ├─ 是财富生产/分配   → 翻主线一
   ├─ 是我或群体判断失灵 → 翻主线二
   ├─ 是长期策略选择     → 翻主线三
   └─ 是"规则本身从哪来" → 翻主线四
   ↓
翻到对应模型的 §6 策略表
   ↓
对照 §8 边界，确认这个模型在当前情境下适用
   ↓
用 §5 的算术验算自己的直觉
```

> **顺序不能颠倒：先确认边界，再用策略。**
> 一个模型最危险的时候，是它在不适用的场合显得很好用。

**三条使用纪律**

1. **看 §8 比看 §6 重要**。§6 告诉你"怎么做"，§8 告诉你"什么时候别这么做"。跳过 §8 等于把工具当信仰。
2. **不信任没算过数的结论**。任何一份模型里，§5 是唯一能被你独立验证的部分——**自己把数字重算一遍**，算不出来就先别用。
3. **标注决定用途**。`✅ 有真实字幕` 的可以引用为"视频说了什么"；`❌ 原书重建` 的**只能引用为"这本书说了什么"**，不能当成视频作者的观点。
