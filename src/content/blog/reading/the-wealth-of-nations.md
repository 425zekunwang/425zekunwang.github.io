## §0 一句话模型

> ## 财富不是金银，是**人均产出**。
> ## 人均产出 = **分工深度**，而分工深度被**市场范围**卡住。

写成一个式子：

```
财富（人均产出）  =  专业化收益  −  协调成本
                       ↑                ↑
                  分工深度 d        交换/运输/信息成本
                       │
                       └── 上界由市场范围 N 决定
                           小市场只能养粗分工
                           大市场才能养细分工
```

或者写成那句最容易被漏掉的话：

```
可维持的分工深度  d*  ∝  √N

N = 能接触到你的有效市场范围（人数 × 购买力 × 可达性）
      ↑ 修一条路、开一条航线、去掉一道关税，都在扩大 N
```

**这是全书的发动机。** 它一次解释掉四个日常困惑：

| 困惑 | 用模型一句话解开 |
|---|---|
| 为什么同样的农民，进城打工收入翻倍？ | 他本人没变，**他的 N 变了**——他的产出现在卖给出价最高的全国市场 |
| 为什么"勤劳但不富"是常态？ | 勤劳提高的是**劳动强度**；分工提高的是**每小时产出**。**两者不是一个变量**，而后者有 240 倍的量级（§5.1） |
| 为什么贸易战对双方都不划算？ | 关税缩小 N → 分工深度 d 下降 → 双方人均产出同时下降。**这是算术，不是立场** |
| 为什么"技术越先进，人越累"？ | 分工提升生产率的同时**也提升了协调成本和单调性**，后者斯密自己最担心（§8 第 4 条） |

> **斯密原话（第一卷第一章，意译）**：
> 劳动生产力上最大的增进，以及运用劳动时所表现的更大的熟练、技巧和判断力，
> 似乎都是**分工**的结果。

**记住这个非对称：财富的变量不是"努力"，是"协作的细分程度"。**
这跟直觉相反——我们以为穷是因为懒，富是因为勤；
斯密的答案是：**同样多的人、同样的勤劳程度，只要组织方式不同，产出可以差两个数量级。**

## §1 七个反直觉翻转

| # | 你以为 | 实际上是 | 为什么 |
|---|---|---|---|
| 1 | 分工提升效率靠"熟能生巧" | **真正的大头是"工序可以拆开"这件事本身** | 熟能生巧是线性的（做多了快 30%）；而把 18 道工序拆给 10 个人，收益是**乘数级**的（240 倍）。斯密列的三条原因里，"节省转换工作的时间"和"简化到能发明机器"是结构性的，不是熟练度的函数 |
| 2 | "看不见的手"= 自由市场万能论 | **原文全书写了两次"看不见的手"（《国富论》里只有一次，第四卷第二章），语境极其具体** | 那一段讲的是：**商人偏爱本国产业**，于是他的资本被引导到"最有利于社会"的用途上。全文的关键词是**资本的用途**，不是"市场永远正确"，更不是"任何政府干预都是坏的" |
| 3 | 生产是目的，消费是手段 | **斯密写反了：消费是一切生产的唯一目的** | 这是重商主义批判的落点——重商主义把金银（顺差）当目的，把人民当手段。斯密第一卷直接说：**"消费是一切生产的唯一目的与用途"** |
| 4 | 价钱由成本决定（成本加成定价） | **斯密没有成本加成定价。他把价格分解成工资+利润+地租，而不是从它们相加得出价格** | 这是经济学史上最细的一刀。三份收入是**同时被决定的**，不是先算成本再加利润。利润不是成本的一部分加价，**利润是价格里的一个份额** |
| 5 | 水比钻石有用，所以水该比钻石贵 | **斯密自己发现了这个矛盾，但他没解开；解开它的人要等 95 年** | 斯密混淆了**总效用**与**边际效用**。水的总效用无穷大，但边际效用趋近于零；钻石反过来。**"用处大小"和"价格高低"根本不是同一个变量**（§5.3） |
| 6 | 分工越细越好 | **斯密自己是最早的分工批判者**：分工让工人"变蠢变无知" | 他把"大多数人智力的迟钝"归因于分工，并主张**政府办教育**来对治。**一个被后世当成市场原教旨的人，在第五卷里主张公共教育** |
| 7 | 商人比政府更懂经济，所以少管就好 | **斯密骂商人骂得比骂政府更狠** | 他说商人的建议"从来不能完全信任"，主张凡是商人聚在一起，讨论的多半是**抬高价格的阴谋**。反重商主义不是"亲商"，恰恰是**反商人游说** |

**其中第 2、4、6 条最容易被误解，也最需要反复校准。**

## §2 核心区分：斯密在重新定义"财富"

在这本书之前，欧洲人算"国富"的方式是**数国库里的金银**。
斯密把变量换掉了。这不是一个新答案，是**换了一道题**。

| | **重商主义的财富** | **斯密的财富** |
|---|---|---|
| 定义 | 一国持有的**贵金属存量** | 一国**人均年产出**（土地和劳动的年产物） |
| 来源 | 贸易顺差（多卖少买） | 劳动生产率（分工深度） |
| 零和？ | **是**：世界金银总量近似固定，你多我少 | **不是**：分工让双方总量都涨 |
| 政策推论 | 关税、垄断殖民地贸易、禁止金银出口 | 扩市场、修路、放开贸易、轻税 |
| 谁受益 | 有特许状的大商人 | 消费者 |
| 斯密的态度 | 一套"商人向国王兜售的学说" | 一套工程学 |

> **关键推论：一旦财富 = 人均产出，国家的最优策略就从"抢"变成了"扩"。**
> 这是全书最贵的一次换题。

### 财富的三个来源，按斯密的排序

斯密在第二卷末尾做了一个**明确的排序**（这一点常被忽略）：

```
资本用途的生产性排序（斯密原意）：

① 农业          → 最生产性：不仅是劳动，连"自然力"也一起干活
② 制造业        → 次之
③ 批发贸易（内贸）→ 再次
④ 批发贸易（外贸）→ 再次
⑤ 零售贸易      → 最后

排序依据：① 雇用的生产性劳动量  ② 是否让土地的年产物增值
```

> **注意这个排序是错的**（§8 第 7 条），但它揭示了斯密的**隐含判据**：
> **一个用途好不好，看它"能养活多少有效劳动"，而不是看它"赚多少钱"。**
> 这个判据今天已经站不住，但它是理解斯密全部政策主张的钥匙。

### 关键区分：生产性劳动 vs 非生产性劳动

| | **生产性劳动** | **非生产性劳动** |
|---|---|---|
| 定义 | 能把价值**固定并实现在**某个可售卖物品上 | 服务随生随灭，不留下可交换物 |
| 例子 | 制造工、农民、工匠 | 家仆、官员、律师、演员、军人 |
| 对财富的作用 | **增加**资本存量 | **消耗**资本存量 |
| 斯密的态度 | 财富的引擎 | 必要的消费，但不创造财富 |

> ⚠️ **这是《国富论》里最严重的一个错误。** 它把"服务"排除在财富之外，
> 而今天服务业占发达经济体 70%+ 的产出。**整块丢弃**（§8 第 3 条）。
> 但要注意：**这个错误派生出了斯密"节约是美德、奢侈是浪费"的整条政策线**——
> 丢掉这个区分，等于丢掉半本书的论证基础。用它的时候要知道**地基是歪的**。

## §3 三根支柱与核心定理

### 支柱一：分工 = 生产率的乘数（引擎）

**斯密的因果链**（第一卷第一到第三章）非常短，只有四步：

```
分工  →  ① 每个工人熟练度提高
      →  ② 节省了"从一道工序换到另一道"的时间
      →  ③ 简化到足以发明机器
      ⇒  同等人数，产出提升两个数量级
```

**然后他立刻问了一个更狠的问题：分工从哪来？**
答案不是"人天生聪明"，而是：

```
分工 ← 交换倾向（the propensity to truck, barter, and exchange one thing for another）
     ← 而交换需要"能被交换的对象存在"
     ← 而这不是人性，是"自利的契约"：
```

> **斯密原话（意译）**：我们能吃上晚饭，不是因为屠夫、酿酒师、面包师仁慈，
> 而是因为他们**关心自己的利益**。我们要诉诸的是他们的**自爱**，不是他们的**仁慈**。

> ## 这是全书最反道德的一段话：
> ## 财富的来源不是善意，是**让善意变得不必要的制度**。

### 支柱二：价格 = 三份收入的合成（信号）

斯密把商品的**真实价格**分解成三个部分，并且坚持它们是**同时被决定**的：

| 组成部分 | 归属 | 由什么决定（斯密的说法） |
|---|---|---|
| **工资** | 劳动者 | 劳动的**自然报酬**；受"维持生存所需"的下限约束，也受"劳动需求 vs 人口"调节 |
| **利润** | 资本所有者 | 与**资本规模**和**风险**有关；斯密注意到利润**随资本丰裕而下降**，且"低利润国家比高利润国家更富" |
| **地租** | 土地所有者 | **价格的结果，不是价格的原因** |

> ⚠️ **最后一行是全书最锋利的一刀**：
> 地租由**价格决定**，不参与决定价格。谷物贵所以地租高，不是地租高所以谷物贵。
> 这直接预示了李嘉图的差额地租理论（1817）。

**还有一层：真实价格 vs 名义价格。**

```
真实价格 = 为获得它而付出的"劳动量"（toil and trouble）
名义价格 = 为获得它而付出的"货币量"

斯密的名言：劳动是"价值的真实尺度"，
           而货币只是"名义尺度"。
```

**他还给了一个绝妙的例子**：金银的价值**长期趋于下跌**（因为发现新矿），
而谷物的价值长期**趋于稳定**（因为等量谷物大致总能养活等量的人）。
**所以"用谷物记的年金"比"用金银记的年金"更保值。**

**这是 1776 年的一句话，距离指数化债券（TIPS, 1997）还有 221 年。**

### 支柱三：自然价格 = 引力中心（协调）

```
自然价格 = 工资自然率 + 利润自然率 + 地租自然率
（"自然率"= 该社会该行业的常规水平，可持续、可长期维持的水平）

市场价格 = 实际成交价（由供求的偶然状态决定）

四步调节机制：
① 市场价格 > 自然价格
② ⇒ 利润高于常规 → 资本与劳动流入该行业
③ ⇒ 供给增加 → 市场价格被压下来
④ ⇒ 回到自然价格附近（反向同理）
```

> **斯密用的词是"引力中心"（center of repose），不是"均衡"。**
> 他说价格**不断地被吸引向**它，但**很少正好停在**它上面。
> ⚠️ 这个措辞差别极其重要：**斯密没有现代意义上的均衡概念**（§8 第 2 条）。

### ⭐ 核心定理

> ## 财富（人均产出）= 分工深度 − 协调成本
> ## 而分工深度 d 的**上界**由市场范围 N 决定：
> ##
> ## **分工受市场范围限制。**
> ## 市场不够大，再好的专业化也养不活。
> ## 市场够大，专业化自己会越长越细。

展开成可操作的等式：

```
d*  =  argmax  [ 专业化收益(d)  −  协调成本(d) ]
               s.t.  销售覆盖量(d) ≤ N

  d ↑ → 单位成本 ↓（斯密效应）
  d ↑ → 交易次数 ↑、单笔批量 ↓ → 协调成本 ↑（科斯效应，1937）

  ⇒ 最优点在两者边际相等处
  ⇒ N 变大（修路/开航/去掉关税/统一货币）
     把约束右移 → d* 上移 → 人均产出上台阶
```

**这跟系列其他几份的核心定理是同构的**：

| 模型 | 核心定理 | 错位的两个量 |
|---|---|---|
| 小岛经济学 | 财富 = 产能；货币/债务 = 索取权 | 实物 vs 凭证 |
| 博弈论 | **内卷 = 帕累托最优 − 纳什均衡** | 两个点的距离 |
| 乌合之众 | **群体意见 = 最响意见 ≠ 平均意见** | 两个量的错位 |
| 政治经济学原理 | **收入 = 生产率 × 分配系数** | 自然 vs 人为 |
| **国富论** | **人均产出 = 分工深度 − 协调成本，受 N 约束** | **收益有上界，上界是市场** |

**五本都在讲同一件事：系统的产出不是由"努力"决定的，是由"结构参数"决定的。**
前面几本讲的是**制度、认知、格局**这些参数；
《国富论》是这条线的起点：**它第一次指出，最不道德的那个参数是"你能和多少人做交易"。**

## §4 四条因果回路

### 回路 A：分工自催化回路（正反馈，但有一个明确的天花板）

```
        市场范围 N 扩大（修路 / 开航 / 人口增长 / 关税下降）
                    ↓
        单个工种的销量能覆盖成本
                    ↓
        可以有人"只干这一件事"
                    ↓
        生产率 ↑ → 单位成本 ↓ → 价格 ↓
                    ↓
        能买得起的人更多 + 能卖到更远
                    ↓
        市场范围 N 进一步扩大（回到起点）
```

**自锁点**：这个回路里没有任何一环会自然刹车，它只会往细里走。
**唯一刹车**：**市场范围本身**。
当 N 不够大时，专业化的销量覆盖不了固定成本，回路**立刻失去动力**。

> 实战含义：**判断一个地方能不能发展，先看它的 N 有多大——不是看它有多少资源。**
> 一个资源富集但 N 很小的经济体，专业化会被困在最粗的层次上（"什么都要自己干"）。
> 一个资源贫瘠但 N 极大的经济体（如 17 世纪荷兰、后来的新加坡），专业化可以极细。
> **斯密：荷兰的土地贫瘠，但荷兰人富。** 这一句话就是这条回路。

**这条回路也是全书的钥匙**：它把"开放贸易"从**价值观问题**变成了**参数问题**。
自由贸易 = 把 N 的约束右移。**反对它的理由不可能是"贸易不好"，只能是"调整成本谁承担"（§8 第 6 条）。**

---

### 回路 B：价格引力回路（负反馈，全系统唯一真正的自动刹车）

```
     市场价格 偏离 自然价格
               ↓
     工资/利润 偏离 自然率
               ↓
     资本与劳动的 净收益 出现差异
               ↓
   ┌───────────┴───────────┐
   ↓                       ↓
该行业利润高            该行业利润低
资本流入、劳动涌入       资本流出、劳动退出
   ↓                       ↓
供给 ↑、价格 ↓          供给 ↓、价格 ↑
   └───────────┬───────────┘
               ↓
     市场价格 回到 自然价格附近
               ↓
     差异消失 → 流入流出停止（负反馈闭合）
```

**自锁点**：本回路**没有**自锁——它是负反馈，天然收敛。
**唯一刹车（也是唯一风险）**：回路依赖两个**现实中经常不成立**的前提：

```
① 资本和劳动可以自由进出（现实中：执照、牌照、最低资本、行业壁垒）
② 价格信号是真实的（现实中：信息不对称、垄断定价、补贴扭曲价格）
```

> **这就是"看不见的手"真正的机制。** 它不是"市场是完美的"，
> 而是：**"如果进出自由且价格真实，那么个体追逐私利的行为会被价格信号汇聚成一个谁也不曾计划的结果。"**
> **两个前提一旦被破坏，这只手就残废了**——而斯密自己用了整整第四卷，
> 证明这只手在 18 世纪的英国被**法律**和**特许状**绑住了。

---

### 回路 C：利润率均等化回路（资本的自由流动）

```
   某行业利润率高
         ↓
   资本流入 / 新进入者
         ↓
   产量 ↑ → 价格 ↓ → 利润率 ↓
         ↓
   同时：该行业所需资本 ↑ → 资本变得更"贵"
         ↓
   各行业利润率趋于均等（扣除风险与麻烦后的净收益相等）
         ↓
   ⇒ 社会资本自发流向"最被需要"的用途
```

**斯密的原文语境**（第四卷第二章，全书唯一一次"看不见的手"）：

> **他（商人）通常既不打算促进公共福祉，也不知道自己在促进多少。**
> 他只盘算自己的安全、自己的利得……在这种情形下，
> **他被一只看不见的手引导着，去促成一种他完全没有意图的目的。**
> 而且他偏爱本国产业而非外国产业，本身就使国家的年产物增大。

```
斯密的完整论证链（漏掉任何一环都会误读）：

  ① 商人出于风险与便利，天然偏爱本国产业
  ② 于是资本留在国内
  ③ 国内产业雇用了更多劳动
  ④ 国家的年产物（真实财富）增加
  ⑤ 这个结果不是他的意图，但发生了

  ★ 关键词：资本被引导到"有利的用途"。
  ★ 不是：市场能解决一切；不是：政府必然有害；
     更不是：价格永远正确。（这些都不在这段里。）
```

> ## "看不见的手"被后世严重过度引用。
> ## 它的原文论证范围只覆盖"资本在本国 vs 外国的用途选择"，
> ## 而且斯密在**同一卷里**用了几百页论证政府该建路、办学、设法院、发纸币但要管制银行。
> ## 把一个具体机制读成"市场万能论"，是 20 世纪最成功的一次选择性引用。

### 回路 D：重商主义寻租自锁回路（斯密没有命名，但他描述了机制）

```
       某些商人获得特权（特许状 / 关税 / 殖民地垄断）
                  ↓
        该行业利润高于自然率
                  ↓
        超额利润的一部分用于游说、维持特权
                  ↓
        立法者获得财政或私人好处
                  ↓
        特权被加强，范围扩大（回到起点）
                  ↓
     真实价格被抬高 → 消费者损失 → 其他人也来要特权
                  ↓        （因为看到"有特权才活得下去"）
     整个经济被切成一个个受保护的格子
```

**自锁点**：这个回路**特别稳**，因为受益集中（少数人、大利益）、受损分散（所有人、小损失）。
**唯一刹车（斯密本人承认的）**：**外生的财政崩溃**——战争把国库掏空，特权体系自己撑不下去。

> 斯密在第四卷末尾观察到：**英国的殖民地贸易垄断，是靠国家用战争去维持的。**
> 他反复算这笔账：垄断带来的利润，**小于它引发的战争和防守的成本**。
> **这是"寻租成本 > 垄断租金"的早期版本。**

> ## 注意：这是《国富论》里最被低估的一节。
> ## 斯密不是一个"相信市场会自愈"的人。
> ## 他相信的是：**利益集团会系统性地劫持立法，而且这个过程会自我强化。**
> ## 他给出的解药因此不是口号，是具体的**制度设计**（§3 支柱三、§5.6、第五卷）。

### 5.1 别针工厂：分工的 240 倍（斯密原文的数字）

**斯密在第一卷第一章描述了一个真实的别针工厂**（他自己去参观过的作坊）：

```
分工前（一个人独立完成全部 18 道工序）：

  一个人一天最多做：   不到 20 枚
  （斯密补了一句：如果不熟悉机器，可能连 1 枚都做不出来）

分工后（10 个工人，每人承担 2 道工序左右）：

  10 个人一天合计产量：  48,000 枚
  人均：            48,000 ÷ 10 = 4,800 枚

倍数：
  4,800 ÷ 20 = 240 倍
```

**换个角度算规模效应：**

```
如果按"一个人"的口径比较：
  单人 20 枚  →  10 人 48,000 枚
  即：10 个人做出了 48,000 ÷ 20 = 2,400 个"单人份"的产量
  也就是雇佣 10 人 = 雇佣了 2,400 个不分工的工人

用人话讲：
  这 10 个人，干出了 2,400 个人单干的活。
```

**再算时间：**

```
每人每天 4,800 枚，工作 8 小时：
  4,800 ÷ (8 × 60) = 10 枚/分钟
  即：每 6 秒出品 1 枚别针

（对比：单人 20 枚/天 = 每 24 分钟 1 枚）
```

> ## 结论
> **这不是"勤劳程度"的差别，是"组织方式"的差别。**
> 同样 10 个人、同样的 8 小时、同样的体力，
> **换一种切法，产出差了 240 倍。**
> 所以"穷是因为懒"这个直觉，在算术上是被否证的——
> **你可以让一个社会所有人的勤劳度翻倍（这几乎不可能），产出也只涨 2 倍；
> 而把分工从"一人全包"改成"十人分工"，产出涨 240 倍。**

**一个必须补上的教训**：这 240 倍**依赖于那 48,000 枚别针卖得出去**。
如果这个村子一个月只需要 500 枚别针，这个工厂**半天就得停产**。
**这就是"分工受市场范围限制"在同一个例子里的另一面——§5.2。**

### 5.2 市场门槛：多少人才能养活一个专业化工人

**问题**：一个专业别针工人一天能做 4,800 枚。他需要多大的市场？

**先算极端情形：如果市场就是这个村子。**

```
村子的别针需求：
  假设每人每月用 1 枚别针 → 每人每月需求 1 枚
  该工人每天产出 4,800 枚 → 每月产出 4,800 × 25 = 120,000 枚

  要卖出这些别针，需要的人口：
  120,000 ÷ 1 = 120,000 人
  ⇒ 一个村子（几百人）绝无可能养活一个"专职别针工"
```

**但这不代表"没有别针工"，只代表"别针工不专业"。**

```
小市场的分工被压缩到最粗的层次：

  村里 200 人  →  只能是"铁匠"：既打别针，也打菜刀、打锄头、修马掌
  镇里 2 万人  →  可以有"专做五金的铺子"
  城里 50 万人 →  可以有"专做别针的作坊"
  全国 1000 万人 → 可以有"专做别针头（针尖那一步）的工序"
```

**把约束反过来说：**

```
能养活一个专业工种的"市场范围门槛" N_min：

  N_min  ≈  该工人的日产能 ÷ 人均日需求
  
  别针：4,800 ÷ (1/30)  = 144,000 人   ← 需要十万人级市场
  面包：200 个 ÷ (1 个/人/天) = 200 人  ← 几百人的村子就能有面包师

  ⇒ 人均需求越大、单件产出越小 → 门槛越低 → 分工越容易发生
  ⇒ 这解释了为什么"面包师/屠夫/酿酒师"是最早专业化的职业（斯密正好举了这三个）
```

**再看运输成本怎么卡住 N：**

```
有效市场范围 N_eff = 半径 R 内的人口 × 可承受的运输成本比例

  假设一车货物 100 公里运费 = 货值的 20%
                300 公里运费 = 货值的 60%
                600 公里运费 = 货值的 120%（超过货值，没人发货）

  ⇒ 水运的每公里成本约为陆运的 1/10（斯密原书明确对比过）
  ⇒ 所以"沿海 + 通航河流"的经济体，N_eff 天然大十倍以上

  ★ 斯密原话的算术版：
    地中海沿岸、波罗的海沿岸、长江/恒河流域，
    文明首先在这些地方变富 —— 不是因为那里的人更聪明，
    是因为那里的 N_eff 大十倍，分工能细十倍。
```

**这条算术还有一个必然后果（斯密没有明说）：**

```
如果 d* ∝ √N（示意关系，用于说明趋势）：
  N 扩大 100 倍  →  d* 扩大 10 倍
  N 扩大 4 倍    →  d* 扩大 2 倍

⇒ 专业化工种的数量，随市场规模"次线性"增长。
⇒ 这解释了：纽约的工种比小镇多得多，但并不是多一百倍。
```

> ## 结论
> **分工不是"想分就能分"，它有一个人口与运输的硬门槛。**
> 所以"这个地区为什么不富"这个问题，
> **常常不是治理问题、不是文化问题、甚至不是资本问题，而是 N 太小的问题。**
> **修一条路、开一条航线、拆一道关税，是在改 N；而 N 是那条回路 A 的输入。**

### 5.3 水与钻石：斯密发现了悖论，也栽在了这里

**斯密的原话**（第一卷第四章）：

> 应当注意，"价值"一词有两种含义：
> 有时表示某物的**使用价值**（value in use），有时表示**交换价值**（value in exchange）。
> **使用价值极大的东西，交换价值往往极小或没有；反之亦然。**
> **水**是最有用的，但几乎买不到什么东西；
> **钻石**几乎没有什么使用价值，却常常能换到大量其他货物。

**算术：把"总效用"与"边际效用"分开，矛盾就消失了。**

```
设水的年消费量 100,000 单位，钻石年消费量 100 单位
（单位 = 可供一人一天使用的量）

关键区别不在总量，在"最后一份"：
  水的最后一单位，人人手上已有 99,999 单位 → 边际效用 ≈ 0
  钻石的最后一单位，人人手上只有 99 单位  → 边际效用 极高

价格由"最后一单位"决定，不由"前 99,999 单位"决定：
  水的总效用：极大（无它必死）
  水的边际效用：≈ 0  → 价格 ≈ 0
  钻石的总效用：很小（无它照活）
  钻石的边际效用：极高 → 价格 极高
```

| | 总效用 | 边际效用 | 价格 |
|---|---|---|---|
| **水** | 极大（生存必需） | **≈ 0**（供给极充裕） | 极低 |
| **钻石** | 小（装饰） | **极高**（供给极稀缺） | 极高 |
| **斯密的困惑** | 他只看这一列 | **他没看这一列** | 他以为矛盾 |

```
如果让钻石像水一样丰富（比如人工合成钻石，1955 年）：
  钻石边际效用 → 崩落 → 价格 → 崩落（天然钻石靠营销维持溢价）
  这就是"边际决定价格"最有说服力的现实证据
```

> ## 结论
> **"有用"和"值钱"是两个不同的变量，而且它们不相关。**
> 决定价格的是**最后一份**的价值，不是**全部**的价值。
>
> **这一条要到 1871 年（门格尔、杰文斯）和 1890 年（马歇尔）才被解开——
> 距斯密写下这段话 95 到 114 年。**
> **斯密诚实地报告了一个他自己解不开的矛盾**——这比编一个假解释更有价值。

**实践含义（今天也一样）**：

```
问一个产品为什么贵，不要问"它有多少用"，
要问："它的边际供给有多难？"和"想买最后一份的人有多想要？"

  "很辛苦做出来的东西"  →  与价格无关（辛苦是供给方的成本，不是买方的估值）
  "很有用的东西"        →  与价格无关（总效用不定价）
  "稀缺 + 有人愿意为最后一份出价" → 这个才定价
```

### 5.4 自然价格与市场价格：距离有多远，要多久回来 ★

**用面包业构造一个完整算例。**（★ 示意数字）

```
【自然状态】
  面粉成本      0.5 元
  自然工资      0.3 元
  自然利润      0.2 元
  ————————————————
  自然价格      1.0 元/个
  自然利润率    0.2 ÷ (0.5+0.3) = 25%

【冲击：需求上涨 20%】
  短期供给无法增加（烤炉、师傅、铺面都固定）
  ⇒ 市场价格被抢到  1.3 元

  此时的账面利润 = 1.3 − 0.5 − 0.3 = 0.5 元
  利润率 = 0.5 ÷ 0.8 = 62.5%
  ⇒ 比自然利润率 25% 高出 37.5 个百分点
```

**资本的反应（回路 B/C 启动）：**

```
高利润吸引了新资本  →  隔壁开新面包铺
假设需要 12 个月才能建成投产（斯密强调资本转移是慢的）
12 个月后供给增加，价格被压回：

  第 0 月：1.00 元（自然）
  第 1 月：1.30 元（+30%）
  第 6 月：1.15 元（资本在建，市场仍紧）
  第 12 月：1.02 元（新产能投产）
  第 18 月：0.98 元（略微超调：大家同时建厂）
  第 24 月：1.00 元（回到自然价格）
```

| 阶段 | 市场价格 | 利润率 | 资本流向 |
|---|---|---|---|
| 冲击前 | 1.00 | 25% | 平衡 |
| 冲击后 1 个月 | 1.30 | 62.5% | **流入信号亮起** |
| 产能投产 | 1.02 | 27.5% | 流入减速 |
| 超调 | 0.98 | 22.5% | **流出信号亮起** |
| 收敛 | 1.00 | 25% | 平衡 |

> ## 结论
> **价格是一个信号，利润是一个流向指示器。**
> 它们共同完成了一件没人指挥的事：**把资本推到"当下最缺"的地方。**
>
> **但请注意表里的两件事：**
> ① **收敛花了 24 个月**，不是瞬间——"看不见的手"是慢的；
> ② **第 18 个月出现超调**——个体各自看利润，看不到"别人也在建厂"，
>    于是**集体过度投资**。这就是"猪周期""产能过剩"的通用结构。
> **看不见的手能纠正错误，但纠正的方式是"先犯错，再饿死一部分人"。**

**这也解释了斯密的政策排序为什么强调"资本自由流动"而不是"资本补贴"**：
补贴改变的是**信号**，而信号一旦失真，回路 B 的收敛能力就丧失了。

### 5.5 税收四原则：同一笔税，四种入库率 ★

**斯密的四条原则**（第五卷第二章）：

```
① 公平（equality）    ：按各自能力比例纳税
② 确定（certainty）   ：纳税时间、方式、金额必须明确，不能随意
③ 便利（convenience） ：在纳税人最方便的时间与方式征收
④ 经济（economy）     ：征收成本应尽可能低，且尽量不打扰纳税人
```

**用同一笔 200 元的纳税人负担，检验三种税制。**（★ 示意数字，仅用于比较量级）

```
                A 包税制        B 随意关税      C 现代宽税基所得税
              （斯密所批判的）  （高不确定）    （四原则都满足）

纳税人实际负担       200            200               200
  其中：税款          120             95               195
        征收成本       40             15                 3
        合规成本       15             10                 2
        寻租/贿赂      25             30                 0
        扭曲损失       —              50               —（简化）
—————————————————————————————————————————————————————
入库               120             95               195
入库率             60%            47.5%            97.5%

附带损失（纳税人多付但社会没得到）：
  A:  80 元（40%）   B: 105 元（52.5%）  C: 5 元（2.5%）

入库率差距：195 / 95 = 2.05 倍
```

| 原则 | A 包税制 | B 随意关税 | C 现代税制 |
|---|---|---|---|
| ① 公平 | ❌ 包税人按"能榨多少"定，不按能力 | ❌ 海关官员看人下菜 | ✅ 统一税率 |
| ② 确定 | ❌ 完全不确定 | ❌ 完全不确定 | ✅ 规则公开 |
| ③ 便利 | ❌ 上门逼缴 | ❌ 卡在关口 | ✅ 代扣代缴 |
| ④ 经济 | ❌ 入库 60% | ❌ 入库 47.5% | ✅ 入库 97.5% |

> ## 结论
> **斯密的四原则不是道德说教，是一张效率表。**
> **同一笔税，四种制度下的入库率可以差 2 倍以上。**
> 也就是说：**同样的名义税率，实际税负可以完全不同**——
> 这解释了为什么"减税"和"加税"的争论常常在说两件不同的事：
> **一个说名义税率，一个说实际负担。**
>
> 斯密排第②条"确定"排在第①条之后、第③条之前，
> 而且专门说："**在税收的所有原则里，确定性的重要性远超其他**"——
> 因为**不确定的税，让所有人的努力都变成了赌博**。

### 5.6 货币与银行：数量、速度、产出 ★

**斯密的货币观**（第二卷第二章）：

```
① 货币是"流动的资本"，是交换的"大车轮"（the great wheel of circulation）
② 但货币本身不构成社会收入 —— 它是工具，不是财富
   （斯密："纸币替代金银，等于把一部分死资本变成活资本"）
③ 纸币可以替代金银，但银行必须受约束：
   斯密明确批评过度的银行券发行，主张限制小额银行券
④ 纸币过多 → 会推高物价 → 出超 → 金银外流（休谟机制，斯密继承）
```

**用数量方程算一遍：**

```
   M × V = P × T

  （M 货币量，V 流通速度，P 物价，T 实际交易量）

斯密时代的英国（★ 量级示意）：
   M ≈ 1
   V ≈ 20（金属货币周转慢，但商业票据已相当活跃）
   T ≈ 20
   ⇒ P = M×V/T = 1×20/20 = 1.00   ← 基准

情形 A：开矿，金银翻倍（斯密讨论过的西班牙情形）
   M = 2, V = 20, T = 20（短期 T 不变）
   ⇒ P = 2×20/20 = 2.00
   ⇒ 物价翻倍，实际产出没变
   ⇒ 这就是"发现新大陆 → 欧洲价格革命"（16 世纪物价涨约 3-4 倍）

情形 B：纸币替代金银（斯密的政策主张）
   M(金银) 从 1 降到 0.3，但加上纸币后 M(总量) 仍是 1
   ⇒ P 不变
   ⇒ 但 0.7 的金银被"释放"出来，可用于购买机器、雇工
   ⇒ 相当于凭空多出 70% 的资本品 —— 这是真实的好处

情形 C：现代（★ 用于对比）
   M(广义) ≈ 100 倍于 18 世纪，V 从 20 降到约 1.3（电子支付？不，是持币意愿上升）
   ⇒ 如果 V 不变：P 应为 100×20/20 = 100 倍
   ⇒ 实际 P 只涨了约 30-40 倍
   ⇒ 差额被 T（实际产出增长了数十倍）和 V 下降吸收了
```

> ## 结论
> **"钱变多"本身不创造财富，它只改变价格的分母。**
> 真正创造财富的是 T（实际产出），而 T 由分工深度决定（回到核心定理）。
>
> **但纸币有一个真实的好处（情形 B）**：它把被"锁在流通职能里"的金银释放出来变成资本品。
> **这是货币金融史上少见的"纯收益"** ——
> **也是斯密对银行相对宽容的原因：不是银行能创造财富，是银行能解锁财富。**
>
> ⚠️ 但斯密自己加了一个条件：**银行券必须能随时兑换成金银**。
> 换成今天的话：**货币发行必须受锚约束**。他对"无锚纸币"是警惕的。

## §6 策略与决策表

**用法**：先判断你在**哪一栏**（生产者 / 消费者 / 立法者 / 被特权排挤的人），再取对应动作。

| 场景 | 该做什么 | 机制依据 |
|---|---|---|
| **我要提高自己的产出** | 不要问"我怎么更努力"，问"**我能不能只做一道工序**"——把非核心环节外包出去 | §0：产出 = 分工深度，不是努力强度。240 倍在组织方式里，不在工时里 |
| **我要提高一个团队/地区的产出** | **先扩 N**（去更远的市场、接更大的客户、拆掉交易摩擦），再谈专业化 | §3 核心定理：N 是 d 的上界。N 不扩大，专业化只会造成闲置产能 |
| **我是一个小市场的生产者** | **不要专业化**。保留多技能（"铁匠模式"），直到 N 足够大 | §5.2：N_min = 日产能 ÷ 人均日需求。达不到门槛，专业化必亏 |
| **我要给一个东西定价** | 问"**它的边际供给有多难 + 愿意买最后一份的人出多少**"，不问"我多辛苦"或"它多有用" | §5.3：总效用不定价，成本不定价，边际稀缺定价 |
| **我看到一个行业利润率很高** | 先问："**这是什么造成的？**"——如果是进出自由的暂时短缺，会收敛（§5.4 的 24 个月）；如果是牌照/特许造成的，**不会收敛** | §4 回路 B 的两个前提：进出自由 + 价格真实。缺一，引力失效 |
| **我在被一个高利润行业吸引** | 数一数**已经有多少人在建产能**。大家同时看到同一个信号 = 同时超调 | §5.4 第 18 个月：个体看不到别人的在建产能 → 集体过度投资 |
| **我是政策制定者，要增加国民财富** | 优先级：① 拆关税与运输壁垒（扩 N）② 保护产权与司法（让价格信号真实）③ 办基础教育（对治分工的愚钝化）④ 轻税、确定、便利、低成本 | §5.2 + §4 回路 A + 支柱二 + §5.5 |
| **我看到"保护本国产业"的提案** | 问三个问题：① **谁受益、谁付费**？② 受益方是**集中**还是**分散**？③ 它是不是在**缩小 N**？ | §4 回路 D：受益集中、受损分散 → 政治必然性 ≠ 经济合理性。§5.2：缩小 N 会降低分工深度 |
| **我在面对商人/行业协会的建议** | 默认打折。斯密的原话是商人建议"从来不能完全信任" | §1 第 7 条：斯密反重商主义 = 反商人游说，不是亲商 |
| **我要设计一个税** | 按四原则倒序检验：**经济 → 便利 → 确定 → 公平**（因为前三条决定它到底能不能收上来） | §5.5：入库率可以差 2 倍 |
| **我看到"看不见的手"被引用** | 问："**说话的人在讲哪个机制？**"如果答案是"市场能解决一切"，引用是错的 | §4 回路 C：原文语境只覆盖"资本在本国 vs 外国的用途" |
| **我在讨论自由贸易** | 把争论拆成两半：**总收益**（几乎总是正的）与**调整成本**（真实且集中）。分开谈 | §3 核心定理 + §8 第 6 条：斯密的静态分析忽略了调整成本 |

### 两条反直觉提醒

> **① "分工受市场范围限制" 是双向的，别只读一半**
> 大多数引用只读它的一半："市场大 → 分工细 → 生产率高"（乐观版）。
> 完整的读法是双向的：
> ```
> 市场缩小 → 分工被迫变粗 → 生产率下降
> ```
> 这意味着**脱钩、制裁、关税、物流中断**的代价，
> **不是"贸易额少了多少"，而是"分工深度退了多远"**——
> 后者是不可逆的（机器闲置、技能流失、供应链解散需要数年重建）。
> **贸易的收益是线性的，贸易中断的代价是断崖式的。** 这是斯密那句话最容易被忽略的一半。

> **② "自利" 不是 "自私"，它需要制度外壳**
> 屠夫和面包师的自利之所以能喂饱你，**前提是他们不能抢你、不能骗你、不能联起手来定你的价**。
> 斯密把这三件事分别放了三个地方：
> ```
> 不能抢你 → 第五卷：司法与国防
> 不能骗你 → 第五卷：标准、度量衡、银行管制
> 不能联手 → 第四卷：反垄断、反特许、反行会限制
> ```
> **所以"看不见的手"不是制度缺位的产物，是制度在场的产物。**
> 把斯密读成"少管就行"，等于把回路 B 的两个前提直接删掉，然后宣称回路成立。

## §7 八个现场检验

**拿这八条去扫任何一次"这个地区/公司/行业为什么不富"的讨论。**

```
① 分工度检验
   这件事里，有多少人只做"一道工序"？
   → 几乎所有岗位都是"一人全包"，说明分工被卡住了。
     接着问下一条。

② 市场范围检验
   这个产出能卖到多远？有效人口是多少？
   运费占货值多少比例？超过 20% 了吗？
   → N 太小就是根因。此时"提高效率"是徒劳的，先扩 N。

③ 门槛检验
   把这个专业工种的日产能，除以人均日需求。
   算出来的人口数，这个市场有吗？
   → 达不到门槛，专业化必然亏本，再多培训也没用。

④ 信号检验（回路 B 的前提一）
   这里的价格是真实的吗？有没有补贴、限价、配额在扭它？
   → 价格失真，资本就不会流向"最被需要"的地方，而会流向"最有补贴"的地方。

⑤ 进出检验（回路 B 的前提二）
   去年利润最高的行业，今年有新进入者吗？
   → 没有新进入者 = 有壁垒 = 引力失效 = 这里的高利润是租金，不是效率。

⑥ 边际检验
   这个产品的价格，是由"它多有用"决定的，还是由"最后一份多难搞"决定的？
   → 找到那个"边际单位"，你就找到了真正的定价机制。

⑦ 寻租检验
   这条规则，谁是集中受益者？谁是分散受损者？
   受益者有没有在花钱维护这条规则？
   → 有，那你面对的是回路 D，不是市场失灵。药方是制度，不是效率。

⑧ 慢变量检验
   如果价格信号刚才变了，资本要多久才能进出？
   → 24 个月？5 年？
     "看不见的手"的时间尺度，决定了下一次繁荣与崩溃的间隔。
```

## §8 诚实边界：这本书什么时候会骗你

**这一节和前面同样重要。斯密是 1776 年的道德哲学教授，他的模型有一大半已经被后来的经济学推翻或修正。**
**而且它是"源头那一本"——所有后来的修正，都是针对它来的。**

| # | 局限 | 具体问题 | 修正 |
|---|---|---|---|
| 1 | **劳动价值论（最大的错误）** | 斯密说"劳动是价值的真实尺度"，并把价格分解为劳动的报酬。**这直接导向了"价值由劳动量决定"**。但 1871 年的**边际革命**（门格尔、杰文斯、瓦尔拉斯）证明：**价值由边际效用决定，不由投入的劳动量决定**。一个耗费巨大劳动却无人想要的东西，价格是零 | **整块替换**为边际效用/边际成本框架（§5.3）。斯密自己其实**发现了这个矛盾**（水与钻石），只是没有工具解它。**承认矛盾比编解释诚实——这一点要给他记功** |
| 2 | **没有现代意义上的均衡概念** | 斯密用的是"引力中心"（center of repose），是一个**隐喻**，不是可解的模型。他说价格"不断被吸引向它，但很少停在那里" | 现代一般均衡（瓦尔拉斯 1874、阿罗-德布鲁 1954）给出了严格版本。**但请注意：一般均衡的成立条件（完全竞争、完全信息、完备市场）比斯密想象的苛刻得多。** 说"斯密预见了均衡"是后见之明，说"斯密有均衡理论"是错的 |
| 3 | **生产性劳动 vs 非生产性劳动（已被证伪）** | 斯密把家仆、官员、律师、演员归为"非生产性"，认为他们不创造财富 | **这条错误在今天的发达经济里意味着 70% 以上的产出"不算财富"**。萨伊、巴斯夏、马歇尔都指出：服务同样创造效用，同样有价值。**整块丢弃**。但它派生出的"节约是美德"整条政策线也随之失去地基 |
| 4 | **对分工的愚钝化忧虑（被系统性忽略，而斯密是对的）** | 斯密在第五卷写道：分工使工人"变得愚蠢和无知"，一辈子只做几个简单动作，**丧失了运用理智的习惯**。他因此主张**政府办教育** | **这一条应被恢复，而且比斯密时代更重要。** 马克思（异化）、涂尔干（失范）、布雷弗曼（《劳动与垄断资本》1974）都是这条线的延续。**今天把它读成"斯密支持自由市场所以不管工人"是彻底的误读** |
| 5 | **"看不见的手"被严重过度引用** | 全书中该短语出现两次（《国富论》一次，《道德情操论》一次）。《国富论》那次的语境是**资本在本国 vs 外国的用途选择**，不是"市场万能" | 按 §4 回路 C 的原文语境使用，并**明确列出两个前提**（进出自由、价格真实）。20 世纪对这句话的"自由市场万能"式引用，**是选择性引用，不是斯密的意思** |
| 6 | **自由贸易：静态分析忽略调整成本与国家安全** | 斯密的比较优势论证是**静态的**：他证明自由贸易下总产出更高，但**没有处理"谁在转型中失业、多久、多痛"**。他也没处理**国防相关性产业**问题（虽然第五卷讲国防时接近了） | 需要补上：① **调整成本**（工人重培训、资本沉没）② **分配**（总收益正 ≠ 人人受益）③ **国家安全**（斯密自己的国防卷就承认有些产业不能只看效率）。这正是李斯特（1841）和现代"战略性贸易政策"的出发点。**但补上这些不等于否定自由贸易，只是说：论证不能停在斯密那一步** |
| 7 | **资本四种用途的生产性排序（错的）** | 斯密说农业 > 制造 > 内贸 > 外贸 > 零售 | 这个排序建立在"只有农业有自然力参与"这一**重农学派遗留**上。现代经济学**没有这种排序**——判断标准是边际产出和消费者估值，不是"雇用了多少劳动"或"是否涉及土地"。**整块丢弃** |
| 8 | **大量经验判断是 18 世纪的观察，不是定理** | 例：斯密断言"水运成本约陆运的 1/10"、"低利润国家的资本比高利润国家更充足"、"荷兰的富庶来自贸易而非土地"。这些都是**观察性的、特定时空的**，有的对，有的是时代局限 | 把它们当**假说**，用现代数据检验。现代物流下"水运/陆运成本比"已完全不同；"低利润率=更富"在金融化经济里也完全不成立 |
| 9 | **对殖民地的论述带有时代偏见** | 第四卷论殖民地时，斯密虽然批判垄断，但整体框架仍是从**宗主国利益**出发；他对美洲、印度原住民社会的描述带有 18 世纪的欧洲中心视角 | 阅读时明确区分：**对垄断机制的分析（有力）vs 对殖民地社会的描述（时代产物）**。前者可用，后者需批判性阅读 |
| 10 | **价值与价格的混用（术语问题）** | 斯密在"劳动价值论"和"三份收入构成价格"之间来回摆动，**这两个主张在逻辑上并不完全兼容**：如果价值由劳动量决定，那地租和利润就是"扣除"，是马克思的路；如果价格由三份收入相加构成，那价值就是分配的结果，是后世的"加法论" | 斯密是**折中主义者**，这个含混是《资本论》整本书的起点：马克思要"修正"的正是这个含混。**读《国富论》时，凡是看到"价值"二字，都要停下来问：他说的是劳动量、交换比率，还是价格？** 斯密自己常常没说清 |

> ### 一个根本性的方法论提醒
> ```
> 《国富论》不是一本"定理集"，它是一本"论证集"。
>
> 它同时是：
>   ① 一部经济理论的奠基作（分工、价格、资本、货币）
>   ② 一部 18 世纪英国的政策论战书（反重商主义、反特许）
>   ③ 一部道德哲学著作的续篇（《道德情操论》的作者写的）
>
> 把 ② 和 ③ 当成 ① 来读，你会得到"市场万能论"；
> 把 ① 当成 ② ③ 来读，你会得到"斯密是个矛盾的人"。
> 两者都不对 —— 他是在用 ① 的工具处理 ② 的问题，并从 ③ 的立场判断。
> ```
>
> **最危险的读法**：只抽走 ①（"看不见的手"那一句），
> 扔掉 ② 的具体论战对象，扔掉 ③ 的道德关怀，
> 然后宣称这是斯密的全部意思。**这正是过去 150 年反复发生的事。**

## §9 一页纸速查

```
┌──────────────────────────────────────────────────────────────┐
│  核心公式                                                     │
│                                                              │
│    人均产出 = 分工深度 − 协调成本                              │
│                 └── 上界由市场范围 N 决定                     │
│                                                              │
│    可维持分工深度  d* ∝ √N                                    │
│                                                              │
│    ★ 分工受市场范围限制                                       │
└──────────────────────────────────────────────────────────────┘

【三根支柱】 分工 = 生产率的乘数  │  价格 = 三份收入的合成  │  自然价格 = 引力中心
【一个引擎】 交换倾向：财富来自「让善意变得不必要的制度」
【一个信号】 利润是资本流向的指示器；价格是稀缺的度量
【一个刹车】 回路 B 的两个前提：进出自由 + 价格真实

【七个翻转】
  分工靠熟能生巧     大头是「工序可以拆开」这件事本身（乘数级，不是线性的）
  「看不见的手」     原文只讲「资本在本国 vs 外国的用途」，不是市场万能论
  生产是目的         斯密写反了：消费是一切生产的唯一目的
  成本加成定价       斯密没有。三份收入同时被决定，利润是份额不是加价
  水比钻石有用       总效用 vs 边际效用。斯密自己发现了矛盾但没解开
  分工越细越好       斯密是最早的分工批判者：分工让工人变愚钝 → 主张办教育
  商人的建议         斯密：商人建议「从来不能完全信任」，反重商主义 = 反游说

【四条回路】
  A 分工自催化  N↑ → 专业化可行 → 成本↓ → 买得起的人更多 → N↑
                ★ 唯一刹车：市场范围本身
  B 价格引力    价格偏离 → 利润差 → 资本进出 → 供给变 → 价格回归
                ★ 负反馈，天然收敛；靠「进出自由 + 价格真实」两个前提
  C 利润均等化  高利润行业 → 资本流入 → 利润率↓ → 各行业趋于均等
                ★ 原文「看不见的手」出现在这里，语境极窄
  D 寻租自锁    特权 → 超额利润 → 游说 → 立法强化特权 → 更多人来要特权
                ★ 唯一刹车：外生财政崩溃。受益集中、受损分散 → 特别稳

【六组算术】
  别针工厂    单人 <20 枚/天  →  10 人 48,000 枚/天 = 人均 4,800 枚 = 240 倍
              ★ 10 个人干出了 2,400 个人单干的活。差的是组织方式，不是勤劳
  市场门槛    4,800 枚/天 ÷ (1 枚/人/月) = 144,000 人才能养活一个专职别针工
              ★ 面包师门槛只要 200 人 —— 这解释了分工的先后顺序
  水与钻石    水的边际效用 ≈ 0 → 价格 ≈ 0；钻石反之
              ★ 决定价格的是「最后一份」，不是「全部」，也不是「成本」
  自然价格    冲击 +30% → 利润率 25%→62.5% → 资本流入 → 24 个月回归
              ★ 第 18 个月超调 = 集体过度投资 = 猪周期的通用结构
  税收四原则  同一笔 200 元负担：入库 120 / 95 / 195 → 入库率 60% / 47.5% / 97.5%
              ★ 名义税率相同，实际税负可以差 2 倍
  货币        4,800 枚别针里没有货币；M×V=P×T 中真正创造财富的是 T
              ★ 印钱改变分母，分工改变分子

【八个检验】
  ①分工度 有多少人只做一道工序？  ②市场范围 能卖多远？运费占比多少？
  ③门槛   日产能÷人均日需求=？    ④信号  价格有没有被补贴/限价扭过？
  ⑤进出   高利润行业有新进入者吗？⑥边际  定价靠「有用」还是「最后一份难搞」？
  ⑦寻租   谁集中受益？谁分散受损？⑧慢变量 资本进出要多久？24 个月还是 5 年？

【边界】
  ❌ 劳动价值论 —— 已被边际革命取代（1871/1890）
  ❌ 生产性 vs 非生产性劳动 —— 服务占今天 70% 产出，整块丢弃
  ❌ 资本四种用途的生产性排序 —— 重农学派遗留，整块丢弃
  ⚠️ 没有现代均衡概念 —— 「引力中心」是隐喻不是模型
  ⚠️「看不见的手」被过度引用 —— 原文只讲资本用途，且全书两次
  ⚠️ 自由贸易忽略调整成本与国家安全 —— 总收益正 ≠ 人人受益
  ⚠️ 经验判断是 18 世纪观察 —— 当假说，不当定理
  ⚠️ 对分工愚钝化的忧虑被忽略 —— 斯密是对的，而且今天更对
  ⚠️ 折中主义导致「价值」一词含混 —— 这正是《资本论》的起点
  ★ 最危险的读法：只抽走「看不见的手」一句，扔掉论战对象与道德关怀

【一句收尾】
  财富不是金银，是分工。
  分工不是勤劳，是市场范围。
  所以真正的问题从来不是「我们够不够努力」，
  而是**「我们把自己和多少人连在了一起」**。
