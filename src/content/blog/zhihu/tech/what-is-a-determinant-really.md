上线性代数课学行列式的时候，老师大概是按这个顺序讲的。

二阶的：ad − bc。 三阶的：Sarrus 规则，六项，正负交错。 n 阶的：det(A) = Σ sgn(σ) · Π A\_{σ(i),i}，对所有置换求和，每一项带一个根据逆序数算的符号。

你抄下这个公式，练了若干道题，学会了按行展开、按列展开、初等变换化简，考试拿了分。

但如果有人拦住问一句，这个数到底是什么东西。一个矩阵的若干次加加减减算出一个实数，这个实数意味着什么。

答不上来。

课本给出的定义是那个巨大的求和公式。这个公式长得像纯组合学，一堆置换，一堆逆序数，一堆正负号，看上去就是有人随手凑出来的一串加减。

然而这串加减算出来的那个数，有一些非常反常的性质。

它等于零，当且仅当这个矩阵不可逆。一个纯粹关于求和后数值的公式，居然精准识别了一个矩阵能不能做逆运算，凭什么。

它具有乘法性：det(AB) = det(A)·det(B)，两个矩阵乘积的行列式恰好等于各自行列式的乘积。矩阵乘法是一堆复杂的累加过程，它的行列式居然能分解成两个子矩阵行列式的简单相乘，这又凭什么。

它还等于一个几何量：二阶行列式是两个列向量张成的平行四边形的带符号面积，三阶行列式是三个列向量张成的平行六面体的带符号体积，n 阶对应 n 维平行多面体的带符号体积。一个组合学求和，居然算的是几何意义下的体积。

一个公式，三件看上去毫无关系的事情，不可能都是巧合。

**公式背后一定藏着一个统一的结构。那个结构才是本质，公式只是这个结构在计算层面的影子。**

要说清楚这个藏着的结构，得先承认一件事。

课本把顺序讲反了。

课本先给公式，然后让人去验证公式满足若干性质，好像公式是第一位的，性质是它的衍生物。

数学史上的真实顺序正好相反。

1693 年，莱布尼茨在给洛必达的一封信里第一次写下了一个判断线性方程组有没有解的表达式。那个表达式是几个系数的加减组合，没有名字，也没有一般公式。莱布尼茨注意到的不是它长什么样，而是它的行为，它在特定取值下会变成零，而方程组恰好在那时无解。

1750 年克莱默写下了一个求解线性方程组的公式，后人叫它克莱默法则。他用到了类似的加减组合，但他也没给它起名字。

真正把行列式作为一个独立研究对象、系统梳理它的代数和几何性质，是 1812 年的柯西干的事。柯西发表了一篇专门讨论行列式的长篇论文，证明了今天教材里几乎所有的基础性质，乘法定理、可逆判据、按行按列展开等等。他的贡献不是发明一个新公式，而是把行列式从方程组求解过程中用到的某个表达，提炼成一个有严格定义、有代数结构、有几何意义的数学对象。更晚一些，数学家意识到可以用多重线性、交替性、归一化这三条公理把它刻画得更干净，公式从公理里长出来这一层才被显影。

**公式是公理的结果，不是反过来。**

课本里看到的那个组合学求和，是按照柯西框架倒推出来的实用表达。课本把结果放在了原因前面，所以学起来觉得公式凭空冒出来。

那公理是什么。

n 维空间里的体积有一个朴素的直觉，二维叫面积，三维叫体积，四维以上虽然画不出来，数学上依然有一个量对应它。这个量必须满足三条几乎不像数学命题、更像常识的规则。

一，把一条边放大 k 倍，整个体积放大 k 倍。平行四边形的一条边拉长到两倍，面积变两倍。这是线性。更一般地，如果某条边本身是两个向量的和，那总体积就是两种情况的体积之和。这叫多重线性，指的是这个量对每一个列向量都是线性的。

二，把任意两条边交换位置，体积变号。一个直觉例子，把右手摆成拇指食指中指三指互相垂直的姿势，这是一个正向的三维体积。把中指和食指交换位置，得到的是左手，是右手的镜像。物理上两者体积相等，但方向反了，数学上用一个负号来编码这个方向反转。这叫交替性。

三，单位立方体的体积是 1。n 维空间里由标准基向量张成的那个标准立方体，总得给它定一个起点，定为 1 就是归一化。

就这三条。对 n 维带符号体积来说，没人会反对这三条。

**关键点是，一旦坚持让一个函数同时满足这三条，答案会被唯一锁死。**

柯西和他之后一代代数学家证明了这件事。在所有”把 n×n 矩阵映射到一个实数”的函数里，有且只有一个同时满足多重线性、交替性、归一化这三条。

把 2×2 的情况展开来算，这个唯一的函数必然等于 ad − bc。把 3×3 展开来算，必然等于 Sarrus 那六项。把 n×n 展开来算，必然等于 Σ sgn(σ) Π A\_{σ(i),i} 这个求和。

**公式不是行列式的定义。公式是三条几何公理下硬解出来的唯一解。**

这就是课本造成错觉的地方。课本让人先背公式，以为公式是第一位的。真实的层次是：三条几何公理是第一位的，唯一性定理是第二位的，公式是第三位的，是前两者在具体代数形式下的投影。

接受了行列式是带符号体积的变换倍数这个本质之后，原先看上去互不相关的那几条性质，全部一秒钟塌缩成同一件事。

先看 det(AB) = det(A)·det(B)。

A 和 B 都是 n 维空间到 n 维空间的线性变换。A 把单位立方体变成一个体积放大了 det(A) 倍的平行多面体，B 再把它变成体积再放大 det(B) 倍的新多面体。连续做两次拉伸，总拉伸倍数等于两次倍数相乘。

这不是一个需要证明的定理，这就是变换倍数这个概念的定义性质，倍数可乘。

再看 det(A) = 0 意味着 A 不可逆。

det(A) = 0 意味着 A 把单位立方体压扁了。n 维的物体被压成了某种 n−1 维以下的结构，一张纸，一条线，或者一个点。一张三维世界里的纸在三维的标准下体积是零，但在二维的标准下可能还有面积。

关键是一旦被压扁，信息就丢了。被压扁的那些维度没有任何办法通过一个线性映射再恢复出来，因为线性映射是逐点对应的，没法凭空生成被压掉的那一维。所以 A 不可逆。等价地，det(A)·det(A⁻¹) = det(I) = 1，如果 det(A) = 0，等式左边恒为零，A⁻¹ 不存在。

不可逆的几何实质是降维，降维之后高维标准下体积归零。这两句话是同一件事的不同说法。

再看二阶行列式为什么等于平行四边形面积。

二阶行列式是二维带符号面积的变换倍数。单位正方形面积为 1，被 A 变换后变成面积为 det(A) 的平行四边形。单位正方形的边是标准基向量，A 的两列是 A 把这两个基向量送过去的位置，所以那个平行四边形以 A 的两列为边，带符号面积就是 det(A)。

不是先算出面积发现恰好等于行列式。行列式本来就是面积。

停下来想一件事，行列式为什么必须带正负号。

如果只是体积，就区分不了这两件事：把平面图形旋转 180 度，和沿一条轴翻转。这两个操作之后，单位正方形变成的那个平行四边形，面积完全一样。但本质上不同，一个保持了方向，一个把正面变成了反面。

二维打个比方，一个是镜子前的自己，一个是镜子里的自己。两者面积一样，但一个能通过旋转变成另一个，一个不能。

det(A) > 0 表示 A 保持方向，右手依然是右手。det(A) < 0 表示 A 反转方向，需要一次镜像才能把左手拧回右手。

这个符号不是行列式定义里多出来的装饰，它是方向这个几何概念在代数里的投影。三条公理和三件几何事实严格对应：多重线性对应缩放与拼接，交替性对应方向，归一化对应原点和度量单位。一一锁死，没有冗余。

再往深走一步。行列式这个概念一旦被定义成变换对体积的影响，就不再只是矩阵的专利。

多元微积分里有一个换元法。二重积分里用新变量 u, v 代替旧变量 x, y 的时候，积分元素要乘上一个东西，叫雅可比行列式的绝对值 |det(J)|。

为什么是这个东西。

因为一个光滑映射在每一点附近都可以被它的雅可比矩阵线性逼近。在 (u, v) 空间里取一个微小的正方形，经过映射后变成 (x, y) 空间里的一个微小的平行四边形。这个小平行四边形的面积等于原小正方形的面积乘以局部的变换倍数，而局部的变换倍数正是雅可比矩阵的行列式。

积分就是把每一点的函数值乘以这一点附近的面积再加起来。换了变量，这一点附近的面积变成了原来的 |det(J)| 倍，所以要乘回去。

**行列式不是线性代数的一个孤立章节。它是变换如何影响体积这件事的底层语言，不管变换是线性的还是非线性的。** 非线性情形下，它只是变成了逐点计算的雅可比行列式。

1841 年雅可比系统整理出了这套理论，他处理的问题跟今天课本里的换元积分是同一件事。微积分里那个突然冒出来的 |det(J)|，其实是行列式在更一般场景下的自然延伸，不是微积分课本临时借了一个线性代数的概念。

到这里可以看清行列式的三条主线。它是一个代数公式，是一个几何量，是一个不变量。

三条线看起来独立，但它们是同一个东西的三个侧面。

代数公式是三条公理下硬解出来的唯一函数。几何量是这三条公理背后的真正内容：带符号体积。不变量是这个几何量具备的若干关键性质，乘法性、识别奇异性、换元时的局部系数等等，这些性质让行列式成为线性代数里少数几个一个数就能判定矩阵全局行为的工具。

课本呈现的那个求和公式，是这三者在最抽象、最远离直觉的形式上被压扁之后的样子。把它放回到原本的位置，带符号体积的变换倍数，所有东西同时变简单。

回到一开始的问题。

行列式的本质是什么。

不是 ad − bc 这个口诀。不是 Sarrus 规则那六项。不是 Σ sgn(σ) Π A\_{σ(i),i} 这个求和。

那些是公式，是三条几何公理在代数上的唯一表达，是算出来的结果，不是原因。

本质是一句话：**行列式是 n 维带符号体积在线性变换下的倍数。** 矩阵把一个单位超立方体变成一个平行多面体，行列式就是后者与前者体积之比，带上一个记录方向是否翻转的正负号。

这一句话同时解释三件事：公式为什么长那样，性质为什么是那几条，几何意义从哪来。三条从一个源头长出去，不是三件独立发生的事。

课本的顺序是公式在前，性质在后，几何意义在附录。现实的顺序是几何直觉在前，公理在中间，公式在最后。

你不是学不会，你是被教错了层次。

最后顺便做一件事。

把三条公理代进去，现场把 ad − bc 推出来，看看它到底从哪冒出来的。

矩阵 A 的两列是 (a, c) 和 (b, d)，拆成标准基向量的组合：第一列等于 a·e₁ + c·e₂，第二列等于 b·e₁ + d·e₂。

用多重线性把 det(A) 展开，得到四项：

ab · det(e₁, e₁) + ad · det(e₁, e₂) + cb · det(e₂, e₁) + cd · det(e₂, e₂)

交替性立刻消掉两项，det(e₁, e₁) 和 det(e₂, e₂) 都等于零，两列相同的话对应的平行四边形退化成一条线，面积为零。

剩下 ad · det(e₁, e₂) + cb · det(e₂, e₁)。

归一化给出 det(e₁, e₂) = 1，也就是标准单位正方形面积。交替性再给出 det(e₂, e₁) = −det(e₁, e₂) = −1，两列一交换就变号。

代回去，ad · 1 + cb · (−1) = ad − bc。

第一节课就学会的那四个字符里，多重线性、交替性、归一化这三条公理已经全部写在里面了。那时只是没被告诉应该怎么读它。
