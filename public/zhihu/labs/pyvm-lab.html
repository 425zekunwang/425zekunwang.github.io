Python 虚拟机模拟器

刘晓刚《自己动手写 Python 虚拟机》把 CPython 拆成三件事：把源码变成树、把树变成字节码、把字节码喂给一个栈式循环。 下面把这三件事各做成一个能动手的模型：你可以单步执行自己设计的字节码、看操作数栈一格一格长起来； 可以手写词法/语法分析器、把语法树真的画出来；也可以亲手制造一个引用计数永远回收不掉的循环引用，再用标记-清除收拾它。
